## Acceptance
- **R193 / AT193:** Remote sign-in second factor by policy (CR-011 §4A): remote.mfa_policy off|admins|sensitive|all with a per-user override replaces remote.require_mfa_admin; for users under the policy the remote channel accepts only an Arx sign-in whose HA refresh token is type normal, client_id = this Arx address, auth_provider_type homeassistant, created after Arx first saw MFA enabled for the user (checked through auth/refresh_tokens and auth/current_user); long-lived access tokens and other clients' sign-ins are refused there; refusals are audited and explained.
- **R194 / AT194:** Step-up for sensitive actions (CR-011 §4E): disarm, bypass, door unlock, alarm codes/PINs/remote settings, user roles and the remote flag, system.configure settings, revoking others' sessions and factor resets answer 403 step_up_required unless the session holds a second-factor proof younger than security.step_up_minutes (default 5); proofs come from a server challenge (32-byte nonce, 60 s, bound to user, session and action); the Android app proves with a Keystore EC P-256 key bound to BIOMETRIC_STRONG (per-use auth, invalidated by new biometric enrolment) signing the challenge through BiometricPrompt with a CryptoObject, registered per device only after a fresh sign-in or an existing factor; browser/PWA sessions without a device key fall back to the personal alarm PIN for alarm actions; audited, rate-limited, remote channel by default; factor reset by administrators from the local channel only by default.
- **R195 / AT195:** Passkeys and push approval (CR-011 §4C/§4D): WebAuthn registration and assertion with rpId = the Arx hostname and userVerification required serve as step-up (and optionally sign-in) proofs in browsers and the PWA, and inside the Android WebView through androidx.webkit setWebAuthenticationSupport(FOR_APP) with a /.well-known/assetlinks.json tunnel route to the add-on and a runtime fallback; after CR-012, a push approval with number matching signed by the device key approves a sensitive action started elsewhere.
