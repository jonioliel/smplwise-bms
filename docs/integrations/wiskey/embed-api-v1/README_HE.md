הבקשה לממשק הטמעה יציב מומשה בצד WisKey ופורסמה בגרסה **2.0.0-rc.19**.

- גרסה להתקנה: https://github.com/jonioliel/home-assistant-hikvision-intercom/releases/tag/v2.0.0-rc.19
- Commit שפורסם: `8c70ae348259088dc4f831ee9d8fa19fcff62a65`
- בדיקות השחרור עברו עבור אותו commit: https://github.com/jonioliel/home-assistant-hikvision-intercom/actions/runs/36478363059
- חבילת המקור שפורסמה נבדקה: נתיב HACS, הגרסה, קוד הממשק וקבצי ההדרכה תואמים לשחרור.

## הוראות להעברה למפתח / Claude

יש לממש את החיבור לפי `WISKEY_EMBED_API_V1.md`, ולהשתמש בדוגמה
`examples/wiskey-embed-client.mjs`. לטעון את המסכים המקוריים באותו מקור דפדפן:

```text
/hikvision-intercom?embed=1&tab=users
/hikvision-intercom?embed=1&tab=tools&tool=media_options
```

להחליף את קריאות `navigate()` הפנימיות ב־`wiskey:navigate`, לבנות את הניווט
לפי `wiskey:ready` ולשקף את המיקום המאושר מתוך `wiskey:location`.
יש להתקין את מאזין ההודעות לפני טעינת המסגרת. המפרט מפרט גם כותרות, קישורים,
הרשאות, איפוס מצב, תמיכה בנייד והבדלה בין התקנה ישנה לטעינה מתעכבת.

כל המסכים והפעולות נשארים במימוש המקורי של WisKey; אין צורך ליצור אותם מחדש
לצורך הטמעה זו. המערכת נשארת תחת domain טכני `hikvision_intercom`.

קטלוג הפקודות נכלל לייחוס בלבד. הוא אינו ערוץ ההטמעה, ואין לשלוח דרכו אסימון
Supervisor לדפדפן. מסגרת ה־WisKey פועלת בזהות המשתמש המחובר ובהרשאותיו.

## היקף האישור

שערי הבדיקות עברו: בדיקות ליבה, בדיקות מול התשתית, בדיקות ממשק Chrome/
Firefox/WebKit, בדיקות קוד ותלויות, HACS ואימות האינטגרציה.
התוצאות המדויקות וקישורי המקור מצורפים ב־`release-verification.json`.

| סבב | תוצאה |
| --- | --- |
| ליבה ב־Python 3.12 | 1,543 עברו |
| ליבה ב־Python 3.14 | 1,543 עברו |
| אינטגרציה מול תשתית המערכת | 545 עברו |
| ממשק ב־Firefox וב־WebKit | 250 עברו |
| ממשק ב־Chrome | 653 עברו |

סבבי הדפדפנים כוללים את 21 הבדיקות הייעודיות לחוזה ההטמעה בכל דפדפן.

האישור הוא למימוש ולשחרור בצד WisKey. בצד ה־VMS נותר לאמץ את המתאם ולבדוק
את מסגרת ה־Ingress בפועל: סרגל אחד, ניווט, משתמש מוגבל, יציאה וחזרה ומדיה.
הבקשה הזו אינה כוללת שינוי בשרת VMS הנפרד או אישור שהחיבור בו כבר הותקן.

אפשר לפתוח את `WISKEY_EMBED_HANDOFF_HE.html` להצגת ההדרכה וקישורים לקבצים.
המסמך המרוכז לכל בדיקות הימים האחרונים נשאר בהמתנה לבקשת בעל המערכת.
