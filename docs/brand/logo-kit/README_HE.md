# חבילת הלוגו לצוות הפיתוח

החבילה מבוססת על **02B-2 שאושר, עם w מעוגלת וסמל SW דק**.

- `svg/brand/logo-horizontal.svg` — הלוגו העליון המלא: סמל ושם.
- `svg/brand/wordmark.svg` — השם בנפרד.
- `svg/brand/symbol.svg` — הסמל בנפרד.
- `svg/brand/logo-stacked.svg` — סמל מעל השם.
- `app-icon.svg` ו־`app-icon-rounded.svg` — אריחי אפליקציה.
- `logo-panel.svg` — לוגו לבן על פאנל כהה.
- `preview/index.html` — דף השוואה עם שינוי צבעים וגודל, עובד מקומית.

כל האותיות הן קווי מתאר וקטוריים, ללא צורך בהתקנת פונט. לא מדובר בתמונה עטופה בתוך SVG. הווקטורים משחזרים את התמונה שאושרה; הצללות קלות בתמונה הוחלפו בצבעים אחידים.

התיקיות `white`, `black`, `navy` מספקות גרסאות בצבע אחיד עם רקע שקוף. בגרסאות `themeable` אפשר לשנות בנפרד את צבע הסמל, השם והרקע באמצעות:

```css
--smplwise-symbol: #0062ff;
--smplwise-wordmark: #0e3054;
--smplwise-background: transparent;
```

לשינוי צבעים מתוך CSS של האתר יש להשתמש ב־SVG מוטמע ישירות, ברכיב React או ב־sprite. קובץ שמוטען באמצעות תגית `img` אינו יורש את משתני הצבע מהעמוד. אפשר גם לערוך ישירות את ערכי `fill` בקבצים.

רוב הגרסאות שקופות לחלוטין; רק גרסאות האריח והפאנל מכילות מלבן רקע שניתן לצבוע או להסיר. גודל ה־SVG אינו מוגבל; שינוי רוחב צריך לשמור על יחס הגובה. קובצי PNG במספר גדלים, favicon ואייקוני אפליקציה כלולים לנוחות.

הוראות מלאות ודוגמאות HTML, React ו־CSS נמצאות ב־`README.md`. אין להחליף את הכיתוב בהקלדה בפונט אחר — צורת ה־w המאושרת כלולה בקווי המתאר.
