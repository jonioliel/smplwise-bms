## 2.10.0 (pilot) — Access control built out on fakes and locked (bulk people import / edit, per-station access, arrival step and cards for vendors, door-opening automations, bridge key rotation, WisKey peer seam and station sync); vendor reports through the message queue with documents by temporary link and e-mail; generator alert routing per severity; an optional passkeys-only sign-in; off-box backup and restore drill; NVR privacy masks; Frigate 0.18 features verified live; an events list for installations without an NVR; a faster 3D screen on phones; no service-request action anywhere while the tickets module is off; UX, RTL and accessibility fixes; public-surface hardening; a faster release gate
**After installing:** **eight automatic database migrations** (0128: vendor report queue and documents by temporary link - two outbox tables rebuilt with every 2.9.3 column kept, new document-link table; 0129: bulk people jobs; 0130: passkeys-only flag per local user; 0131: generator alert routing per severity (old escalation minutes moved to the new field); 0132: arrival flags and access cards on the access grants; 0133: door automations; 0134: per-station access of a person; 0135: bridge key set for key rotation; the sequence is 0001..0135, contiguous). **Bridge 0.9.4** (allowlist picker in the bridge options): **one Home Assistant restart** after the update. No new add-on option. Reload the installed web app once. WisKey door writes, the extended service identity, bulk people, per-station access, door automations, access cards and bridge key rotation stay locked (their go-live permits are not in this build).
- **עברית:** אחרי ההתקנה: **שמונה מיגרציות אוטומטיות של מסד הנתונים** (0128: תור דוחות לספקים ומסמכים בקישור זמני - שתי טבלאות יוצאות נבנות מחדש וכל העמודות של 2.9.3 נשמרות, טבלת קישורי מסמכים חדשה; 0129: משימות עדכון אנשים בכמות; 0130: סימון "מפתחות גישה בלבד" למשתמש מקומי; 0131: ניתוב התראות גנרטור לפי חומרה (דקות ההסלמה הישנות עוברות לשדה החדש); 0132: סימוני הגעה וכרטיסי גישה בהרשאות הגישה; 0133: אוטומציות דלתות; 0134: גישה לפי עמדה של אדם; 0135: סט מפתחות הגשר להחלפת מפתח; הרצף הוא 0001..0135, רציף). **גשר 0.9.4** (בורר רשימת ההיתרים באפשרויות הגשר): **הפעלה מחדש אחת של מערכת הבית** אחרי העדכון. אין אפשרות תוסף חדשה. יש לטעון מחדש פעם אחת את אפליקציית הרשת המותקנת. כתיבות הדלתות של WisKey, הזהות המורחבת, עדכון אנשים בכמות, גישה לפי עמדה, אוטומציות דלתות, כרטיסי גישה והחלפת מפתח הגשר נשארים נעולים (היתרי ההפעלה שלהם אינם בגרסה הזו).

### What is OFF by default and how to enable - מה כבוי כברירת מחדל ואיך מפעילים
- **English:** Reports to vendors: Settings › service module › message channel › "Reports to vendors" (master switch, then e-mail and document links). Generator alert routing: the generator's alert settings (routing starts empty). Passkeys only: in the user's own passkeys card, or by an administrator. Restore drill: `GET/POST /backups/drill` and its schedule (`backup.manage`; monthly run OFF); the off-box destinations have no settings screen in this build. Live camera viewfinder: the tickets settings `ui.camera_viewfinder`. NVR privacy masks: holders of `nvr.config.privacy`, local only. Public-interface settings: Settings › Security › Public interface. Locked in this build (cannot be turned on): WisKey door writes (`access_grants.GO_LIVE_PERMITTED = False`), the extended identity, bulk people, per-station access, door automations, access cards and bridge key rotation. Everything else applies without a switch.
- **עברית:** דוחות לספקים: הגדרות › מודול השירות › ערוץ הודעות › "דוחות לספקים" (מתג ראשי, ואחריו מייל וקישורי מסמכים). ניתוב התראות גנרטור: הגדרות ההתראות של הגנרטור (הניתוב מתחיל ריק). מפתחות גישה בלבד: בכרטיס מפתחות הגישה של המשתמש, או על ידי מנהל. תרגיל שחזור: דרך ממשק הגיבוי (`backup.manage`; הרצה חודשית כבויה); ליעדים מחוץ למכשיר אין מסך הגדרות בגרסה הזו. עינית מצלמה חיה: הגדרות הבקשות `ui.camera_viewfinder`. מסיכות פרטיות ב-NVR: מי שמחזיק `nvr.config.privacy`, מקומית בלבד. הגדרות הממשק הציבורי: הגדרות › אבטחה › ממשק ציבורי. נעולים בגרסה הזו (אי אפשר להפעיל): כתיבות הדלתות של WisKey, הזהות המורחבת, אנשים בכמות, גישה לפי עמדה, אוטומציות דלתות, כרטיסי גישה והחלפת מפתח הגשר. כל השאר פועל בלי מתג.

### Known limits - מגבלות ידועות
- **English:** The access-control features, door automations, key rotation, vendor reports and backup destinations were tested with fakes only (no real WisKey, station, door, bridge, WhatsApp, e-mail, SFTP or S3). `tickets.directory` does not open the external-access identity card, its export, link or delete-person (still `tickets.configure`; fail closed, for the security review). The vendor-report document link is a new public surface: a public-surface security review is required before it is switched on.
- **עברית:** תכונות בקרת הגישה, אוטומציות הדלתות, החלפת המפתח, דוחות הספקים ויעדי הגיבוי נבדקו רק עם תחליפים (ללא WisKey, עמדה, דלת, גשר, וואטסאפ, מייל, SFTP או S3 אמיתיים). `tickets.directory` לא פותחת את כרטיס הזהות של הגישה החיצונית, את הייצוא, הקישור או מחיקת האדם (עדיין `tickets.configure`; נכשל סגור, לסקירת האבטחה). קישור המסמך בדוחות לספקים הוא ממשק ציבורי חדש: נדרשת סקירת אבטחה של ממשק ציבורי לפני שמפעילים אותו.
