# SmplWise Arx 2.5.1 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.5.1, bilingual per item).

Gate: serial tier L on the Linux test machine; the result is recorded in 2.5.1-INTEGRATION-NOTES.md. Fakes only: no real message was sent.

## 2.5.1 (pilot) — Service management: a "Handlers and vendors" page, employees without an account, an assign dialog that tells you what is missing, departments with a name only (and restore), and the Permissions tab no longer hangs
**After installing:** **one database migration, applied automatically at start**: 0084 (`ALTER TABLE ticket_contacts ADD COLUMN employee`, a flag with a 0/1 check); the sequence is now 0001..0084, contiguous. **No bridge change** (0.8.0). **No new add-on option.** Reload the installed web app once. The module stays OFF by default and nothing changes for an installation that has not switched it on. **Fakes and fixtures only: nothing here sent a real message or contacted a device.**
- **עברית:** אחרי ההתקנה: **מיגרציה אחת של מסד הנתונים, שרצה אוטומטית בהפעלה**: 0084 (`ALTER TABLE ticket_contacts ADD COLUMN employee`, דגל עם בדיקת 0/1); הרצף עכשיו 0001..0084 ללא פערים. **אין שינוי בגשר** (0.8.0). **אין אפשרות תוסף חדשה.** יש לרענן את היישום המותקן פעם אחת. המודול נשאר כבוי כברירת מחדל ושום דבר לא משתנה בהתקנה שלא הפעילה אותו. **רק דמויות ופיקסצ'רים: דבר מכל זה לא שלח הודעה אמיתית ולא פנה להתקן.**

## What was added and fixed - מה נוסף ומה תוקן
- **English:** (1) **A "Handlers and vendors" page** (`#/tickets/handlers`, the fifth entry in the service-management view menu) with four segments: department handlers (members with an account: add, role, alert, remove), employees without an account, vendors and contacts. The contacts tab left Settings; a link card replaces it and the old `?tab=contacts` link opens the vendors segment. (2) **Employee without an account**: a new contact kind "employee" for a staff member who has no Arx login; he is assigned and reached through the same private-link path as any outside contact, and is offered first in the assign dialog (migration 0084). (3) **The assign dialog always shows its three groups** (handlers, employees without an account, vendors and contacts); a group that cannot be used says why in one line, with a link to the exact setting that fixes it. WhatsApp being off is a note, not a block. A **readiness strip** on the handlers page appears only when something is missing (handler page, address, key, WhatsApp switch, account); it is fed by one readiness object (`GET /api/v1/tickets/readiness`, also inside `GET /tickets/assignees`) that carries booleans and counts only. (4) **A new department needs only a name**: the identifier field is gone and the server makes the key from the name; the delete asks for confirmation and says what it affects (open requests block it, with the reason). (5) **Deleted departments can be restored**: Settings lists "מחלקות שנמחקו" (collapsible) with a restore action; a delete never touched categories, priorities, members, SLA, templates or requests, so they all come back. (6) **Fixed: the Permissions tab ("הרשאות") of the module no longer loads forever.** The cost permissions were missing from its label catalogue and the render threw; labels now read both catalogues, an unknown permission shows its name, a grant on a removed place shows its id (never "null"), and a failed load shows an error with a retry. (7) The outside list in the assign dialog keeps its rows' height when it scrolls.
- **עברית:** (1) **עמוד "מטפלים וספקים"** (`#/tickets/handlers`, הרשומה החמישית בתפריט התצוגה של ניהול השירות) עם ארבעה מקטעים: מטפלי מחלקה (חברים עם חשבון: הוספה, תפקיד, התראה, הסרה), עובדים בלי חשבון, ספקים ואנשי קשר. לשונית אנשי הקשר יצאה מההגדרות; כרטיס קישור תופס את מקומה והקישור הישן `?tab=contacts` פותח את מקטע הספקים. (2) **עובד בלי חשבון**: סוג איש קשר חדש "עובד" לעובד שאין לו כניסה ל־Arx; משייכים אותו ומגיעים אליו באותו מסלול של קישור פרטי כמו כל איש קשר חיצוני, והוא מוצע ראשון בחלון השיוך (מיגרציה 0084). (3) **חלון השיוך מציג תמיד את שלוש הקבוצות** (מטפלים, עובדים בלי חשבון, ספקים ואנשי קשר); קבוצה שאי אפשר להשתמש בה אומרת למה בשורה אחת, עם קישור להגדרה המדויקת שמתקנת. וואטסאפ כבוי הוא הערה ולא חסימה. **פס מוכנות** בעמוד המטפלים מופיע רק כשמשהו חסר (דף מטפלים, כתובת, מפתח, מתג וואטסאפ, חשבון); הוא ניזון מאובייקט מוכנות אחד (`GET /api/v1/tickets/readiness`, וגם בתוך `GET /tickets/assignees`) שמכיל רק ערכים בוליאניים וספירות. (4) **מחלקה חדשה דורשת שם בלבד**: שדה המזהה הוסר והשרת מייצר את המפתח מהשם; מחיקה מבקשת אישור ואומרת על מה היא משפיעה (בקשות פתוחות חוסמות אותה, עם הסיבה). (5) **אפשר לשחזר מחלקות שנמחקו**: בהגדרות מופיעה הרשימה "מחלקות שנמחקו" (מתקפלת) עם פעולת שחזור; מחיקה מעולם לא נגעה בקטגוריות, בעדיפויות, בחברים, ב־SLA, בתבניות ובבקשות, ולכן הכול חוזר. (6) **תוקן: לשונית ההרשאות של המודול כבר לא נתקעת בטעינה.** הרשאות העלות חסרו בקטלוג התוויות והתצוגה נפלה; עכשיו התוויות נקראות משני הקטלוגים, הרשאה לא מוכרת מציגה את שמה, הרשאה על מקום שהוסר מציגה את המזהה שלו (לעולם לא "null"), וטעינה שנכשלה מציגה שגיאה עם "נסה שוב". (7) רשימת החיצוניים בחלון השיוך שומרת על גובה השורות שלה בגלילה.

## How to use - איך משתמשים
- **English:** open the service-management area and choose "מטפלים וספקים" in the view menu (needs `tickets.configure` to edit, or `tickets.manage` to read the rows of your own departments, with masked phones). Add an **employee without an account** in the employees segment (name and phone, the departments he serves). In a request's **assign** dialog pick the group; if a group is greyed out, its one-line reason links to the setting to fix. To create a department: Settings › the module › departments › new, type a name only. To restore one: Settings › "מחלקות שנמחקו" › restore (needs `tickets.configure`). Rollback: revert the release; the `employee` column is additive and harmless to the old code.
- **עברית:** נכנסים לאזור ניהול השירות ובוחרים "מטפלים וספקים" בתפריט התצוגה (עריכה דורשת `tickets.configure`, וקריאת שורות המחלקות שלך דורשת `tickets.manage`, עם טלפונים מוסתרים). מוסיפים **עובד בלי חשבון** במקטע העובדים (שם וטלפון, והמחלקות שהוא משרת). בחלון **השיוך** של בקשה בוחרים קבוצה; אם קבוצה מעומעמת, שורת הסיבה שלה מקשרת להגדרה שמתקנת. ליצירת מחלקה: הגדרות › המודול › מחלקות › חדשה, מקלידים שם בלבד. לשחזור: הגדרות › "מחלקות שנמחקו" › שחזר (דורש `tickets.configure`). החזרה לאחור: החזרת הגרסה; העמודה `employee` תוספתית ולא מזיקה לקוד הישן.
