# SmplWise Arx 2.3.1 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.3.1, bilingual per item).

## 2.3.1 (pilot) - patch: DXF layers per level, optional "DXF + picture" package, Hebrew user guide refresh

**After installing:** no database migration; the bridge stays 0.7.0. Reload the installed web app once. 699 API routes (unchanged; the
package route takes one new optional body field `dxf`). Nothing new is switched on by itself.

### Plan DXF per level (PLN2)
**Added.** A plan with more than one level exports its DXF with a layer family per level (`SW_WALLS-L0`, `SW_OPENINGS-L1`, rooms,
objects, connectors, labels; suffix = level id, upper-case, `[A-Z0-9_]`, at most 24 characters). A plan with one level exports the
same drawing as before. The signed plan package can carry `assets/plan.dxf` beside the plan picture (button **"DXF + picture"**,
body `{"draft": ..., "dxf": true}`); the drawing names `background.<ext>` by file name, so unzip the package and open `assets/plan.dxf`.
Multi-level round-trip tests (three levels, stairs, elevator, connector to another floor; replace and merge import) and an editor
end-to-end spec were added.
**Compatibility.** Importers of 2.2.x and 2.3.0 reject packages with the extra file. The plain **"Package"** button is unchanged and
still produces packages those versions can import; use "DXF + picture" only between 2.3.1 installations or to give the drawing to a
CAD user. A DXF over 24 MiB is left out of the package.
**Known open item.** A furniture or structure item attached to a camera still names that camera id in `plan.json` and in the geometry
reads even when the exporter's camera scope hides the camera elsewhere (anchors, report, DXF devices). Needs an owner decision, since
the stored document is what the hashes cover (`docs/changes/ST5-PLAN-PACKAGE-DXF.md`, PLN2 section).
**Not verified.** The drawing with its picture was read back with a Python DXF library only, not opened in AutoCAD / BricsCAD / QCAD.
**How to use.** Plan Studio editor, structure panel, export row: **DXF** (drawing alone), **Package** (as before), **DXF + picture**.
The structure editor is not offered on a phone (intentional).

### User guide
Hebrew guide refreshed (`docs/user-guide/he/`): second factor policy per user / role, voice announcement extras, Frigate review
event controls, with new screenshots. No product behaviour change. Registry: management evidence and test catalog updated.

## עברית - תקציר
- **DXF לפי קומה:** תוכנית רב-קומתית מייצאת DXF עם משפחת שכבות לכל קומה (`SW_WALLS-L0` וכו'); תוכנית עם קומה אחת - כמו קודם.
- **"DXF + תמונה":** כפתור חדש בעורך; החבילה החתומה כוללת `assets/plan.dxf` לצד תמונת התוכנית. **תאימות:** 2.2.x ו־2.3.0 דוחות חבילה
  כזו, לכן הכפתור "חבילה" הרגיל לא השתנה.
- **נושא פתוח:** פריט המחובר למצלמה עדיין נושא את מזהה המצלמה ב־`plan.json` גם כשהיקף המייצא מסתיר אותה - ממתין להחלטת בעלים.
  **לא אומת** בתוכנת CAD אמיתית.
- **מדריך המשתמש** רוענן (אימות דו-שלבי, הכרזות, בקרות אירוע ב־Frigate). **אחרי ההתקנה:** אין מיגרציה; טוענים מחדש את אפליקציית הרשת.
