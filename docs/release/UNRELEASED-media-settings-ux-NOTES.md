# Release notes draft - Settings > Multimedia lists (media-settings-ux)

## עברית
### מה חדש
- הגדרות › מולטימדיה: רשימות המסכים והנגנים/רמקולים הן שורות קומפקטיות. לחיצה על החץ בתחילת השורה פותחת את טופס העריכה המלא מתחתיה (כל השדות והפעולות כמו קודם).
- בכל שורה: האינטגרציה שממנה הרכיב הגיע, המזהה של הישות והמזהה של ההתקן (עם כפתור העתקה), החדר, המצב (זמין/לא זמין), אישור ומספר החיבורים.
- סינון: חיפוש חופשי (גם לפי מזהה ושם אינטגרציה), אינטגרציות (אפשר כמה יחד), חדר, סוג, אישור וזמינות. "נקה סינון" מאפס.
- מיון וקיבוץ: מיון לפי שם, סוג, אינטגרציה, חדר, מזהה או מצב (עולה/יורד, גם בלחיצה על כותרת עמודה); קיבוץ לפי אינטגרציה, חדר או סוג עם כותרת מתקפלת ומספר.
### איך משתמשים
1. כנסו להגדרות › מולטימדיה.
2. הקלידו בחיפוש חלק ממזהה או משם אינטגרציה, או לחצו על אינטגרציה אחת או יותר.
3. בחרו "קיבוץ" כדי לראות כותרת לכל אינטגרציה או חדר; לחיצה על הכותרת מקפלת אותה.
4. הבחירה האחרונה (בלי טקסט החיפוש) נשמרת בדפדפן, לכל משתמש ולכל רשימה בנפרד.

## English
### What is new
- Settings > Multimedia: the screens and the speakers / players lists are compact rows. The arrow at the start of a row opens the full edit form under it (every field and action as before).
- Each row shows the integration the component came from, the entity id and the device id (with a copy key), the room, the status (available / not), approval and the connections count.
- Filters: free text (also matches ids and integration names), integrations (several at once), room, type, approval and availability; "נקה סינון" resets.
- Sort and group: by name, type, integration, room, id or status (ascending / descending, also from the column headers); group by integration, room or type with collapsible headers and counts.
### How to use
1. Open Settings > Multimedia.
2. Type part of an id or an integration name, or press one or more integration chips.
3. Choose a grouping to get a header per integration or room; press a header to fold it.
4. The last choice (not the search text) is remembered in the browser per user and per list.
