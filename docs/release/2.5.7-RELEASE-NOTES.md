## 2.5.7 (pilot) — Service management: vendor page quote / payment card, security hardening, expand-arrow fix
**After installing:** **two automatic database migrations** (0085 adds the cost-quote table, 0086 adds a column to the outbound message table; the sequence is 0001..0086, contiguous). **No bridge change** (0.8.0). **No new add-on option.** Reload the installed web app once; the vendor page reloads itself on the next link opening. The module stays OFF by default and nothing changes for an installation that has not switched it on. **Fakes and fixtures only: nothing here sent a real message or contacted a device.**
- **עברית:** אחרי ההתקנה: **שתי מיגרציות אוטומטיות של מסד הנתונים** (0085 מוסיפה את טבלת הצעות המחיר, 0086 מוסיפה עמודה לטבלת ההודעות היוצאות; הרצף 0001..0086 ללא פערים). **אין שינוי בגשר** (0.8.0). **אין אפשרות תוסף חדשה.** יש לרענן את היישום המותקן פעם אחת; דף הספק נטען מחדש בפתיחת הקישור הבאה. המודול נשאר כבוי כברירת מחדל ושום דבר לא משתנה בהתקנה שלא הפעילה אותו. **רק דמויות ופיקסצ'רים: דבר מכל זה לא שלח הודעה אמיתית ולא פנה להתקן.**

### What was changed - מה השתנה
- **English:** Fixed: the expand arrow in a service-request side panel now opens the request full-screen instead of snapping back to the list. Drawers no longer rewrite the address when their screen is left.
- **עברית:** תוקן: חץ ההרחבה במגירת בקשת שירות פותח כעת את הבקשה במסך מלא, במקום לחזור לרשימה. מגירה כבר לא משכתבת את הכתובת בעת עזיבת המסך.
- **English:** Vendor page: a permanent 'quote / payment request' card is visible from the first moment - send a quote before the work (work + parts by default; travel/other only when the request or department allows) and the payment request after 'Done', shown against the approved quote. Approving a quote sends no message. New setting for the vendor page look (light / dark / auto, default light) under Settings > service management > General > handlers page, plus a light/dark toggle on the page itself. Arabic and Russian strings of the card and the theme are initial and need native review. Known limits: no manager UI for quotes yet (API only), the quote draft is kept in memory only.
- **עברית:** דף הספק: כרטיס קבוע 'הצעת מחיר / דרישת תשלום' מוצג מהרגע הראשון: הצעת מחיר לפני העבודה (עבודה וחלקים כברירת מחדל; נסיעה ואחר רק אם הבקשה או המחלקה אישרו) ודרישת תשלום אחרי 'בוצע', מול ההצעה המאושרת. אישור הצעה לא שולח הודעה. הגדרה חדשה למראה הדף (בהיר / כהה / לפי המכשיר, ברירת מחדל בהיר) בהגדרות > ניהול השירות > כללי > דף המטפלים, ומתג בהיר/כהה בדף עצמו. מחרוזות בערבית וברוסית של הכרטיס ושל המראה הן ראשוניות ודורשות בדיקת דובר שפה. מגבלות ידועות: אין עדיין מסך ניהול להצעות מחיר (API בלבד), וטיוטת ההצעה נשמרת בזיכרון בלבד.
- **English:** Service management security hardening: the invoice PDF check also reads streams after a lone CR or trailing blanks, refuses predictor-coded and double-compressed object streams and indirect decode parameters (cross-reference streams and image XObjects keep their predictor), and honours a stream's declared length. Pending invoice files are capped at 64 MiB per vendor link (as well as 30 files). Vendor replies are cleaned like every other text. One faulty incoming message no longer drops the others received with it. Reply buttons of a message sent before 'new link' no longer act. A reply claimed by a manager more than 15 minutes ago can be taken over. Message templates also refuse a bare web address with a path. One automatic database migration adds a column to the outbound message table.
- **עברית:** הקשחת אבטחה בניהול השירות: בדיקת קובצי PDF של חשבוניות קוראת גם זרמים אחרי CR בודד או רווחים, דוחה זרמי אובייקטים מקודדים ב-Predictor או דחוסים פעמיים ופרמטרי פענוח עקיפים (זרמי הפניה צולבת ותמונות שומרים על ה-Predictor), ומכבדת את האורך המוצהר של הזרם. קבצים ממתינים מוגבלים ל-64MiB לכל קישור ספק (בנוסף ל-30 קבצים). תשובות ספקים עוברות ניקוי טקסט כמו כל טקסט אחר. הודעה נכנסת תקולה אחת כבר לא מפילה את ההודעות שהתקבלו איתה. כפתורי תשובה בהודעה שנשלחה לפני 'קישור חדש' כבר לא פועלים. תשובה שמנהל לקח לפני יותר מ-15 דקות אפשר להעביר לאחר. תבניות הודעה דוחות גם כתובת אתר ללא http שאחריה נתיב. מיגרציה אוטומטית אחת מוסיפה עמודה לטבלת ההודעות היוצאות.

### How to use - איך משתמשים
- **English:** Vendor page look: Settings > service management > General > handlers page (light is the default). The quote card needs no switch. Rollback: revert the release; the two migrations only add a table and a column, which an older version ignores.
- **עברית:** מראה דף הספק: הגדרות > ניהול השירות > כללי > דף המטפלים (ברירת המחדל בהיר). כרטיס ההצעה לא דורש הפעלה. החזרה לאחור: החזרת הגרסה; שתי המיגרציות רק מוסיפות טבלה ועמודה, שגרסה ישנה מתעלמת מהן.
