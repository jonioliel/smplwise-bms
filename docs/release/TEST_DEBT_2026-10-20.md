## Result

The "67 unit-spec failures that also fail on 2.9.2 main" were a **harness fault**, not 67 product bugs. The pre-gate job (`fe293.sh`) runs every
`tests/unit-*` file with `playwright.unit.config.ts`, which is node-only and has no `baseURL`. 18 of those files drive the real app
(`page.goto('/...')`), so each of their tests failed with `page.goto: Protocol error (Page.navigate): Cannot navigate to invalid URL`.
One further failure was a real (stale-state) test bug.
