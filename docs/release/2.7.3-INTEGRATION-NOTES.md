1. The kill-switch route is a new remote-reachable, authority-removing endpoint. A compromised administrator session could switch the
   extended mode off (denial of service of the feature, not an escalation); it is audited (`identity.service_identity.kill_switch`).
2. VU-F4 gives Office scans their own public slot: the public decode capacity is now the shared slot plus the Office slot (bounded, one each).
   Load behaviour NOT_RUN.
3. F3 / F4 of the claim review remain open product decisions; handler-page prefill (F1) is live without a switch.
4. UI bundles in `smplwise_vms/www` / `www-public` are not rebuilt on this branch (the lead builds); none of the three branches changes UI
   source.
5. All branches were cut before the lead's later main changes; drift is covered only by the targeted runs and the lead's gate.
