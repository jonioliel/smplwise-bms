### The migration-number rule (confirm before tagging)

`db.py` records a migration by its INTEGER version only. A pilot build that ran a provisional file recorded its number; on that database the final
file with the same number is skipped for good, with no error. Before upgrading any database that ever ran one of these pilot branches:
`SELECT max(version) FROM schema_migrations` must be **<= 151**. A clean install and every 2.14.0 database are fine.
