## Visible changes without a switch

- Generator settings, routing section: a collapsed explainer "how a critical alert escalates" (read-only, he / en / ar / ru).
- Elevator alert settings: WhatsApp is offered as a channel (unchecked; the GET answer carries `can_whatsapp`).
- 2.20.0 gate fixes (FIX2200, also in 2.20.0): the emergency-grant expiry date input follows the date-format language; the lead-logo row fades as a whole on scroll; the schedules rows view takes no more rows a page than fit the screen.

## Behaviour changes

- WisKey direct join (only while the direct path is selected: `auto` + signing key + authenticated socket): a command is written only when the CURRENT connection's `direct/capabilities` lists it and `direct/time` admits Arx's signing window (WKR5 unit A). The signed envelope kind comes from the round-5 catalog. The five HA-body audio commands and `jobs/approval_decide` / `jobs/approval_request` are refused `not_sent` before any byte.
- Emergency (only while the capture lease route is on, which it cannot be in this build): a real emergency OPEN or LOCK revokes every live capture lease (reason `emergency`, scope `all`, audited, idempotent); while an OPEN is in effect a capture start is refused 409 `capture_lease_emergency`; a sweep at each lease-worker round closes the race gap. Drills never act. The door action is never blocked by a lease-side failure.
- WisKey peer reads: the query owner may be the direct service subject `arx-service:<entry>` as well as an HA user id (one rule for attestation, owner pin, binding row and mint).
- WisKey talk (WK4ADOPT W-002): no periodic `talk_floor` heartbeat while a talk is open; Arx's 30 s idle timer of a muted talk is re-armed only by a verified 800-byte PCMU packet. Against an older WisKey a muted talk ends with `idle_timeout` after 12 s.
- WisKey media (ASGI-295 via WK4ADOPT): a server cancel after the talk opened is audited `ended`; the station sound is published only after a confirmed permission; shutdown cancels and awaits the daily backup loop; `w10.listed` accepts the feed's projected command set.
