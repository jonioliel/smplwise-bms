## English
Added: phone-app push about service requests ("Status updated", "Note added"; requester and internal assignee, never the actor, an internal note never reaches
the requester); an electricity bill-draft notification (`energy.bill_draft`, once per automatic draft, period only); a live bill state route with revision and ETag;
rate limits for bill recalculation and PDF render (429 with `retry_after_s`). Tests only: personal per-camera permissions x shared spaces matrix.
How to enable: the new service-request sources appear in the notification matrix per user; the electricity bill-draft source appears only with billing accounts;
nothing else to enable. No bridge update, no restart.
