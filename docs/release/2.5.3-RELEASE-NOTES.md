### What was fixed - מה תוקן
- **English:** The public handler-page address can be saved from a local session; in a remote session the other tickets settings save normally and the address is read-only with an explanation. Details: only the public keys (address, trusted proxies, client-address header) are local-only; a remote PUT that touches one of them is refused whole (403 `local_only`, no partial write) with a clear message, every other key saves through the remote channel; the address probe and the key rotation stay local-only. In a remote session the card shows the address, the check button and the proxy fields read-only with one line "זמין רק בגישה מקומית (דרך Home Assistant)", and a failed save of the address shows the server's message next to the field instead of only at the top of the page.
- **עברית:** תוקנה שמירת הכתובת הציבורית: כתובת הדף הציבורי נשמרת בגישה מקומית, ובגישה מרחוק ההגדרות האחרות ממשיכות להישמר והשדה מוצג לקריאה בלבד עם הסבר. פרטים: רק המפתחות הציבוריים (כתובת, פרוקסי מהימנים, כותרת כתובת הלקוח) מותרים בגישה מקומית בלבד; שמירה מרחוק שנוגעת באחד מהם נדחית כולה (403 `local_only`, בלי כתיבה חלקית) עם הודעה ברורה, וכל שאר המפתחות נשמרים דרך הערוץ המרוחק; בדיקת הכתובת והחלפת המפתח נשארות מקומיות בלבד. בגישה מרחוק הכרטיס מציג את הכתובת, כפתור הבדיקה ושדות הפרוקסי לקריאה בלבד עם שורה אחת "זמין רק בגישה מקומית (דרך Home Assistant)", ושמירה שנכשלה של הכתובת מציגה את הודעת השרת ליד השדה ולא רק בראש העמוד.

### How to use - איך משתמשים
- **English:** to set the public address open the system from Home Assistant (or the local network), Settings › the module › General › "דף המטפלים", type the address, press "שמירה", then "בדיקת כתובת". Rollback: revert the release; no data format changed.
- **עברית:** כדי להגדיר את הכתובת הציבורית פותחים את המערכת מתוך Home Assistant (או מהרשת המקומית), הגדרות › המודול › כללי › "דף המטפלים", מקלידים את הכתובת, לוחצים "שמירה" ואז "בדיקת כתובת". החזרה לאחור: החזרת הגרסה; שום פורמט נתונים לא השתנה.
