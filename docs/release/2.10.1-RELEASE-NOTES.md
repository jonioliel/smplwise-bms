# SmplWise Arx 2.10.1 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.10.1, bilingual per item). The merge order, the conflict
decision and the checks are in 2.10.1-INTEGRATION-NOTES.md. Fakes only on the WisKey and access side.

## 2.10.1 (pilot) — Settings navigation on phones as a personal choice (tab row or dropdown); a startup fix so the temperature report and the identity / access messaging uses always appear in the messaging accounts screen; the microphone permission follows the features that use it; Arabic and Russian words of the vendor page load on demand; tickets.directory also opens the external-access identity card; per-widget failure panels on the home screen; WisKey access_state parser (v1 + v2) on fakes; test hygiene
**After installing:** no database migration (the last one stays 0135); reload the web app once. The add-on restarts itself.
- **עברית:** אחרי ההתקנה: בלי מיגרציה של מסד הנתונים (האחרונה נשארת 0135); לטעון מחדש את אפליקציית הרשת פעם אחת. התוסף מופעל מחדש לבד.

### What was changed - מה השתנה
- **English:** Settings navigation on phones (personal preference): a new personal choice "settings navigation on phones" - the sub-pages of a settings area as the tab row (default) or as one dropdown (44 px chip and rows). Stored per user in the personal preferences (`ui.dd_settings_nav`, presentation only, no migration); no hint text on the screen.
- **עברית:** ניווט בהגדרות בטלפון (העדפה אישית): בחירה אישית חדשה "ניווט הגדרות בטלפון" - תתי-הדפים של אזור הגדרות כשורת לשוניות (ברירת מחדל) או כתפריט נפתח אחד (שבב ושורות של 44 פיקסלים). נשמר לכל משתמש בהעדפות האישיות (`ui.dd_settings_nav`, תצוגה בלבד, בלי מיגרציה); בלי טקסט הסבר במסך.
- **English:** Messaging accounts screen: the temperature report use and the identity / access uses (local reset, access grants) now join the messaging registry at startup, so the screen no longer shows or omits them depending on what ran since the restart. The temperature report use is active only while a temperature unit exists.
- **עברית:** מסך חשבונות ההודעות: שימוש דוח הטמפרטורה והשימושים של זהות / גישה (איפוס מקומי, הרשאות גישה) מצטרפים עכשיו לרישום ההודעות בעליית המערכת, כך שהמסך כבר לא מציג או מסתיר אותם לפי מה שרץ מאז ההפעלה. שימוש דוח הטמפרטורה פעיל רק כשקיימת יחידת טמפרטורה.
- **English:** Remote channel: the Permissions-Policy of the remote document allows the microphone only while a feature that uses it is on (Arx push-to-talk, or the embedded WisKey panel reachable); otherwise the microphone is off. The camera part, the Ingress channel and the public listener are unchanged.
- **עברית:** ערוץ מרוחק: מדיניות ההרשאות של המסמך המרוחק מתירה מיקרופון רק כשפיצ'ר שמשתמש בו פעיל (לחץ-ודבר של Arx, או פאנל WisKey משובץ זמין); אחרת המיקרופון כבוי. חלק המצלמה, ערוץ ה-Ingress והמאזין הציבורי ללא שינוי.
- **English:** Vendor page: the Arabic and Russian words load on demand (Hebrew and English stay in the bundle); a page in those languages waits for its words, falls back to the same-direction text if the load fails; the ticket page bundle drops from 62.7 KB to 52.1 KB gzip.
- **עברית:** דף הספק: המילים בערבית וברוסית נטענות לפי דרישה (עברית ואנגלית נשארות בחבילה); דף בשפות האלה ממתין למילים שלו, ובכשל טעינה חוזר לטקסט באותו כיוון; חבילת דף הבקשה יורדת מ-62.7 ל-52.1 KB (gzip).
- **English:** Permissions: `tickets.directory` also opens the external-access identity card, the grants CSV export and link / unlink (either `tickets.configure` or `tickets.directory`); delete-person still needs the grant permission. No new permission name, no migration.
- **עברית:** הרשאות: `tickets.directory` פותחת גם את כרטיס הזהות של הגישה החיצונית, ייצוא ה-CSV של ההרשאות וקישור / ניתוק (די ב-`tickets.configure` או ב-`tickets.directory`); מחיקת אדם עדיין דורשת את הרשאת הגישה. בלי שם הרשאה חדש ובלי מיגרציה.
- **English:** Home screen: each widget draws its own failure panel (the media widget no longer hides a failed read); the users list shows name and username once; the WisKey frame has a settle timeout with he / en / ar / ru words.
- **עברית:** מסך הבית: כל וידג'ט מציג לוח כשל משלו (וידג'ט המדיה כבר לא מסתיר קריאה שנכשלה); רשימת המשתמשים מציגה שם ושם משתמש פעם אחת; למסגרת WisKey יש זמן המתנה מוגבל עם מילים בעברית / אנגלית / ערבית / רוסית.
- **English:** WisKey (Arx side, fakes only): one strict `access_state` parser for v1 and v2 used by the engine and the access-request consumer, with table-driven tests (80+ malformed cases, version dispatch without fallback); `GO_LIVE_PERMITTED` stays False and the WisKey switches stay OFF.
- **עברית:** WisKey (צד Arx, תחליפים בלבד): מנתח `access_state` קפדני אחד ל-v1 ול-v2 שמשמש את המנוע ואת צרכן בקשות הגישה, עם בדיקות מבוססות טבלה (מעל 80 מקרים פגומים, בחירת גרסה בלי נפילה לאחור); `GO_LIVE_PERMITTED` נשאר False ומתגי WisKey נשארים כבויים.
- **English:** Tests only: the messaging registry is isolated per test, the payment plan is built at call time, the alert stream is quiet in tests, the sweep bound scales with the load.
- **עברית:** בדיקות בלבד: רישום ההודעות מבודד לכל בדיקה, תוכנית התשלום נבנית בזמן הקריאה, זרם ההתראות שקט בבדיקות, גבול הסריקה גדל עם העומס.

### Bugs fixed - באגים שתוקנו
- **English:** Messaging accounts: the temperature report and identity / access uses were shown or omitted depending on which module had been imported since the restart.
- **עברית:** חשבונות הודעות: שימוש דוח הטמפרטורה ושימושי הזהות / גישה הוצגו או הוסתרו לפי המודול שנטען מאז ההפעלה.
- **English:** Home screen: a failed media read hid the media widget instead of showing its failure panel.
- **עברית:** מסך הבית: קריאת מדיה שנכשלה הסתירה את וידג'ט המדיה במקום להציג את לוח הכשל שלו.
- **English:** Remote channel: the microphone was always allowed in the remote document policy.
- **עברית:** ערוץ מרוחק: המיקרופון הותר תמיד במדיניות המסמך המרוחק.

### What is OFF by default and how to enable - מה כבוי כברירת מחדל ואיך מפעילים
- **English:** No new switch. The personal choice is under Settings › personal preferences (settings navigation on phones). Everything that was OFF or locked in 2.10.0 stays OFF or locked; the WisKey switches stay OFF.
- **עברית:** אין מתג חדש. הבחירה האישית נמצאת בהגדרות › העדפות אישיות (ניווט הגדרות בטלפון). כל מה שהיה כבוי או נעול ב-2.10.0 נשאר כבוי או נעול; מתגי WisKey נשארים כבויים.

### Known limits - מגבלות ידועות
- **English:** Everything new on the WisKey and access side was tested with fakes only. The phone-only settings dropdown reverted in 2.10.0 is replaced by the personal choice above (default: the tab row, no phone-only gate). ENTIDSWEEP-295 and SECFIX2-RED-295 are not in this release.
- **עברית:** כל החדש בצד WisKey והגישה נבדק עם תחליפים בלבד. התפריט הנפתח של ההגדרות לטלפון בלבד שהוחזר לאחור ב-2.10.0 הוחלף בבחירה האישית שלמעלה (ברירת מחדל: שורת לשוניות, בלי שער לטלפון בלבד). ENTIDSWEEP-295 ו-SECFIX2-RED-295 לא בגרסה הזו.
