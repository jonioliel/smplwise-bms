## Visible changes without a switch

- Schedules (table, cards), automations (rows, cards) and scripts show only as many items per page as fit the screen height; the page size settings are the maximum (`?fit=off` disables the fit for a page).
- A compact media card on the home screen; legible choice buttons in the dark theme.

## Behaviour changes

- New routes `GET` and `PUT /notices/tv-defaults` (`notices.boards`; the GET rides the existing settings read). A board without its own value in its display JSON follows the installation default.
