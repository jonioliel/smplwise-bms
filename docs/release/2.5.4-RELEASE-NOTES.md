The module stays OFF by default and nothing changes for an installation that has not switched it on; an address without a prefix behaves exactly as before. **Fakes and fixtures only: nothing here sent a real message or contacted a device.**
- **עברית:** אחרי ההתקנה: **אין מיגרציה של מסד הנתונים** (הרצף נשאר 0001..0084 ללא פערים). **אין שינוי בגשר** (0.8.0). **אין אפשרות תוסף חדשה.** יש לרענן את היישום המותקן פעם אחת. המודול נשאר כבוי כברירת מחדל ושום דבר לא משתנה בהתקנה שלא הפעילה אותו; כתובת בלי נתיב מתנהגת בדיוק כמו קודם. **רק דמויות ופיקסצ'רים: דבר מכל זה לא שלח הודעה אמיתית ולא פנה להתקן.**

### What was added - מה נוסף
- **English:** The public address of the handler page may include one path prefix such as `/support` (`https://ecc.smplwise.com/support`): lower-case letters, digits and hyphen, 2 to 32 characters, a single segment; still https, a DNS name, port 443, no query, fragment, user info or IP literal. Vendor links are built with it (`<address>/support/#<token>`, e-mail `<address>/support/r/<id>`; without a prefix they stay `/t/...`), the token stays in the fragment, and the address check requests the prefixed path and reports a 404 as "not routed to the handler page". The listener itself is unchanged and serves only `/t/...`: Cloudflare maps `/support` to `/t` at the edge (rewrite rule and tunnel route in the guide; the rewrite-before-tunnel ordering is UNVERIFIED until the address check passes on the owner's setup).
- **עברית:** הכתובת הציבורית של דף המטפלים יכולה לכלול נתיב אחד, למשל `/support` (`https://ecc.smplwise.com/support`): אותיות קטנות באנגלית, ספרות ומקף, 2 עד 32 תווים, מקטע אחד; עדיין https, שם DNS, פורט 443, בלי שאילתה, קטע מזהה, פרטי משתמש או כתובת IP. הקישורים לספקים נבנים איתו (`<כתובת>/support/#<אסימון>`, בדואר `<כתובת>/support/r/<מזהה>`; בלי נתיב הם נשארים `/t/...`), האסימון נשאר בקטע המזהה, ובדיקת הכתובת פונה לנתיב עם הקידומת ומדווחת 404 כ"הכתובת לא מנותבת לדף המטפלים". השרת הציבורי עצמו לא השתנה ומשרת רק `/t/...`: Cloudflare ממפה את `/support` ל-`/t` בקצה (כלל Rewrite ומסלול מנהרה במדריך; סדר שכתוב-לפני-מנהרה לא אומת עד שבדיקת הכתובת מצליחה אצל הבעלים).

### How to use - איך משתמשים
- **English:** Settings › the module › General › "דף המטפלים": type `https://ecc.smplwise.com/support`, save, check the address (the card shows a sample link). In Cloudflare: Rewrite URL for host `ecc.smplwise.com` with path starting `/support/` to `concat("/t/", substring(http.request.uri.path, 9))`, and a tunnel route `^/t(/.*)?$` to `http://<add-on host>:18093` placed before the empty-path Home Assistant route. Rollback: revert the release (clear the prefix first); no data format changed.
- **עברית:** הגדרות › המודול › כללי › "דף המטפלים": מקלידים `https://ecc.smplwise.com/support`, שומרים ובודקים את הכתובת (הכרטיס מציג קישור לדוגמה). ב-Cloudflare: Rewrite URL לשם המארח `ecc.smplwise.com` כשהנתיב מתחיל ב-`/support/` אל `concat("/t/", substring(http.request.uri.path, 9))`, ומסלול מנהרה `^/t(/.*)?$` אל `http://<כתובת התוסף>:18093` לפני מסלול ה-Home Assistant ללא נתיב. החזרה לאחור: החזרת הגרסה (קודם מנקים את הנתיב מהכתובת); שום פורמט נתונים לא השתנה.
