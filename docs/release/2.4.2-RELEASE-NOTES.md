## 2.4.2 (pilot) — curved walls in Plan Studio, sign-in and alarm-code block counters survive a restart
**2.4.2 contains everything of the withdrawn 2.4.1 (section below): two migrations, 0071 (SEC3 block counters) and 0072 (Frigate write class `config`); bridge 0.8.0 - update the bridge and RESTART Home Assistant.**
**ב־2.4.2 כלול כל מה שהיה ב־2.4.1 שלא שוחררה (הסעיף שמתחת): שתי מיגרציות, 0071 (מוני חסימה) ו־0072 (מחלקת כתיבה `config` של Frigate); גשר 0.8.0 - מעדכנים את הגשר ו*מפעילים מחדש את Home Assistant*.**
**After installing:** **one database migration, 0071** (adds the table `block_counters`; additive, the previous version ignores it; the sequence is now 0001..0072 without gaps). Plans that use a curved wall are stored as schema 2.1 and an older Arx **refuses** to import such a plan; plans without curved walls stay byte for byte as before. Reload the installed web app once. Nothing new is switched on by itself.
- **עברית:** אחרי ההתקנה: **מיגרציה אחת, 0071** (מוסיפה את הטבלה `block_counters`; תוספתית, הגרסה הקודמת מתעלמת ממנה; הרצף עכשיו 0001..0072 בלי חורים). תוכניות עם קיר מעוקל נשמרות כסכמה 2.1, ו־Arx ישן **דוחה** ייבוא של תוכנית כזו; תוכניות בלי קירות מעוקלים נשארות זהות בייטים לפני כן. טוענים מחדש את אפליקציית הרשת פעם אחת. דבר לא מופעל מעצמו.

### Curved walls (WALLC2) - קירות מעוקלים
- **English - what was added:** walls in Plan Studio can be curved. Structure tool (desktop): Curve mode (`C`) - drag a segment's middle handle to bend it, set or clear a segment radius in the wall panel, round a corner with a radius; Arc wall mode - start, end and a point on the arc; "straighten". A wall keeps its corner points and carries one DXF-style bulge per segment (`walls[].bulges`, `|bulge| <= 4`). Doors and windows sit on curved walls by arc length; window walls (glass) may be curved too (glazing divides the exact arc length). Drawing points snap onto an arc's body; the wall panel shows the floor area of a closed outline (a round room counts). The map, 3D (curved joints mitred), SVG / PNG exports, the signed package, diff, re-crop and shared rooms all follow the arc. DXF export writes bulged LWPOLYLINEs (glass on `SW_GLAZING`); DXF import turns bulged centre lines, concentric arc pairs and arcs on wall layers into curved wall candidates and hosts door swing arcs / window lines on them.
- **English - limits:** the editor is desktop-only (the phone shows the desktop-only state; the floor map draws the arcs). Zones are not derived from closed curved walls (they stay drawn polygons). Library objects do not snap to walls. A dragged corner keeps the segment's bulge (the angle), not its radius. An older Arx refuses a 2.1 plan (`package_doc_version`); a stale editor tab draws chords. A small cosmetic step shows in the shadow under the free end of a curved wall.
- **English - how to use:** Plan Studio › structure tool › press `C` (Curve mode) or choose Arc wall; select a wall and set a radius in the wall panel. Design note: `docs/architecture/CURVED_WALLS.md`.
- **עברית - מה נוסף:** אפשר לעקם קירות ב־Plan Studio. כלי המבנה (מחשב): מצב עיקום (`C`) - גוררים את ידית האמצע של קטע כדי לכופף אותו, קובעים או מנקים רדיוס לקטע בלוח הקיר, מעגלים פינה ברדיוס; מצב קיר קשת - התחלה, סוף ונקודה על הקשת; "ישור". קיר שומר את נקודות הפינה ונושא bulge אחד בסגנון DXF לכל קטע (`walls[].bulges`, `|bulge| <= 4`). דלתות וחלונות יושבים על קירות מעוקלים לפי אורך קשת; גם קירות חלונות (זכוכית) יכולים להיות מעוקלים (הזיגוג מחלק את אורך הקשת המדויק). נקודות ציור נצמדות לגוף הקשת; לוח הקיר מציג את שטח הרצפה של מתאר סגור (חדר עגול נחשב). המפה, תלת־ממד (חיבורים מעוקלים בחיתוך זווית), ייצוא SVG / PNG, החבילה החתומה, השוואה, חיתוך מחדש וחללים משותפים עוקבים כולם אחר הקשת. ייצוא DXF כותב LWPOLYLINE עם bulge (זכוכית ב־`SW_GLAZING`); ייבוא DXF הופך קווי מרכז עם bulge, זוגות קשתות קונצנטריים וקשתות בשכבות קירות למועמדי קיר מעוקל, ומארח עליהם קשתות סחרור של דלתות וקווי חלונות.
- **עברית - מגבלות:** העורך למחשב בלבד (הטלפון מציג מצב "מחשב בלבד"; מפת הקומה מציירת את הקשתות). אזורים לא נגזרים מקירות מעוקלים סגורים (נשארים מצולעים מצוירים). אובייקטי ספרייה לא נצמדים לקירות. גרירת פינה שומרת את ה־bulge של הקטע (הזווית) ולא את הרדיוס. Arx ישן דוחה תוכנית 2.1 (`package_doc_version`); לשונית עורך ישנה מציירת מיתרים. מדרגה קוסמטית קטנה נראית בצל מתחת לקצה החופשי של קיר מעוקל.
- **עברית - איך משתמשים:** Plan Studio › כלי המבנה › מקש `C` (מצב עיקום) או בחירת קיר קשת; בוחרים קיר וקובעים רדיוס בלוח הקיר. מסמך תכן: `docs/architecture/CURVED_WALLS.md`.

### Sign-in and alarm-code block counters persist (SEC3) - מוני החסימה של כניסה וקוד אזעקה נשמרים
- **English - what changed:** the remote sign-in / second-factor rate limiter and the wrong alarm-code window were in memory only, so an add-on restart cleared a lockout in progress (security review 2.2.0, finding L4). They are now stored in the table `block_counters` (migration 0071): the sign-in limiter is written behind by the janitor and at shutdown and restored at start; the wrong-code window is stored with each wrong code and read once per key after a restart; an explicit alarm lockout reset wipes stored windows too. The TOTP lockout was already persisted by 0069. No visible change; the table holds only a scope, an address or user / panel id and attempt instants (no code, secret or token).
- **English - limits / rollback:** a sign-in attempt in the last seconds before a crash may not be stored (write-behind); the table is ignored by the previous version (rollback = counters live in memory again).
- **עברית - מה השתנה:** מגביל הקצב של כניסה מרחוק / גורם שני וחלון קוד האזעקה השגוי היו בזיכרון בלבד, ולכן הפעלה מחדש של התוסף ניקתה נעילה שהייתה בעיצומה (סקירת אבטחה 2.2.0, ממצא L4). עכשיו הם נשמרים בטבלה `block_counters` (מיגרציה 0071): מגביל הכניסה נכתב בדיחוי על ידי ה־janitor ובכיבוי ומשוחזר בעלייה; חלון הקוד השגוי נשמר עם כל קוד שגוי ונקרא פעם אחת לכל מפתח אחרי הפעלה מחדש; איפוס נעילת אזעקה מפורש מוחק גם חלונות שמורים. נעילת ה־TOTP כבר נשמרה ב־0069. אין שינוי גלוי; הטבלה מחזיקה רק סוג, כתובת או מזהה משתמש / לוח וזמני ניסיון (בלי קוד, סוד או אסימון).
- **עברית - מגבלות / חזרה אחורה:** ניסיון כניסה בשניות האחרונות לפני קריסה עלול לא להישמר (כתיבה בדיחוי); הטבלה לא נקראת בגרסה הקודמת (חזרה אחורה = המונים שוב בזיכרון).
