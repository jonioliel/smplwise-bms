# SmplWise Arx 2.4.5 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.4.5, bilingual per item).

## 2.4.5 (pilot) — Crystal skin and background setting, "turn all on", sticky 3D view mode, floor and area pickers, home and security screens polish, security review 2.4.2 L1 / L3
**After installing:** **no database migration** (the sequence stays 0001..0073), **no bridge change** (0.8.0 stays; no restart of the system infrastructure is needed for this release). Reload the installed web app once. Nothing new is switched on by itself: the skin stays the one chosen (classic by default), the background setting only shows in the Crystal skin, the 3D view mode default is "automatic" (the earlier behaviour).
- **עברית:** אחרי ההתקנה: **אין מיגרציה** (הרצף נשאר 0001..0073), **אין שינוי בגשר** (נשאר 0.8.0; אין צורך להפעיל מחדש את תשתית המערכת בגרסה זו). טוענים מחדש את אפליקציית הרשת פעם אחת. דבר חדש לא מופעל מעצמו: הסגנון נשאר זה שנבחר (קלאסי כברירת מחדל), הגדרת הרקע פועלת רק בסגנון קריסטל, ברירת המחדל של מצב התצוגה בתלת־ממד היא "אוטומטי" (ההתנהגות הקודמת).

### Crystal skin and the background behind the glass (CRY) - סגנון קריסטל והרקע מאחורי הזכוכית
- **English - what was added:** a fifth skin, "Crystal": luminous glass panels on a pearl (light) / indigo (dark) canvas, a sapphire accent, the building tree kept prominent, solid fallbacks when the browser has no backdrop blur or the user asks for reduced transparency. With it a background setting: the built-in day / night artworks (drawn for the product, chosen by the light / dark scheme), none, or the installation's own pictures (one for day, one for night; PNG, JPG or WebP up to 12 MB, re-encoded by the server; when one is missing the other serves both). Each user may override the installation's choice for themselves. Settings `ui.skin` = `crystal`, `ui.background` (builtin | none | custom, `system.configure`, audited, in the backup together with the uploaded pictures); personal `ui.background` in /me/prefs (null = like the system). New API `GET / POST / DELETE /settings/background/{day|night}`.
- **English - how to use:** Settings › General › "System look" › Style: Crystal › Save; then the "Background" row (administrator) - built-in, none, or "My pictures" with the day / night upload slots; "My background" sets your own choice on every device ("Like the system" clears it).
- **עברית - מה נוסף:** סגנון חמישי, "קריסטל": לוחות זכוכית זוהרים על משטח פנינה (בהיר) / אינדיגו (כהה), צבע הדגשה ספיר, עץ הבניין בולט, וגיבוי אטום כשהדפדפן לא תומך בטשטוש רקע או כשהמשתמש ביקש פחות שקיפות. ואיתו הגדרת רקע: יצירות היום / לילה המובנות (צוירו למוצר, מתחלפות לפי בהיר / כהה), ללא, או התמונות של ההתקנה (אחת ליום ואחת ללילה; PNG, JPG או WebP עד 12 MB, השרת מקודד אותן מחדש; כשחסרה אחת השנייה משמשת לשתיהן). כל משתמש יכול לבחור לעצמו במקום בחירת ההתקנה. ההגדרות `ui.skin` = `crystal`, `ui.background` (builtin | none | custom, `system.configure`, נרשם ביומן, בגיבוי יחד עם התמונות שהועלו); אישית `ui.background` ב־/me/prefs (ריק = כמו המערכת). API חדש `GET / POST / DELETE /settings/background/{day|night}`.
- **עברית - איך משתמשים:** הגדרות › כללי › "מראה המערכת" › סגנון: קריסטל › שמור; אחר כך השורה "רקע" (מנהל) - מובנה, ללא, או "תמונות שלי" עם משבצות ההעלאה ליום וללילה; "הרקע אצלי" קובע בחירה אישית בכל מכשיר ("כמו המערכת" מבטל).

### "Turn all on" next to "turn all off" (ALLON) - "הדלק הכל" ליד "כבה הכל"
- **English - what was added:** on the area screen the lighting and switches sections have "Turn all on" (bolt icon) beside "Turn all off", same size and look; it shows only while the section holds a device of its kind that is off, available and not protected. The floor / area "⋯" menu gains "Turn lights on" under "Turn lights off". Same server path as turn-all-off: a preview with the count, one confirmation, the server re-checks the list at confirmation, protected switches (CR-019) are never included, one audit row. Climate and media stay off-only.
- **English - bugs fixed:** the "nothing to do" refusal and the result notes use words that are true for an "on" action.
- **English - how to use:** open an area › Lighting or Switches › "Turn all on" › confirm.
- **עברית - מה נוסף:** במסך האזור, בחלקי "תאורה" ו"מתגים", יש "הדלק הכל" (סמל ברק) ליד "כבה הכל", באותו גודל ומראה; הוא מופיע רק כשיש בחלק התקן מהסוג הזה שכבוי, זמין ולא מוגן. בתפריט "⋯" של קומה ואזור נוסף "הדלק תאורה" מתחת ל"כבה תאורה". אותו מסלול בשרת כמו "כבה הכל": תצוגה מקדימה עם המספר, אישור אחד, השרת בודק שוב את הרשימה ברגע האישור, מתגים מוגנים (CR-019) לעולם לא נכללים, שורת יומן אחת. מיזוג ומסכים נשארים עם כיבוי בלבד.
- **עברית - תיקונים:** הודעת "אין מה לעשות" והערות התוצאה מנוסחות נכון גם לפעולת הדלקה.
- **עברית - איך משתמשים:** פותחים אזור › תאורה או מתגים › "הדלק הכל" › מאשרים.

### The 3D view mode sticks (PLANMODE) - מצב התצוגה בתלת־ממד נשאר
- **English - bugs fixed:** on the floor map in 3D a chosen "Full" mode jumped back to "Schematic" after about half a minute on a slower device ("dropped to schematic, the frame rate was low"). Now only "Automatic" drops to schematic, and only after a sustained low frame rate (2.5 s, with hysteresis); a chosen "Full" stays and shows a small non-blocking hint with a one-tap "Switch to schematic".
- **English - what was added:** three modes - automatic / full / schematic. An installation default (`plan.quality`: auto | 2 | 1, default auto, `system.configure`, audited) and a personal mode (`plan.quality` in /me/prefs, null = follow the installation, no permission needed); the 3D toolbar chips write the personal mode, so the choice survives a reload and follows the user to other browsers.
- **English - how to use:** Settings › General › "Default view mode" (administrator) and "My view mode" (every user); or pick Schematic / Full / Automatic on the 3D toolbar.
- **עברית - תיקונים:** במפת הקומה בתלת־ממד, מצב "מלא" שנבחר קפץ חזרה ל"סכמטי" אחרי כחצי דקה במכשיר איטי ("ירד לסכמטי, קצב הפריימים נמוך"). עכשיו רק "אוטומטי" יורד לסכמטי, ורק אחרי קצב פריימים נמוך לאורך זמן (2.5 שניות, עם שוליים); "מלא" שנבחר נשאר ומציג הערה קטנה שלא חוסמת עם מעבר לסכמטי בלחיצה אחת.
- **עברית - מה נוסף:** שלושה מצבים - אוטומטי / מלא / סכמטי. ברירת מחדל להתקנה (`plan.quality`: auto | 2 | 1, ברירת מחדל auto, `system.configure`, נרשם ביומן) ומצב אישי (`plan.quality` ב־/me/prefs, ריק = לפי ההתקנה, בלי הרשאה); הבחירה בסרגל התלת־ממד נשמרת כמצב האישי, ולכן נשארת אחרי טעינה מחדש ועוברת עם המשתמש לדפדפנים אחרים.
- **עברית - איך משתמשים:** הגדרות › כללי › "מצב תצוגה ברירת מחדל" (מנהל) ו"מצב התצוגה שלי" (כל משתמש); או בוחרים סכמטי / מלא / אוטומטי בסרגל התלת־ממד.

### Home and area polish, the floor and area pickers (HOME) - ליטוש הבית והאזור, בוחרי הקומה והאזור
- **English - what changed:** the area header is two comfortable pickers side by side - the floor and the area (the area picker is the page title, so the area's name is on the screen once); on a phone both lists open as a bottom sheet and the old chip row of areas is gone. The home, building, area and tiles-panel screens get a clearer hierarchy, focus rings on every row / tile / chip, reduced-motion-safe state transitions, skeleton loading states in the screen's own shape, a "Try again" button on load errors and shorter empty-state hints. No API change.
- **English - how to use:** open an area; tap the floor or the area picker in the header to move.
- **עברית - מה השתנה:** כותרת האזור היא שני בוררים נוחים זה לצד זה - הקומה והאזור (בורר האזור הוא כותרת הדף, כך ששם האזור מופיע פעם אחת); בטלפון שתי הרשימות נפתחות כגיליון תחתון ושורת השבבים של האזורים הוסרה. במסכי הבית, הבניין, האזור ולוח האריחים: היררכיה ברורה יותר, טבעות מיקוד על כל שורה / אריח / שבב, מעברי מצב שמכבדים "פחות תנועה", שלד טעינה בצורת המסך, כפתור "נסה שוב" בשגיאות טעינה והערות קצרות יותר במצב ריק. אין שינוי ב־API.
- **עברית - איך משתמשים:** פותחים אזור; לוחצים על בורר הקומה או האזור בכותרת כדי לעבור.

- **English - what changed:** the alarm screen (state card hierarchy, state-in motion, zone cards plus a list view, counts), the live tiles, wall, overview, camera and saved views (on-video HUD tokens, focus, keyboard-operable tiles, off states), the events and notification centres, the recorders card and camera health (state tokens, focus, empty and error states). ### Security review 2.4.2: L1 and L3 (SEC244) - סקירת אבטחה 2.4.2: L1 ו־L3
- **English - bugs fixed:** L1 - a reader from whom a plan reference is withheld (floor-scoped) is now handed the hash of the redacted document, not the stored one, in every place a plan hash is served (geometry reads, timeline, versions, publish / rollback, the floor bundle, the package preview / import, the skins keys), so the hash can no longer be used to guess the withheld part; unscoped readers keep the stored hash. L3 - a reference the writer was not shown is kept whatever they send; removing an item or panel that holds one warns (`anchor_hidden_removed`) and is audited; a package exported by a scoped person lists the redacted / withheld references in its signed manifest, and importing it gives them back from the current draft. No migration, no API shape change.
- **English - how to use:** nothing to switch on.
- **עברית - תיקונים:** L1 - קורא שמוסתרת ממנו הפניה בתוכנית (מוגבל לקומה) מקבל עכשיו את הגיבוב של המסמך המצונזר ולא של המסמך השמור, בכל מקום שבו מוגש גיבוב של תוכנית (קריאות הגאומטריה, ציר הזמן, הגרסאות, פרסום / שחזור, חבילת הקומה, תצוגה מקדימה / ייבוא של חבילה, מפתחות הסגנונות), כך שאי אפשר עוד לנחש מהגיבוב את החלק המוסתר; קורא בלי הגבלה מקבל את הגיבוב השמור. L3 - הפניה שלא הוצגה לכותב נשמרת מה שלא ישלח; הסרת פריט או לוח שמחזיקים הפניה כזו מציגה אזהרה (`anchor_hidden_removed`) ונרשמת ביומן; חבילה שיוצאה בידי משתמש מוגבל מפרטת את ההפניות המצונזרות / המוסתרות במניפסט החתום שלה, וייבוא שלה מחזיר אותן מהטיוטה הנוכחית. אין מיגרציה ואין שינוי במבנה ה־API.
- **עברית - איך משתמשים:** אין מה להפעיל.
