## English
See CHANGELOG 2.14.0 "What was added". Every new feature ships OFF. How to enable: `security.app_refresh` (lab only), `privacy.local_purge`,
`privacy.personal_export`, `quiet.windows.enabled`, `occupancy.enabled`, `water.enabled`, `reports.shift.enabled`,
`access.external.denied_alert`, `access.compliance_export` (compliance export, needs `access.events.export`), `nvr.privacy_mask_copy`
(mask copy plan, needs `nvr.config.privacy`), `ticket_acceptance_settings.enabled` + opted-in categories (smart acceptance; a table row, no route
or screen yet). The WisKey media provider is selected only when WisKey lists the W10 commands.
Known limits: refresh tokens are lab-only until the device-key binding; most server slices have no frontend yet. The compliance export has no
frontend and applies the WisKey schedules to every station in native mode. The mask copy is plan-only and never writes a device. The acceptance
engine handles temperature units only.

`privacy.personal_export`, `quiet.windows.enabled`, `occupancy.enabled`, `water.enabled`, `reports.shift.enabled`,

אין נתיב או מסך). ספק המדיה של WisKey נבחר רק כאשר WisKey מציג את פקודות W10.

את לוחות הזמנים של WisKey על כל העמדות במצב מקורי. העתקת המסכות היא תכנון בלבד ולעולם אינה כותבת למכשיר. מנוע הקבלה מטפל ביחידות
