### The migration-number rule (confirm before tagging; review B-1)

`db.py` records a migration by its INTEGER version only. The final numbers of this release are **0146..0151**. A pilot build that ran the
provisional files (0150 / 0152 / 0155 / 0160) on a real database recorded those numbers; on that database the final file with the same number
would be skipped for good, with no error (example: 0150 recorded from the pilot `0150_app_refresh_tokens` means `0150_infra_water.sql` never runs).
Before upgrading any database that ever ran a pilot build: `SELECT max(version) FROM schema_migrations` must be **<= 145**. If it is higher,
that database is fixed by hand before installing 2.14.0 (no code change: a clean install and every 2.12.x database are fine). The only
installed lab version is **2.12.1** (2.12.x ships migrations up to 0145, so the lab add-on is expected to pass; its database was not queried
for this note - run the check above before installing); the runner's test databases are created fresh per run.

## English
See CHANGELOG 2.14.0 "What was added". Every new feature ships OFF. How to enable: `security.app_refresh` (lab only), `privacy.local_purge`,
`privacy.personal_export`, `quiet.windows.enabled`, `occupancy.enabled`, `water.enabled`, `reports.shift.enabled`,
`access.external.denied_alert`, `access.compliance_export` (compliance export, needs `access.events.export`), `nvr.privacy_mask_copy`
(mask copy plan, needs `nvr.config.privacy`), `ticket_acceptance_settings.enabled` + opted-in categories (smart acceptance; a table row, no route
or screen yet). The WisKey media provider is selected only with `access.station_media_provider` = `auto` and while WisKey lists the W10
commands; it falls back to Arx's own station stream when WisKey's answer fails.
Known limits: refresh tokens are lab-only until the device-key binding; most server slices have no frontend yet. The compliance export has no
frontend and applies the WisKey schedules to every station in native mode. The mask copy is plan-only and never writes a device. The acceptance
engine handles temperature units only.
