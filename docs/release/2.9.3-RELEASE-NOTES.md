## 2.9.3 (pilot) — Temperature control phase 3 (health, door insight, duty cycle, early warning, maintenance, tickets, comparison, home widget, HACCP report); a generators home widget; the external-access screen (shared Arx + WisKey identity) with the manual access-request form; per-person permission overrides in the door-system write gate; the technician phone-verification message carries the short privacy notice; elevator doors drawn by state; page background and clock fixes; public-surface security fixes; a lighter release gate
**After installing:** **three automatic database migrations** (0125: temperature phase 3 - power sensor, insights, maintenance windows, escalation and ticket links, ALTERs plus two new tables; 0126: the external-access identity - read-back proof and name-drift digests on the access grants and person links, the "confirmed gone" closure table; 0127: the access-request form - purpose, internal notes and who asked on the grant, the privacy-notice table rebuilt with the same rows to accept a requester's tick; the sequence is 0001..0127, contiguous). No bridge change (still 0.9.2; no Home Assistant restart needed for this version). No new add-on option. Reload the installed web app once. The door-system write features and the extended service identity stay locked.
- **עברית:** אחרי ההתקנה: **שלוש מיגרציות אוטומטיות של מסד הנתונים** (0125: שלב 3 של הטמפרטורה - חיישן הספק, תובנות, חלונות תחזוקה, הסלמה וקישור לבקשות שירות, שינויי עמודות ושתי טבלאות חדשות; 0126: זהות הגישה החיצונית - הוכחת קריאה חוזרת ותקצירי שינוי שם על ההרשאות וקישורי האנשים, וטבלת סגירה "אושר שנעלם"; 0127: טופס בקשת הגישה - מטרה, הערות פנימיות ומי ביקש, וטבלת אישורי הודעת הפרטיות נבנית מחדש עם אותן שורות כדי לקבל אישור של המבקש; הרצף הוא 0001..0127, רציף). אין שינוי בגשר (עדיין 0.9.2; אין צורך להפעיל מחדש את מערכת הבית בגרסה הזו). אין אפשרות תוסף חדשה. יש לטעון מחדש פעם אחת את אפליקציית הרשת המותקנת. כתיבות מערכת הדלתות והזהות המורחבת נשארות נעולות.

### What was changed - מה השתנה
- **English:** Temperature control, phase 3 (migration 0125): sensor health (frozen value, gaps, noise), door-to-temperature correlation, compressor duty cycle from an optional power sensor (read only, never switched), an early warning of an approaching breach (switch OFF by default; lead time `predict_warn_min`, default 20 minutes), maintenance windows that pause warnings only, escalation, opening a service request from a unit, a comparison view, units grouped by floor, a home-screen temperatures widget and a HACCP-style report. Read-only towards devices.
- **עברית:** בקרת טמפרטורה, שלב 3 (מיגרציה 0125): תקינות חיישן (ערך קפוא, פערים, רעש), קשר בין פתיחות דלת לטמפרטורה, מחזור עבודה של המדחס מחיישן הספק אופציונלי (קריאה בלבד, לעולם לא מיתוג), התרעה מוקדמת על חריגה מתקרבת (כבויה כברירת מחדל; זמן התרעה `predict_warn_min`, ברירת מחדל 20 דקות), חלונות תחזוקה שעוצרים רק אזהרות, הסלמה, פתיחת בקשת שירות מיחידה, תצוגת השוואה, קיבוץ לפי קומה, ווידג'ט טמפרטורות במסך הבית ודוח בסגנון HACCP. קריאה בלבד מול המכשירים.
- **English:** Home screen, generators widget: shown only to a viewer who sees at least one generator; it lands last in the widget order (after the temperatures widget).
- **עברית:** מסך הבית, ווידג'ט גנרטורים: מוצג רק למי שרואה לפחות גנרטור אחד; הוא מתווסף אחרון בסדר הווידג'טים (אחרי ווידג'ט הטמפרטורות).
- **English:** Access control, the external-access screen ("גישת חוץ", migration 0126) and the access-control identity card of a directory person: grants with "Active - verified" only when the server stores read-back proof of the scope, name drift between Arx and WisKey, the manual "confirmed gone" closure (system administrator, evidence reference), a weekly digest. The manual "request external access" form (migration 0127): a second person must approve (except a system administrator; 403 `access_grant_self_approval`), a manager who may only request chooses from the external-entrance stations and the ticket's building (403 `access_grant_station_not_allowed`), purpose and internal notes, the requester may confirm the privacy notice. Nothing reaches WisKey while `access.external_grants` is off, and it cannot be turned on in this build.
- **עברית:** בקרת גישה, מסך "גישת חוץ" (מיגרציה 0126) וכרטיס זהות בקרת הגישה של אדם בספר הכתובות: הרשאות במצב "פעיל - מאומת" רק כשהשרת שומר הוכחת קריאה חוזרת של ההיקף, שינוי שם בין Arx ל-WisKey, סגירה ידנית "אושר שנעלם" (מנהל מערכת, אסמכתה), תקציר שבועי. טופס "בקשת גישה חיצונית" ידני (מיגרציה 0127): אדם שני חייב לאשר (חוץ ממנהל מערכת), מנהל שמותר לו רק לבקש בוחר מעמדות הכניסה לחיצוניים ומהבניין של הבקשה, מטרה והערות פנימיות, המבקש יכול לאשר את הודעת הפרטיות. שום דבר לא מגיע ל-WisKey כש-`access.external_grants` כבוי, ולא ניתן להפעיל אותו בגרסה הזו.
- **English:** Door system (WisKey) write gate: a person's own permission overrides (allow and deny) count as stations of that person; a manager scoped to one station can no longer change a person whose override sits on a station outside his chain. Unknown overrides refuse anyone not unrestricted.
- **עברית:** שער הכתיבה של מערכת הדלתות (WisKey): ההרשאות האישיות של אדם (התרה וחסימה) נחשבות עמדות של אותו אדם; מנהל של עמדה אחת כבר לא יכול לשנות אדם שיש לו הרשאה אישית בעמדה מחוץ לשרשרת שלו. הרשאות לא ידועות נדחות לכל מי שאינו בלתי מוגבל.
- **English:** Privacy: the technician-only phone-verification message carries the short privacy notice; the technician notice in its final wording in Hebrew, English, Arabic and Russian.
- **עברית:** פרטיות: הודעת אימות הטלפון שנשלחת רק לטכנאים כוללת את הודעת הפרטיות המקוצרת; הודעת הטכנאי בנוסחה הסופי בעברית, אנגלית, ערבית ורוסית.
- **English:** Security (public surfaces): the client address is taken from CF-Connecting-IP / X-Forwarded-For only when the peer is a trusted proxy; the remote channel answers 404 for source maps; opening a code-protected ticket link before the code records no "opened" line and no device row.
- **עברית:** אבטחה (ממשקים ציבוריים): כתובת הלקוח נלקחת מ-CF-Connecting-IP / X-Forwarded-For רק כשהעמית הוא פרוקסי מהימן; הערוץ המרוחק מחזיר 404 למפות מקור; פתיחת קישור בקשה מוגן בקוד לפני הקוד לא רושמת "נפתח" ולא שורת מכשיר.
- **English:** Tabs settings for every section: the tabs editor now also orders and hides the tabs of Multimedia, Infrastructure (including the electricity and generator page rows; Temperatures joins automatically) and Service requests (the external-access tab only when it is placed there).
- **עברית:** הגדרות לשוניות לכל האזורים: עורך הלשוניות מסדר ומסתיר עכשיו גם את הלשוניות של מולטימדיה, תשתיות (כולל שורות דפי החשמל והגנרטור; טמפרטורות מצטרפת אוטומטית) ובקשות שירות (לשונית הגישה החיצונית רק כשהיא ממוקמת שם).
- **English:** Release gate: evidence specs reviewed as not depending on the 1024 px band skip the tablet project in the release gate; the nightly still runs them all.
- **עברית:** שער השחרור: בדיקות תיעוד שנבדקו ואינן תלויות ברוחב 1024 מדלגות על הטאבלט בשער השחרור; הריצה הלילית עדיין מריצה את כולן.

### Bugs fixed - באגים שתוקנו
- **English:** The home clock froze while live data refreshed (its timer was re-armed after every render); one shared wall-clock ticker now drives the home clock, the ticket elapsed clocks and the relative times of the automations and notification settings.
- **עברית:** השעון במסך הבית קפא בזמן ריענון נתונים חיים (הטיימר שלו הופעל מחדש אחרי כל ציור); שעון משותף אחד מניע עכשיו את שעון הבית, שעוני הזמן שחלף בבקשות והזמנים היחסיים בהגדרות האוטומציות וההתראות.
- **English:** Elevators: doors are drawn closed while the car is in operation and open while it waits; a reporting door sensor wins.
- **עברית:** מעליות: הדלתות מצוירות סגורות כשהמעלית בפעולה ופתוחות כשהיא ממתינה; חיישן דלת שמדווח גובר.
- **English:** One page background on every screen: the glass screens (devices, schedules, automations, multimedia, service requests, notification settings, the notification centre) no longer paint a flat pale layer over the skin's page background.
- **עברית:** רקע דף אחד בכל המסכים: מסכי הזכוכית (מכשירים, תזמונים, אוטומציות, מולטימדיה, בקשות שירות, הגדרות התראות, מרכז ההתראות) כבר לא מציירים שכבה בהירה אחידה מעל רקע הדף של הערכה.
- **English:** Opening a drawer or the home tiles panel no longer shifts or re-packs the page behind it (a shared scroll lock keeps the scrollbar gutter; the home layout is frozen while the panel is open).
- **עברית:** פתיחת מגירה או לוח האריחים בבית כבר לא מזיזה או מסדרת מחדש את הדף שמאחור (נעילת גלילה משותפת שומרת את מקום פס הגלילה; פריסת הבית קפואה כל עוד הלוח פתוח).
- **English:** Temperature drawer, wizard and report show friendly sensor names only (never an entity id) and no longer overflow sideways.
- **עברית:** מגירת הטמפרטורה, האשף והדוח מציגים רק שמות ידידותיים של חיישנים (אף פעם לא מזהה ישות) ולא גולשים הצידה.
- **English:** Integration fixes: migrations renumbered 0125-0127; the external-access screen keeps the header dropdown room (lead reserve).
- **עברית:** תיקוני שילוב: המיגרציות מוספרו מחדש 0125-0127; מסך הגישה החיצונית שומר מקום לתפריט הכותרת.

### What is OFF by default and how to enable - מה כבוי כברירת מחדל ואיך מפעילים
- **English:** Temperature early warning: Settings › Infrastructure › Temperatures › early warning (and its lead time). The external-access screen and the request form are visible to managers but act only when `access.external_grants` is on, which this build keeps locked together with WisKey door writes (`access_grants.GO_LIVE_PERMITTED = False`) and the extended service identity (`EXTENDED_GO_LIVE_PERMITTED = False`). Everything else applies without a switch.
- **עברית:** התרעה מוקדמת בטמפרטורה: הגדרות › תשתיות › טמפרטורות › התרעה מוקדמת (וזמן ההתרעה). מסך הגישה החיצונית וטופס הבקשה גלויים למנהלים אך פועלים רק כש-`access.external_grants` פעיל, ובגרסה הזו הוא נעול יחד עם כתיבות הדלתות של WisKey והזהות המורחבת. כל השאר פועל בלי מתג.

### Known limits - מגבלות ידועות
- **English:** Temperature phase 3, the access screens and the WisKey gate were tested with fakes only; no real sensor, WisKey, station or door. A malformed WisKey person record answers 403 (not 404) to a restricted writer who cannot see that person (pre-existing since 2.9.2, listed for the security review).
- **עברית:** שלב 3 של הטמפרטורה, מסכי הגישה ושער WisKey נבדקו רק עם תחליפים; ללא חיישן, WisKey, עמדה או דלת אמיתיים. רשומת אדם פגומה מ-WisKey מחזירה 403 (ולא 404) לכותב מוגבל שאינו רואה את האדם (קיים מאז 2.9.2, ברשימה לסקירת האבטחה).
