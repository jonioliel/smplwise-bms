# SmplWise Arx 2.3.0 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.3.0, bilingual per item).

## 2.3.0 (pilot) - more Frigate, voice announcement extras, second factor follow-ups, /health counters, warning-only visual check in the gate, runner tooling, add-on docs

**After installing:** three migrations run on start, in order: `0068_frigate_f2b`, `0069_second_factor_followups`,
`0070_announce_extras` (new tables; `0068` and `0070` each rebuild one table to widen a value list, every row kept). The bridge stays
0.7.0. Reload the installed web app once. 699 API routes (680 + 19: 17 Frigate F2b - automatic profile 4, exports 4, cases 4, manual events 2, first-write state 1, clip read 2 - and 2 second factor overrides). **Every new capability is OFF by default.** Two new permissions:
`analytics.exports`, `analytics.cases` (sensitive; site administrator and system administrator).

### Frigate F2b (CR-029 section 11, server side)
**Added.** Automatic profile on an alarm change per recorder (`off` default / `suggest` / `apply`; `apply` needs the profile class,
an explicit per-recorder consent and a supervised first write; withdrawing consent drops to `suggest`). Write classes `exports` and
`cases` (Arx-created objects only, otherwise `frigate_object_not_arx`; delete confirms every time; change log and undo). Manual events
create / end through the events class. A streamed, read-only `clip.mp4` read (camera window up to one hour, or a reviewed event;
`video.playback`; size / time caps; no Frigate address in the answer). A **first-supervised-write flag** (`frigate_first_write`) gates
every new kind: 409 `frigate_first_write_unsupervised` until a system administrator passes `supervised=true` once. Frigate undo is
single-shot (security follow-up I2).
**Not verified.** Every new wire shape was tested only against the in-process fake Frigate; the first supervised write / read on a real
Frigate is still to do (runbook `docs/operations/FRIGATE_SUPERVISED_VERIFICATION_HE.md`). No operator screen yet for these calls.
**How to enable.** Settings › the Frigate recorder › write classes: `exports` / `cases`; grant `analytics.exports` / `analytics.cases`
(exports also need `video.export`); automatic profile: `PUT /api/v1/frigate/{recorder}/profile-auto/setting` (system.configure); a
system administrator performs the first supervised call of each kind with the owner present.

### Voice announcement extras (ANN2)
**Added.** Per-announcement volume (clamped and restored), pause / resume of playing music, quiet hours (`suppress` or `lower`;
critical always spoken), rule actions with volume and a critical flag, and the `announce` notification channel (notifications spoken
in a chosen room by category and minimum severity, same limits and audit). Migration 0070.
**Off by default.** All of it; the `announce` channel is off in every notification policy.
**How to enable.** Settings › Multimedia › Voice announcements (volume, pause music, quiet hours, announce notifications), then tick the
announcement channel in the notification policies that should speak.

### Second factor follow-ups (TFA2)
**Added.** Persisted wrong-code lockout (survives a restart), a reset notice in the user's inbox (no actor, no secret), per-user and
per-role override `inherit` / `optional` / `required` (user first, then roles, then the global policy; enforced on browser and token
sign-ins), device-token revocation of the phone app when the factor is enabled or reset, and a neutral note in the remote-access
settings that the factor protects the Arx sign-in only. Migration 0069.
**Fixed.** The browser keeps freshly refreshed sign-in tokens in memory only while the second factor is pending (security follow-up I3).
**Off by default.** Every override starts as `inherit`; the factor stays optional.
**How to enable.** Settings › users and access › user drawer or Roles tab › second factor for the remote sign-in.

### /health process and database counters
**Added.** `process` (uptime, threads, open files, RSS) and `db` (file and WAL size) in `GET /api/v1/health`, returned **only to a
`system.configure` holder**; everyone else sees the same answer as before. The read-only soak sampler reads them and now takes the
supervisor statistics over the HA WebSocket. **How to enable.** Nothing to do.

### Release gate: visual regression, warning only
**Added.** The M074 visual matrix (screens touched by the change, against committed Linux baselines) runs in every gate tier **as a
warning section only**; it never changes the verdict (`--visual-block` to count it, `--no-visual` to switch it off). The 2.2.1 retry
fix (retries matched per test title) is kept. Docs: `docs/release/VISUAL_REGRESSION.md`, `docs/operations/VISUAL_REGRESSION.md`.

### Runner tooling
**Added.** A fixture job for the live-fixture browser specs under the shared lock (`scripts/fixture_job.py`,
`docs/operations/RUNNER_FIXTURE_JOB.md`; what the gate runs is unchanged), lock hygiene notes and the deployed patch
(`docs/operations/RUNNER_LOCKS.md`), failure diagnostics for `unit-devices-tiles.spec.ts` (no assertion change).

### Documentation
`smplwise_vms/DOCS.md` / `DOCS_HE.md` refreshed with a test that every add-on option is documented in both; Hebrew Frigate supervised
verification runbook.

### Known limits
The first supervised write / read of every Frigate write class and of the new F2b kinds on a real Frigate is still open; there is no
operator UI for the F2b calls yet; PTZ stays behind `PTZ_RELEASED = False`; no signed Android build is staged; the push relay is not
deployed (owner step).

## עברית - תקציר
- **Frigate F2b (צד שרת):** החלפת פרופיל אוטומטית בשינוי מצב אזעקה (ברירת מחדל כבוי), מחלקות כתיבה לייצואים ולתיקים, אירועים ידניים,
  קריאת קטע clip.mp4 לקריאה בלבד; כל סוג חדש חסום עד כתיבה ראשונה בפיקוח של מנהל מערכת. **לא אומת מול Frigate אמיתי** - רק מול Frigate מדומה.
- **הכרזות קוליות:** עוצמה, השהיית מוזיקה, שעות שקט וערוץ התראות `announce`; הכול כבוי כברירת מחדל (הגדרות › מולטימדיה › הכרזות קוליות).
- **אימות דו-שלבי:** נעילה שנשמרת, הודעה על איפוס, עקיפה לכל משתמש / תפקיד, ביטול אסימוני מכשיר, הערה ניטרלית בהגדרות הגישה מרחוק.
- **/health:** מוני תהליך ומסד נתונים רק למחזיק `system.configure`.
- **שער השחרור:** השוואה חזותית כאזהרה בלבד; תיקון הניסיון החוזר של 2.2.1 נשמר. **כלי מכונת הבדיקות:** משימת fixture וסדר בנעילות.
- **תיעוד:** דפי התוסף ומדריך אימות בפיקוח ל־Frigate.
- **אחרי ההתקנה:** מיגרציות 0068, 0069, 0070; טוענים מחדש את אפליקציית הרשת פעם אחת.
