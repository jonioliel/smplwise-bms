## Visible changes without a switch

- Home screen: the clock, weather, Shabbat and alarm cards are one thin glass bar in the header row; counters read "5 / 12" in their kind's colour (POLISH-295).
- Schedules and automations open as compact rows, one page at a time; "needs review" is a chip next to the state filter (POLISH-295).
- The developer and installer logos are back at the start side of the top row on desktop and tablet (LOGOSIDE-295, owner report on 2.17.1 / 2.18.0); side = end restores the corner row.
- Nav: the devices tab row is overview (`building`), schedules (`automations`) and announcements (`announce`, shown to holders of `media.announce`); the notice board stays on the rail (NOTICEADD-295 owner decision 2026-10-24).

## Behaviour changes

- New built-in role `announcer` (`devices.read` + `media.announce`). It holds no `presence.report` and is treated as an add-on grant like the door roles (open decision for the lead, see the assembly notes).
- New built-in roles `security_manager` and `notices_delete`.
- Emergency-open retry after UNKNOWN: a holder of `emergency_open` at the door's scope may now retry (while "Role holders may try again a door that was not confirmed" is on). The refusal code for a non-holder changed from `admin_only` to `retry_not_allowed`.

## Contents

### Doors and roles
- EMROLE-295: the `emergency_open` role for guards, temporary guards and reception with an expiry (default 24 h, security manager capped at 168 h); the `security_manager` role grants only it. Routes `GET/POST /doors/emergency/grants`, `POST /doors/emergency/grants/{binding_id}/revoke`.

### Infrastructure reports
- TEMPLINK-295: temperature report as a temporary download link (`GET/POST /infra/temperature/report/links`, `DELETE /infra/temperature/report/links/{link_id}`).
- WALINK-295: plain-text WhatsApp send of a live link with a typed per-recipient result (`POST /infra/temperature/report/links/{link_id}/send`).

### Notice board
- NOTICECAPS-295: editable connection caps for the TV board listener, applied without a restart.
- NOTICEDEL-295: `DELETE /notices/{id}` for published and archived notices with `notices.delete`; on-air notices need `?confirm_live=true`; an urgent notice on air is refused without `emergency.manage`; one content-free audit row. The `notices.show_places_tree` setting; an empty-filter row with "clear filter".
- NOTICERSS-295: an installation list of up to 12 https RSS sources with display name, enable flag and logo (PNG/JPEG, 300 KB); routes `GET/PUT /notices/news-sources`, `GET/PUT/DELETE /notices/news-sources/{id}/logo`, `GET /notices/display/{slug}/news-logo/{id}`; the TV ticker shows logo and name instead of the address.

### Voice announcements
- ANNOUNCE-295 stage A (migration 0177): templates, one-click emergency, languages, local or cloud TTS, hold-until-quiet-hours, the `announcer` role. Routes `POST /announcements/emergency`, `GET/PUT /announcements/templates`.

### WisKey (fakes only, nothing run against a real WisKey, station or go2rtc)
- WKF01F02-295: the leased go2rtc stream lifecycle in WKLIVE and full-duplex talk with station sound.
- CAPMAP-295: disabled Arx-side DTO9 map of the card-capture lease (`MAPPING_ENABLED = False`).
- WKVEC-295: WisKey's signed vectors and simulator checked against the bridge.

### Brand and polish
- LOGOSIDE-295: `brand.logo_side` (start | end) and `brand.company_logo_size` (same | s | m | l | xl); the TV feed carries `board.brand.company_size` when set.
- POLISH-295: home ambient bar, schedules rows / pager / 24 h timeline, automations rows / pager, list display settings card, dark-scheme button hover contrast.

### Fixed
- Schedules: the browser's view choice was written as JSON and read raw; it is read correctly now (POLISH-295).
- Dark-scheme primary-button hover kept white-label contrast above 4.5:1 (POLISH-295).
