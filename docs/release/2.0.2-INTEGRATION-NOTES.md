  `..., 55, 56, 57]`, comment text names both. `release_check.py` "migrations contiguous: 57 files" is green on the merged tree (it
  was expectedly red on the branch alone).

  lines that main had since replaced (the WebRTC-first transport text, the NVR-settings-in-Arx wording and the "connections" page
  subtitle). Main's side was kept in every conflicting hunk; the branch's non-conflicting wording changes (the phone-app embed row,
  the "תשתית המערכת" card and identity-source line, the bootstrap-admin option label) merged automatically. Platform-name count after
  the merge: `system-diagnostics.ts` 24 (all inside the settings screens, allowed by UI_COPY_RULES), `system-setup.ts` 1.
- **Merge 13, `docs/changes/CR-025-PROVISION-ISR.md`:** both sides appended to section 6.4; the branch's simulated-RTSP drop-recovery
  table and findings (2026-10-05 night) were kept first, followed by main's "Follow-up (2.0.0, all vendors)" stall-resume paragraph.
