## Time-dependent Frigate tests (fixed here)
`test_frigate_api.py::test_event_centre_shows_frigate_events_with_their_thumbnail` and
`test_frigate_join.py::test_the_review_screen_flow_with_the_uis_own_query` failed on main because the fake Frigate's reviews sit at a
fixed instant (T0 = 2026-10-05 19:20 UTC) while the event list's default window (last 24 h) and the review summary (last N days) read
`datetime.now`; the summary tests with the 7-day default would have followed on 2026-10-12. The shared `world` fixture now patches the
`dt` of `routers/events.py` and `routers/frigate.py` with a clock that starts one minute after T0 and runs forward
(`conftest.datetime_shim`, the seam `daytime_clock` already uses; no production change). Locally: the two Frigate files 43 passed;
frigate api / join / control / events / adapter + push + notify_core 182 passed.
