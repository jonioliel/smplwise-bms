# SmplWise Arx 2.2.0 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.2.0, bilingual per item).

## 2.2.0 (pilot) - Frigate recorders, optional TOTP second factor, voice announcements, Android download offer, plan DXF / package

**After installing:** migrations `0064_frigate_provider`, `0065_second_factor_totp`, `0066_frigate_control`, `0067_announcements` run
on start (new tables only). The bridge stays 0.7.0. Reload the installed web app once. Every new feature is off or optional by default.
678 API routes (629 + 49). New permissions: `analytics.review` (operator and above); `analytics.control`, `analytics.record_control`,
`analytics.profile`, `analytics.events`, `media.announce` (sensitive; site and system administrators).

### Frigate recorders, F1 + F2 (CR-029)
**Added.** F1 "see and play": Frigate 0.18+ connection, camera import, review screen (alert / detection layers, motion, per-user
reviewed, tracked-object timeline), recordings coverage and playback, refreshing still tiles, health rows, notifications from alerts
only; reads are read-only through an allow-list. F2 "control and actions": six write classes (one-camera analytics switches,
recording / snapshots / camera on-off, profile and alarm-to-profile mapping, reviewed mirror, event retain / sub-label, PTZ), each
with its own permission; read - write once - read back, change log with undo, confirmation per action for recording / profile / PTZ,
no retries or queues. **Off by default.** Every write class is off for every recorder; PTZ is held back by the code flag
`PTZ_RELEASED = False` (cannot be switched on, no PTZ pad). The Frigate type is selectable only when the server runs with
`SW_FRIGATE=1` (no add-on option yet). **Not verified.** Writes were tested only against an in-process fake: the first supervised
write of each write class on a real Frigate is still to do; a viewer-role account, clip export and HLS time anchors remain open from
F1. **How to enable.** Connect the Frigate recorder (with `SW_FRIGATE=1`); then Settings › the Frigate recorder › write classes, and
grant the matching `analytics.*` permissions.

### Optional TOTP second factor (CR-011, K11)
**Added.** RFC 6238 codes (Google Authenticator and similar) asked at a NEW remote sign-in for users who enrolled; enrol / remove in
the user menu › my account › second factor; replay refused, lock-out after 5 wrong codes; secret encrypted; administrator reset
(audited). **Off by default.** Optional for everyone (policy `optional`); `admins` refuses a remote sign-in of an administrator without
a factor. The local panel channel is unchanged. **How to enable.** Each user enrols in their account menu; the policy is under
Settings › Remote access; reset: Settings › users and access › the user › second factor.

### Voice announcements (MU2)
**Added.** Speak a typed line through allowed speakers by room or speaker (platform text-to-speech), from Settings › Multimedia › Voice
announcements or as a rule action; rate limit, history and audit for every attempt; permission `media.announce`. **Off by default.**
Off, and no speaker allowed, until an administrator sets it up. **How to enable.** Pick the engine, tick the allowed speakers, test
one, switch on, grant `media.announce`.

### Android app download offer on the sign-in page
**Added.** One quiet download link (with version and SHA-256) on the remote sign-in page, only on Android devices outside the app.
**Off by default.** Nothing shows until an administrator sets an https URL in Settings › Remote access › Android app download. The
current Android build is a debug build and is NOT for distribution: do not publish a link until a signed release build exists.

### Plan DXF export and signed plan package (ST5, T088)
**Added.** Plan editor export row: DXF (R2018, `SW_*` layers, metres when calibrated), a signed package (Ed25519, SHA-256 manifest) and
package import (dry-run preview, replace or merge, draft only, explicit trust for a foreign package, hostile ZIP checks). No
migration. **How to enable.** Nothing to switch on.

### Bugs fixed
- Test only: the phone-app push test no longer fails after the fixture date (expiry clock pinned). No product change.

### Known limits
- Frigate: writes not verified on a real Frigate (first supervised write per class to do); PTZ unreleased; no add-on option for
  `SW_FRIGATE`; the new Frigate tables are not in the backup archive.
- TOTP applies to the remote sign-in only (not to step-up of sensitive actions; that is a later slice of CR-011).
- Announcements and the Android link were tested with fakes and mocks only; no real speaker was spoken to.
- DXF Hebrew ordering in commercial CAD programs not verified.

## עברית - 2.2.0: מקליטי Frigate, אימות דו-שלבי רשות, הכרזות קוליות, הורדת אפליקציית Android, DXF וחבילת תוכנית

**אחרי ההתקנה:** המיגרציות `0064_frigate_provider`, `0065_second_factor_totp`, `0066_frigate_control`, `0067_announcements` רצות
בהפעלה (טבלאות חדשות בלבד). רכיב החיבור נשאר 0.7.0. טוענים מחדש את אפליקציית הרשת פעם אחת. כל יכולת חדשה כבויה או רשות
כברירת מחדל. 678 נתיבי API (629 + 49). הרשאות חדשות: `analytics.review` (מפעיל ומעלה); `analytics.control`,
`analytics.record_control`, `analytics.profile`, `analytics.events`, `media.announce` (רגישות; מנהלי אתר ומערכת).

### מקליטי Frigate, F1 + F2 (CR-029)
**מה נוסף.** F1 "צפייה וניגון": חיבור ל־Frigate 0.18 ומעלה, ייבוא מצלמות, מסך סקירה (שכבות התראה / זיהוי, תנועה, "נסקר" לכל משתמש,
ציר זמן של אובייקט), כיסוי הקלטות וניגון, תמונות מתעדכנות, שורות בריאות, התראות מהתראות בלבד; קריאה בלבד דרך רשימה סגורה. F2 "שליטה
ופעולות": שש מחלקות כתיבה (מתגי ניתוח למצלמה אחת, הקלטה / תמונות / הפעלת מצלמה, פרופיל ומיפוי אזעקה לפרופיל, שיקוף "נסקר", שמירת אירוע
/ תווית משנה, PTZ), לכל אחת הרשאה; קריאה - כתיבה אחת - קריאה חוזרת, יומן שינויים עם ביטול, אישור לכל פעולה בהקלטה / פרופיל / PTZ,
בלי ניסיונות חוזרים ובלי תור. **כבוי כברירת מחדל.** כל מחלקת כתיבה כבויה בכל מקליט; PTZ חסום בדגל בקוד `PTZ_RELEASED = False` (אי אפשר
להפעיל, אין לוח PTZ). סוג Frigate זמין לבחירה רק כשהשרת רץ עם `SW_FRIGATE=1` (אין עדיין אפשרות תוסף). **לא אומת.** הכתיבות נבדקו רק מול
Frigate מדומה: הכתיבה הראשונה בפיקוח של כל מחלקת כתיבה מול Frigate אמיתי עוד לפנינו; חשבון צופה, ייצוא קטע ועוגני זמן של HLS עדיין
פתוחים מ־F1. **איך מפעילים.** מחברים את מקליט ה־Frigate (עם `SW_FRIGATE=1`); אחר כך הגדרות › מקליט ה־Frigate › מחלקות כתיבה, ונותנים
את הרשאות `analytics.*` המתאימות.

### אימות דו-שלבי רשות (TOTP, CR-011, K11)
**מה נוסף.** קודים לפי RFC 6238 (Google Authenticator ודומיו) שנדרשים בכניסה מרחוק חדשה למי שנרשם; הרשמה / הסרה בתפריט המשתמש › החשבון
שלי › אימות דו-שלבי; קוד חוזר נדחה, נעילה אחרי 5 קודים שגויים; הסוד מוצפן; איפוס על ידי מנהל (נרשם ביומן). **כבוי כברירת מחדל.** רשות
לכולם (מדיניות `optional`); `admins` דוחה כניסה מרחוק של מנהל בלי אימות. ערוץ הלוח המקומי לא משתנה. **איך מפעילים.** כל משתמש נרשם
בתפריט החשבון; המדיניות בהגדרות › גישה מרחוק; איפוס: הגדרות › משתמשים והרשאות › המשתמש › אימות דו-שלבי.

### הכרזות קוליות (MU2)
**מה נוסף.** השמעת שורה מוקלדת ברמקולים מותרים לפי חדר או רמקול (מנוע הדיבור של התשתית), מהגדרות › מולטימדיה › הכרזות קוליות או
כפעולת כלל; הגבלת קצב, היסטוריה ויומן לכל ניסיון; הרשאה `media.announce`. **כבוי כברירת מחדל.** כבוי, ואף רמקול אינו מותר, עד שמנהל
מגדיר. **איך מפעילים.** בוחרים מנוע, מסמנים רמקולים מותרים, בודקים אחד, מפעילים, נותנים `media.announce`.

### הצעת הורדה לאפליקציית Android במסך הכניסה
**מה נוסף.** קישור הורדה שקט אחד (עם גרסה ו־SHA-256) במסך הכניסה מרחוק, רק במכשירי Android מחוץ לאפליקציה. **כבוי כברירת מחדל.** לא
מוצג דבר עד שמנהל מגדיר כתובת https בהגדרות › גישה מרחוק › הורדת אפליקציית Android. בניית ה־Android הנוכחית היא בניית debug ואינה
להפצה: לא לפרסם קישור עד שתהיה בניית שחרור חתומה.

### ייצוא DXF וחבילת תוכנית חתומה (ST5, T088)
**מה נוסף.** שורת הייצוא בעורך התוכניות: DXF (R2018, שכבות `SW_*`, מטרים כשמכויל), חבילה חתומה (Ed25519, מניפסט SHA-256) וייבוא
חבילה (תצוגה מקדימה יבשה, החלפה או מיזוג, לטיוטה בלבד, אמון מפורש לחבילה זרה, בדיקות ZIP עוין). בלי מיגרציה. **איך מפעילים.** אין
מה להפעיל.

### באגים שתוקנו
- בדיקה בלבד: בדיקת הדחיפה לאפליקציית הטלפון לא נכשלת עוד אחרי תאריך הבדיקה (שעון התפוגה מוצמד). בלי שינוי במוצר.

### מגבלות ידועות
- Frigate: הכתיבות לא אומתו מול Frigate אמיתי (כתיבה ראשונה בפיקוח לכל מחלקה עוד לפנינו); PTZ לא שוחרר; אין אפשרות תוסף ל־`SW_FRIGATE`;
  הטבלאות החדשות של Frigate אינן בארכיון הגיבוי.
- האימות הדו-שלבי חל על הכניסה מרחוק בלבד (לא על אישור מחדש לפעולות רגישות; זו פרוסה עתידית של CR-011).
- ההכרזות וקישור ה־Android נבדקו רק מול דמויות; לא הושמע דבר ברמקול אמיתי.
- סדר העברית ב־DXF בתוכנות CAD מסחריות לא אומת.
