## Owner decisions applied on this branch
- **400 - vendor visits and "I arrived" OFF by default.** `visits.enabled` and `visits.public_arrival` default to `false` in `services/tickets/settings_doc.py`. No migration
  or seed row is needed: an installation that never saved the `visits` block follows the new default; one that saved it keeps its value. With visits off the visit
  routes answer 404 `feature_disabled`, the vendor page carries no visit and `/t/api/arrived` is the uniform 404; the button also needs `public_arrival`. The frontend has no
  settings text for these two defaults (nothing to reword); `docs/changes/CR-SVC215.md` already said "off".
- **402 - settings side column.** Measured in a browser (demo mode): the column was 1601 px tall (34 links) in a 982-622 px slot, so on every desktop screen it was cut off
  and scrolled inside itself. Now one group is open at a time (the group of the current page by default; each group header is a button with `aria-expanded`) and on a
  short desktop screen (height <= 960 / <= 800) the open group is drawn denser. Measured: the longest group (17 entries) is 789 px at 1440x900 (slot 802) and 613 px at
  1366x768 (slot 670). The `overflow:auto` on the column stays only as the last resort below about 700 px of height. Spec: `frontend/tests/layout-settings-nav-fit-402.spec.ts`.
- **403 - NVR encoding pixel test = dialog only.** `pixel-nvr-encoding-batch.spec.ts` now shoots `sw-dialog[data-nvr-enc]`, with new baseline names
  `enc-<skin>-dialog-<phase>-<width>.png`. The 20 old whole-page baselines were removed; until the runner writes the new ones the existing missing-baseline rule skips the
  compare (annotation `skipped-pixel`), so the gate does not go red on a missing image.

# SmplWise Arx 2.16.0 - הערות שחרור (עברית)

**מגיע כבוי:** ממשק השותפים וה-webhooks, מאזין מסכי הטלוויזיה של לוח ההודעות, וקליטת בקשות מטקסט חופשי. לכל יכולת חדשה אחרת יש מתג משלה, כבוי כברירת מחדל.

**אימות:** השער המלא (דרגה L, תזמון v2) על `release/2160B` @ `9645d4c2f` עבר ב-150 דקות: tsc, build, release_check, fixture, preview 14052, dev 1016, pixel 187, backend 16114 - אפס כשלונות (16 בדיקות לא יציבות עברו בהרצה חוזרת). השער הראשון (252 דקות) נכשל ותוקן: רצועת הלוגו ה"דביקה" כיסתה כותרות, שורות העמודה בצד בעור "בועה" היו נמוכות מ-44 פיקסלים, שיוך אנשים לפי Wi-Fi לא עבד, ועוד.
**לא הורץ (NOT_RUN):** בדיקת סדר המיגרציות על עותק של מסד 2.15.0 אמיתי.

**לתקן לפני הפעלה (סקירת אבטחה, אין חוסם):** (1) ממשק השותפים: חלון הכשלים הכללי עלול לנעול שותפים תקינים; (2) לוח ההודעות: הזנות RSS מותאמות בלי הגנת SSRF;
(3) לוח ההודעות: למאזין המקומי אין זמן קצוב לסוקט ולא תקרת חיבורים; (4) קליטת טקסט חופשי: תור הטיוטות אינו מופרד לפי מחלקה.
