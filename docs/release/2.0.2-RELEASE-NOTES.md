# SmplWise Arx 2.0.2 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.0.2, bilingual per item).

## 2.0.2 (pilot) — The phone app's server side (off by default); the recordings comparison picker is one dropdown; more Bubble tiles; recorder health per camera and Hikvision detail; the "שידור" (cast) column; the recorder disable dialog tells the truth; the meter-readings backup switch; bill PDFs draw Cyrillic and Arabic names

**After installing:** one database migration runs on start, `0057_mobile_presence_push` (three new tables for the phone app; nothing
existing is rewritten). The bridge integration stays **0.6.2**; no platform restart. Reload the installed web app once. **Nothing new is
switched on by itself:** the phone app's data sharing stays off until an administrator enables it, the "אפליקציה" notification channel
plans nothing until the add-on options `push_relay_url` / `push_relay_key` are set (the server is inert without them), the cast column
is read-only information, the per-camera health choice is empty, the new Bubble tiles appear only when chosen. The live transport default
stays **automatic (WebRTC first, MSE when WebRTC cannot be used)**, as in 2.0.1. 564 API routes (545 + 19 phone-app routes).

### The phone app's server side (CR-027) - אפליקציית הטלפון: צד השרת

**What was added.** Device registration (a device token shown once, stored hashed, never an HA token), `presence/config` for the app
(master switch, cadence, the employee notice with a version the device must acknowledge, allowed sensors, geofences, beacons, Wi-Fi
sites), validated event batches (fix / enter / exit / sensor) against the sensor allow-list, a **required-sensors policy** (an
administrator may require e.g. location before the phone app may use the system; break-glass exists), retention (30 days by default),
permissions `presence.report` / `presence.sensors.view`, the settings tab הגדרות › **אפליקציה לנייד**. **Push:** the app is a new
notification channel ("אפליקציה") - the server sends a generic payload to the SmplWise relay (a stateless Cloudflare Worker in
`services/push-relay/`; it never sees the text), the app fetches the real message with its device token (24 h expiry); mutes, quiet
hours, retries and dead registrations are handled; a test push exists. Migration `0057`.

**Bugs fixed.** None (new capability).

**How to enable.** (1) הגדרות › אפליקציה לנייד › the master switch, the allowed sensors, the employee notice, optionally the
required-sensors policy. (2) Push: add-on Configuration › `push_relay_url` + `push_relay_key` (this installation's relay credential;
relay deployment in `services/push-relay/README.md`) › restart the add-on › הגדרות › התראות › the "אפליקציה" channel per category › the
user registers the phone from the app › "שלח התראת בדיקה". **Without the two options nothing is sent** (`channel_unavailable`).

### Recordings: the comparison picker is one dropdown (CMP1) - הקלטות › השוואה

**What was added.** The chip-per-camera row that filled a phone screen is one multi-select dropdown (up to three cameras next to the
lead, "n מתוך 4"), in the dropdown style the installation or the user chose (six styles + auto + capsule, four skins, light / dark,
phone sheet / centred / inline, search at 8+ cameras); at the limit the other options are greyed and a press answers "אפשר לבחור עד 4";
"נקה" and "סיום" in the foot; keyboard: Tab cycles inside, Esc returns to the chip. The route's `extra=` parameter and the session
semantics are unchanged. **Bugs fixed.** None. **How to use.** הקלטות › "השוואה" › pick › "סיום".

### More Bubble variants (BV1) - עוד גרסאות Bubble

**What was added.** Clock and weather widgets in **tile** style; new home widgets **agenda** (the next event per chosen calendar) and
**quick launcher** (round launch buttons: screens, scenes, scripts, quick actions); look dials **slider: vertical** (device sheet sliders)
and **surface: none** (no fill, ring and text only). Skin authoring guide section 6d. **Bugs fixed.** The agenda tile was forced square
and overflowed at 600-1024 px. **How to enable.** מסך הבית › עריכה › add "יומן" / "משגר מהיר" or set the clock / weather style to
"אריח"; הגדרות › מראה › "מחוונים" → אנכי, "משטח" → ללא.

### Recorder health per camera and Hikvision detail (NN6B / NN6H) - בריאות המקליטים

**What was added.** A continuous / events expectation per camera on top of the recorder's choice (same thresholds value, no
migration, empty by default; a collapsed "לכל מצלמה" section in the thresholds card). The Hikvision adapter reads, GET-only, disks,
channel connectivity, recording state and clock drift (shapes from the lab capture of 2026-09-14). **Bugs fixed.** None. **How to
enable.** הגדרות › בריאות המקליטים › "לכל מצלמה" › choose per camera › שמור; Hikvision detail appears by itself.

### Cast to screens, read-only preparation (CR-028) - שידור למסך: הכנה

**What was added.** Each media device's cast technology and confidence (**מאומת / כנראה / לא ידוע**) computed from the mirrored
registry data only; a "שידור" column in הגדרות › מולטימדיה (screens and players) and a reason sentence in the open form. No button, no
command, no device write, no migration, no flag. The research, the phased plan and the owner's three open decisions:
`docs/changes/CR-028-CAST-TO-SCREENS.md`. **Bugs fixed.** None. **How to use.** Nothing to turn on; columns panel › "שידור".

### Fix: the recorder disable dialog; the meter-readings backup switch - הגדרות › חיבורים; גיבוי ושחזור

**Bugs fixed.** The "השבת" dialog claimed the cameras stay in the lists while the code removed them from the wall and pickers; the
dialog now says exactly what happens, and the kiosk wall, the overview, the case snapshot picker, the floor map (pin kept, no picture
or buttons) and the single camera page all treat a disabled recorder's cameras consistently. Disable / enable apply at once, no restart.
**What was added.** הגדרות › גיבוי ושחזור › "גיבויים של הפרויקט" › **"נתוני מוני החשמל"** (the raw readings in the backup; meters,
bills, PDFs, logo and daily totals are always included). **How to enable.** The switch only; the dialog needs nothing.

### Bill PDF: Cyrillic and Arabic names - PDF של חיוב: שמות בקירילית ובערבית

**Bugs fixed.** A customer, meter or address typed in Russian / Ukrainian / Bulgarian or in Arabic printed as missing-glyph boxes.
**What was added.** Four Noto subsets (Noto Sans Cyrillic 400 / 700, Noto Sans Arabic 400 / 700; 400 KB; SIL OFL 1.1) in the bill's
font allow-list; the page falls through Heebo → Noto per character, the layout stays Heebo; the fpdf2 fallback draws them too (Arabic
unjoined there). **How to use.** Nothing to turn on.

### Smaller items

- **Provision-ISR push validation (NN2A, scripts only):** the push listener outside the add-on and the save-and-restore alarm-server
  write. No device write was made; product defaults unchanged (polling, port 18091/tcp unmapped); the owner runs the write himself.
- **Tests and gate (GT2, BL1):** multimedia evidence screenshots at CSS scale; gate baselines = the green 2.0.0 numbers; runner cleanup
  script (dry run by default); retention rules documented.
- **Operator guide (M091):** chapters 8-15 for 0.1.157-2.0.0 and the 2.0.2 note on disabled recorders; user guide 91 / 95 updated.
- **Documents merged:** WisKey DTO v3 addendum + golden vectors (with tests), exchange schemas, CR-025 rig findings, test policy names
  the gate, design research and compare mockups; "תשתית המערכת" wording in the settings screens.

### Known limits
- **Phone app:** server side only; the app is built separately (`docs/api/mobile-presence-contract.md`). The relay Worker was not run
  against APNs / FCM (owner keys needed); push was tested with a fake relay; nothing tried on the owner's installation.
- **Cast:** information only; no cast in 2.0.2; confidence comes from registry data, not a device probe.
- **Hikvision health detail:** lab-capture shapes and fake devices; not yet read from the owner's recorder in this version.
- **Bubble tiles:** mocked screens and backend tests; the agenda tile needs a calendar entity in the mirrored catalogue.
- **Bill PDF, Cyrillic / Arabic:** verified with WeasyPrint + pdftotext on the test machine; not rebuilt inside the add-on image (the
  fonts travel in the package like Heebo).

### How to turn it on and use it (English)
1. Install the update; migration 0057 runs on start; reload the web app once.
2. Phone app data sharing: הגדרות › אפליקציה לנייד › switch on › allowed sensors › employee notice › (optional) required sensors.
3. Phone push: add-on Configuration › `push_relay_url`, `push_relay_key` › restart › הגדרות › התראות › "אפליקציה" per category › register
   the phone from the app › "שלח התראת בדיקה".
4. Comparison picker: הקלטות › "השוואה" › pick up to three › "סיום".
5. Bubble tiles: home editor › "יומן" / "משגר מהיר" / tile style; הגדרות › מראה › sliders vertical, surface none.
6. Health per camera: הגדרות › בריאות המקליטים › "לכל מצלמה".
7. Cast column: הגדרות › מולטימדיה › columns › "שידור" (information only).
8. Meter readings in backups: הגדרות › גיבוי ושחזור › "נתוני מוני החשמל".
9. Bill PDF names in Cyrillic / Arabic: nothing to turn on.

## עברית — 2.0.2: צד השרת של אפליקציית הטלפון (כבוי כברירת מחדל); בורר ההשוואה בהקלטות הוא תפריט אחד; עוד אריחי Bubble; בריאות מקליטים לכל מצלמה ופירוט Hikvision; עמודת "שידור"; דיאלוג ההשבתה אומר את האמת; מתג גיבוי קריאות המונים; PDF של חיוב מצייר שמות בקירילית ובערבית

**אחרי ההתקנה:** מיגרציה אחת רצה בהפעלה, `0057_mobile_presence_push` (שלוש טבלאות חדשות לאפליקציית הטלפון; שום דבר קיים לא נכתב
מחדש). רכיב החיבור נשאר **0.6.2**; אין צורך להפעיל מחדש את התשתית. טוענים מחדש את אפליקציית הרשת פעם אחת. **שום דבר חדש לא נדלק
מעצמו:** שיתוף הנתונים של אפליקציית הטלפון כבוי עד שמנהל מפעיל אותו; ערוץ ההתראות "אפליקציה" לא מתכנן דבר עד שמגדירים באפשרויות

### אפליקציית הטלפון - צד השרת (CR-027)
**מה נוסף.** רישום מכשיר (אסימון מכשיר שמוצג פעם אחת, נשמר מגובב, לעולם לא אסימון של התשתית), `presence/config` לאפליקציה (מתג ראשי,
קצב, הודעת העובדים עם גרסה שהמכשיר חייב לאשר, חיישנים מותרים, גדרות גיאוגרפיות, משואות, אתרי Wi-Fi), קבוצות אירועים נבדקות מול רשימת
החיישנים המותרים, **מדיניות חיישנים נדרשים** (מנהל יכול לחייב למשל מיקום לפני שהאפליקציה משתמשת במערכת; יש מתג חירום), שמירה 30 יום
כברירת מחדל, הרשאות `presence.report` / `presence.sensors.view`, הלשונית הגדרות › **אפליקציה לנייד**. **דחיפה:** האפליקציה היא ערוץ
התראות חדש ("אפליקציה") - השרת שולח מטען גנרי לממסר של SmplWise (Worker ב־Cloudflare; לא רואה את הטקסט), האפליקציה מביאה את ההודעה
עם אסימון המכשיר (תפוגה 24 שעות); השתקות, שעות שקט, ניסיונות חוזרים ורישומים מתים מטופלים; יש התראת בדיקה. מיגרציה `0057`.
**באגים שתוקנו.** אין. **איך מפעילים.** (1) הגדרות › אפליקציה לנייד › המתג הראשי, חיישנים מותרים, הודעת העובדים, ואם רוצים חיישנים
נדרשים. (2) דחיפה: הגדרות ה־add-on › `push_relay_url` + `push_relay_key` (פריסת הממסר: `services/push-relay/README.md`) › הפעלה מחדש
של ה־add-on › הגדרות › התראות › ערוץ "אפליקציה" לכל קטגוריה › המשתמש רושם את הטלפון מהאפליקציה › "שלח התראת בדיקה". **בלי שתי
האפשרויות שום דבר לא נשלח.**

8. קריאות מונים בגיבוי: הגדרות › גיבוי ושחזור › "נתוני מוני החשמל".
9. שמות בקירילית / ערבית ב־PDF: אין מה להפעיל.

### מגבלות
- **אפליקציית הטלפון:** צד השרת בלבד; האפליקציה נבנית בנפרד. הממסר לא הורץ מול APNs / FCM (צריך את המפתחות של הבעלים); הדחיפה נבדקה
  עם ממסר מדומה; שום דבר לא נוסה בהתקנת הבעלים.
- **שידור:** מידע בלבד; אין שידור ב־2.0.2; רמת הביטחון מנתוני הרישום, לא מבדיקת המכשיר.
- **פירוט בריאות Hikvision:** צורות מלכידת המעבדה ומכשירים מדומים; עוד לא נקרא מהמקליט של הבעלים בגרסה הזו.
- **אריחי Bubble:** מסכים מדומים ובדיקות שרת; אריח היומן צריך ישות יומן בקטלוג.
- **PDF בקירילית / ערבית:** אומת עם WeasyPrint + pdftotext במכונת הבדיקות; לא נבנה מחדש בתוך תמונת ה־add-on (הגופנים נוסעים בחבילה כמו Heebo).
