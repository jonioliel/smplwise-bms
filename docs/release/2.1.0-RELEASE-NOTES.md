# SmplWise Arx 2.1.0 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.1.0, bilingual per item).

## 2.1.0 (pilot) - Map marker clustering; the search dial for camera pickers only; server id and relay address for the phone app; load and exposure evidence

**After installing:** no migration, the bridge stays 0.7.0. Reload the installed web app once. The only server change is additive
(`server_id`, `relay_url` in the phone-app responses; the relay key is never returned).

### Map marker clustering (M037)
**Added.** Above 60 markers a plan groups nearby markers into counted clusters; click or Enter expands, the worst status colour wins, the
selection is kept. **Bugs fixed.** None (new). **How to enable.** Nothing: small plans look as before.

### Camera pickers only follow the search dial (CMP3)
**Added.** `ui.dd_search` applies to camera pickers (compare, synchronized playback) only (`camera-picker` attribute); the settings
label says "search in the camera list". **Bugs fixed.** The dial also changed unrelated lists. **How to enable.** The picker settings
(installation default and personal choice).

### Phone app: server id and relay address (CR-027)
**Added.** `server_id` and `relay_url` (never the key) in device registration, presence config and push routes; contract updated.
**Bugs fixed.** None (additive). **How to enable.** Nothing.

### Load and exposure evidence (M024, M069)
**Added.** Tests and documents only: 1,000-entity HA sync fixture, 120 MiB through the live relay (fake go2rtc), remote-channel
checklist script, go2rtc exposure review in DOCS. **Bugs fixed.** None. **How to enable.** Nothing.

### Known limits
- Clustering and the picker change: Playwright evidence only. Load tests run against fakes; no real go2rtc, NVR or Home Assistant was contacted.

## עברית - 2.1.0: אשכולות סמנים במפה; חוגת החיפוש רק לבוררי מצלמות; מזהה שרת וכתובת ממסר לאפליקציה; ראיות עומס וחשיפה

**אחרי ההתקנה:** בלי מיגרציה, רכיב החיבור נשאר 0.7.0. טוענים מחדש את אפליקציית הרשת פעם אחת. השינוי היחיד בשרת הוא תוספת
(`server_id`, `relay_url` בתשובות לאפליקציה; מפתח הממסר לא מוחזר).

### אשכולות סמנים במפה (M037)
**מה נוסף.** מעל 60 סמנים התכנית מקבצת סמנים קרובים לאשכולות עם מספר; לחיצה או Enter מרחיבים, צבע המצב החמור גובר, הבחירה נשמרת.
**באגים שתוקנו.** אין (חדש). **איך מפעילים.** אין מה להפעיל: תכניות קטנות נראות כמו קודם.

### חיפוש ברשימה רק בבוררי מצלמות (CMP3)
**מה נוסף.** `ui.dd_search` חלה רק על בוררי מצלמות (השוואה, ניגון מסונכרן); התווית בהגדרות "חיפוש ברשימת המצלמות".
**באגים שתוקנו.** החוגה שינתה גם רשימות שלא נועדו לה. **איך מפעילים.** הגדרות הבוררים (ברירת מחדל להתקנה ובחירה אישית).

### אפליקציה: מזהה שרת וכתובת ממסר (CR-027)
**מה נוסף.** `server_id` ו־`relay_url` (לא המפתח) ברישום מכשיר, בתצורת נוכחות ובנתיבי התראות; החוזה עודכן. **באגים שתוקנו.** אין
(תוספת בלבד). **איך מפעילים.** אין מה להפעיל.

### ראיות עומס וחשיפה (M024, M069)
**מה נוסף.** בדיקות ומסמכים בלבד: מתקן סנכרון של 1,000 ישויות, 120 MiB דרך ממסר הלייב (go2rtc מדומה), סקריפט רשימת בדיקה לערוץ מרחוק,
סקירת חשיפת go2rtc ב־DOCS. **באגים שתוקנו.** אין. **איך מפעילים.** אין מה להפעיל.

### מגבלות ידועות
- אשכולות ושינוי הבורר: ראיות Playwright בלבד. בדיקות העומס רצות מול דמויות; לא נוצר קשר עם go2rtc, NVR או Home Assistant אמיתיים.
