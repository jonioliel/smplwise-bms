# SmplWise Arx 2.0.4 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.0.4, bilingual per item).

## 2.0.4 (pilot) - Cast one camera to a Google Cast screen (off by default); the Provision encoding editor; live wall camera count; bill PDF diagnostics

**After installing:** migration `0060_cast_sessions` runs on start. The bridge integration becomes **0.7.0**: update it and restart the
platform once for casting (everything else works on 0.6.2). **Casting is off** (add-on option `cast_relay` = false, no screen allowed).
Reload the installed web app once. 585 API routes (572 + 13).

### Cast to a screen (CR-028)
**Added.** A cast button next to full screen on the live camera screen, a picker of allowed screens, a global pill (extend / switch /
stop), the relay inside the add-on (HLS of the screen's own go2rtc stream behind a one-use token, port 18092, only with `cast_relay`),
sessions with limits (30 minutes, up to 8 extensions, one per screen, sub stream by default), a 60-second administrator test cast,
audit, and Settings › Multimedia administration. Bridge 0.7.0 adds the single `cast_stream` service with its own URL and origin check.
**Bugs fixed.** None (new). **How to enable.** Install, update the bridge to 0.7.0 and restart the platform, set `cast_relay` to true and
restart the add-on, Settings › Multimedia › casting: origin check, switch a screen on, test cast. First physical test only by
`docs/operations/CAST_FIRST_PHYSICAL_TEST_RUNBOOK.md`.

### Provision encoding editor (NN2B)
**Added.** Single and bulk encoding editing on Provision NVR cameras (resolution, frame rate, VBR / CBR, bit rate, quality, GOP, codec +
profile, smart codec), validated against the device, read back after the write, never retried on an unknown outcome, refused cleanly
where the recorder lacks the command. v1 writes the whole `streams` element, v2 only the changed fields. **Bugs fixed.** None.
**How to enable.** Nothing beyond the recorder's NVR-writes approval; the first real write only by
`docs/integrations/provision-isr/RUNBOOK_FIRST_REAL_ENCODING_WRITE.md`. No write to the real NVR was made.

### Live wall camera count (LV1)
**Added.** Choose how many cameras the wall shows (ladder to the visible total, plus all); columns became a compact dropdown.
**Bugs fixed.** None. **How to enable.** Nothing.

### Bill PDF diagnostics
**Added.** Retry button only for retryable errors; a draft without lines prints with a note. **Bugs fixed.** A meter without a reading
at the period edge made the bill PDF fail with a blind error; it now prints a dash and other failures say why (`pdf_no_lines` /
`pdf_invalid_snapshot`). **How to enable.** Nothing.

### Known limits
- **Cast:** tested with fakes only (relay, sessions, bridge policy, mocked screens); no real Chromecast / TV, camera or go2rtc was contacted.
- **Encoding editor:** proven on the fake device only; whether the owner's NVR accepts the whole-`streams` body is unverified.
- **Bill PDF / live wall:** backend tests and mocked screens.

## עברית - 2.0.4: שידור מצלמה למסך Google Cast (כבוי כברירת מחדל); עורך הקידוד ב־Provision; כמות מצלמות בקיר הלייב; אבחון PDF של חשבון

**אחרי ההתקנה:** מיגרציה `0060_cast_sessions` רצה בהפעלה. רכיב החיבור הופך ל־**0.7.0**: מעדכנים ומפעילים מחדש את הפלטפורמה פעם אחת
בשביל השידור (כל השאר עובד על 0.6.2). **השידור כבוי** (אפשרות התוסף `cast_relay` = false, אין מסך מורשה). טוענים מחדש את אפליקציית
הרשת פעם אחת. 585 נתיבי API (572 + 13).

### שידור למסך (CR-028)
**מה נוסף.** כפתור שידור ליד מסך מלא במסך הלייב, בורר מסכים מורשים, מוסית גלובלית (הארכה / החלפה / עצירה), ממסר בתוך התוסף (HLS של
הזרם של המסך מ־go2rtc מאחורי אסימון חד־פעמי, פורט 18092, רק עם `cast_relay`), שידורים עם מגבלות (30 דקות, עד 8 הארכות, אחד למסך,
זרם משני כברירת מחדל), שידור בדיקה של 60 שניות למנהל, ביקורת וניהול בהגדרות › מולטימדיה. רכיב החיבור 0.7.0 מוסיף את השירות
`cast_stream` עם בדיקת כתובת ומקור משלו. **באגים שתוקנו.** אין (חדש). **איך מפעילים.** מתקינים, מעדכנים את רכיב החיבור ל־0.7.0 ומפעילים
מחדש את הפלטפורמה, מגדירים `cast_relay` ל־true ומפעילים מחדש את התוסף, הגדרות › מולטימדיה › שידור: בדיקת מקור, מדליקים מסך, שידור
בדיקה. הבדיקה הפיזית הראשונה רק לפי `docs/operations/CAST_FIRST_PHYSICAL_TEST_RUNBOOK.md`.

### עורך הקידוד ב־Provision (NN2B)
**מה נוסף.** עריכת קידוד בודדת וקבוצתית במצלמות NVR של Provision (רזולוציה, קצב פריימים, VBR / CBR, קצב סיביות, איכות, GOP, קודק +
פרופיל, קודק חכם), עם אימות מול המכשיר, קריאה חוזרת אחרי הכתיבה, בלי ניסיון חוזר כשהתוצאה לא ידועה, ודחייה נקייה כשהמקליט חסר את
הפקודה. v1 כותב את כל אלמנט `streams`, v2 רק את מה ששונה. **באגים שתוקנו.** אין. **איך מפעילים.** אין מה להפעיל מעבר לאישור הכתיבה
של המקליט; הכתיבה האמיתית הראשונה רק לפי `docs/integrations/provision-isr/RUNBOOK_FIRST_REAL_ENCODING_WRITE.md`. לא בוצעה כתיבה ל־NVR האמיתי.

### כמות מצלמות בקיר הלייב (LV1)
**מה נוסף.** בחירת כמה מצלמות הקיר מציג (סולם עד סך הנראות, ו"הכל"); העמודות הפכו לתפריט קומפקטי. **באגים שתוקנו.** אין. **איך מפעילים.** אין מה להפעיל.

### אבחון PDF של חשבון
**מה נוסף.** כפתור "נסה שוב" רק בשגיאות שניתן לנסות שוב; טיוטה בלי שורות מודפסת עם הערה. **באגים שתוקנו.** מונה בלי קריאה בקצה
התקופה גרם לכשל עיוור בהפקת ה־PDF; עכשיו מודפס מקף ושאר הכשלים מסבירים למה (`pdf_no_lines` / `pdf_invalid_snapshot`). **איך מפעילים.** אין מה להפעיל.

### מגבלות
- **שידור:** נבדק עם מדמים בלבד (ממסר, שידורים, מדיניות רכיב החיבור, מסכים מדומים); לא נוצר קשר עם Chromecast / טלוויזיה, מצלמה או go2rtc אמיתיים.
- **עורך הקידוד:** הוכח על מכשיר מדומה בלבד; לא ידוע אם ה־NVR של הבעלים מקבל גוף `streams` מלא.
- **PDF / קיר לייב:** בדיקות שרת ומסכים מדומים.
