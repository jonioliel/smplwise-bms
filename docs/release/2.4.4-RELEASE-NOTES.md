# SmplWise Arx 2.4.4 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.4.4, bilingual per item).

## 2.4.4 (pilot) — one design language (DU1), device types in Settings, Frigate review and activity window polish, brand colours, glass light / dark setting, self-update switch
**After installing:** **one database migration, 0073** (adds the table `device_type_override`; additive, the previous version ignores it; the sequence is now 0001..0073 without gaps), **no bridge change** (0.8.0 stays; no restart of the system infrastructure is needed for this release). Reload the installed web app once. Nothing new is switched on by itself: the accent and switch colours stay the system blue, the glass screens follow the product's light / dark as in DU1, and installing updates from Arx stays on.
- **עברית:** אחרי ההתקנה: **מיגרציה אחת, 0073** (מוסיפה את הטבלה `device_type_override`; תוספתית, הגרסה הקודמת מתעלמת ממנה; הרצף עכשיו 0001..0073 בלי חורים), **אין שינוי בגשר** (נשאר 0.8.0; אין צורך להפעיל מחדש את תשתית המערכת בגרסה זו). טוענים מחדש את אפליקציית הרשת פעם אחת. דבר חדש לא מופעל מעצמו: צבע ההדגשה וצבע המתג נשארים כחול המערכת, מסכי הזכוכית עוקבים אחרי הבהיר / כהה של המערכת כמו ב־DU1, והתקנת עדכונים מתוך Arx נשארת פעילה.

### One design language (DU1) - שפה עיצובית אחת
- **English - what changed:** the screens' literal font sizes, radii and recurring colours now read the design tokens (type and radius scales, control states, on-video HUD, toast tokens, one focus-ring rule); the glass screens (devices, schedules, automations, media, notifications) take the product accent, toggle and state colours instead of the mockup's iOS blue / green, and are never lighter than the shell (dark glass inside a dark product). A token-lint test keeps new literals out. Classic stays the same look apart from 0.5-1 px snaps to the scales.
- **English - how to use:** nothing to switch on.
- **עברית - מה השתנה:** גדלי הגופן, העיגולים והצבעים החוזרים של המסכים נקראים עכשיו מאסימוני העיצוב (סולמות טקסט ועיגול, מצבי פקדים, שכבת וידאו, הודעות קופצות, כלל אחד לטבעת המיקוד); מסכי הזכוכית (חשמל והתקנים, תזמונים, אוטומציות, מולטימדיה, התראות) מקבלים את צבע ההדגשה, המתג והמצבים של המוצר במקום הכחול / ירוק של iOS מהמוקאפ, ולעולם אינם בהירים יותר מהמסגרת (זכוכית כהה במוצר כהה). בדיקת אסימונים מונעת ערכים קבועים חדשים. המראה הקלאסי נשאר זהה מלבד יישור של 0.5-1 פיקסל לסולמות.
- **עברית - איך משתמשים:** אין מה להפעיל.

### Device types in Settings (DEVTYPE) - סוגי התקנים בהגדרות
- **English - what was added:** Settings › Electricity and devices › "Device types": every switch / virtual on-off helper with its place and its type (automatic by name, or fixed by whom and when). An administrator fixes the type per device or for many at once (search, filters, select, one confirmation), or returns it to automatic; the fixed type wins over the name-word guess in the cards and the activity window. Presentation only: the controls stay the device's own. New API `GET /devices/device-types`, `PUT /devices/entities/{id}/device-type`, `POST /devices/device-types` (`system.configure`, audited). Migration 0073; backed up, and an older backup keeps the current fixed types.
- **English - bugs fixed:** the climate-kind override (air conditioning / heating) is now in the project backup too (`device_climate_kind`); an older archive without it keeps the current rows.
- **English - how to use:** Settings › Electricity and devices › Device types (administrator).
- **עברית - מה נוסף:** הגדרות › חשמל והתקנים › "סוגי התקנים": כל מתג / עוזר הפעלה וכיבוי וירטואלי עם מיקומו והסוג שלו (אוטומטי לפי השם, או קבוע - מי קבע ומתי). מנהל קובע סוג להתקן אחד או לרבים יחד (חיפוש, מסננים, בחירה, אישור אחד), או מחזיר לאוטומטי; הסוג הקבוע גובר על הניחוש לפי השם בכרטיסים ובחלון הפעילות. תצוגה בלבד: הפקדים נשארים של ההתקן עצמו. API חדש `GET /devices/device-types`, `PUT /devices/entities/{id}/device-type`, `POST /devices/device-types` (`system.configure`, נרשם ביומן). מיגרציה 0073; נשמר בגיבוי, וגיבוי ישן משאיר את הסוגים הקבועים הנוכחיים.
- **עברית - תיקונים:** הקביעה הידנית של מיזוג / חימום למזגן נשמרת עכשיו גם בגיבוי הפרויקט (`device_climate_kind`); גיבוי ישן בלעדיה משאיר את השורות הנוכחיות.
- **עברית - איך משתמשים:** הגדרות › חשמל והתקנים › סוגי התקנים (מנהל).

### Frigate review screen polish (FRG) - ליטוש מסך הסקירה של Frigate
- **English - what changed:** skeleton first load, a dimmed refilter, empty-state actions ("clear filters", "show reviewed items too"), roving focus with Home / End, previous / next in the drawer, paging on scroll, a one-row filter strip on a phone, an "ongoing" marker; the zone editor inserts a point on an edge midpoint; the camera settings panel has a loading state; the supervised clip plays in an in-app viewer (a new tab stays as the second way). No API change.
- **English - how to use:** Investigate › Frigate review; Settings › Frigate recorder.
- **עברית - מה השתנה:** טעינה ראשונה עם שלד, סינון מחדש מעומעם, פעולות במצב ריק ("נקה מסננים", "הצג גם פריטים שנסקרו"), מיקוד נע עם Home / End, הקודם / הבא במגירה, טעינת עמוד בגלילה, שורת מסננים אחת בטלפון, סימון "מתמשך"; עורך האזורים מוסיף נקודה באמצע צלע; לוח הגדרות המצלמה מציג מצב טעינה; הקליפ בפיקוח מתנגן בנגן בתוך האפליקציה (לשונית חדשה נשארת כדרך שנייה). אין שינוי ב־API.
- **עברית - איך משתמשים:** חקירה › סקירת Frigate; הגדרות › מקליט Frigate.

### Activity window polish (ACT) - ליטוש חלון הפעילות
- **English - what changed:** the device activity window has two views (cards / dense list, kept per browser), tone markers per event, a sticky day line with its count, a clear chip with the number of narrowed filters, refresh, keyboard Home / End; on a phone the sheet is the only scroller. The equipment card gets a state dot. No API change.
- **English - how to use:** long-press a device (or its "Activity" menu item).
- **עברית - מה השתנה:** בחלון הפעילות של התקן שתי תצוגות (כרטיסים / רשימה צפופה, נשמר לכל דפדפן), סימון גוון לכל אירוע, שורת יום נצמדת עם הספירה, שבב ניקוי עם מספר המסננים, רענון, Home / End במקלדת; בטלפון רק הגיליון גולל. בכרטיס הציוד נקודת מצב. אין שינוי ב־API.
- **עברית - איך משתמשים:** לחיצה ארוכה על התקן (או "פעילות" בתפריט שלו).

### Brand colours - צבעי המותג
- **English - what was added:** Settings › General › "Brand colours": the accent colour (primary buttons, links, selection, focus) and the switch-on colour, each "default" (the system blue), a preset (iOS green - the earlier glass mockup's switch colour - iOS blue, teal, purple, orange, pink, graphite) or any colour from the picker. Applied on the DU1 token layer in every skin, light and dark, the glass screens included; a colour too light for white button text is flagged. Settings `ui.accent`, `ui.toggle_on` (`system.configure`, audited, in the backup).
- **English - how to use:** Settings › General › Brand colours (administrator) › pick › Save.
- **עברית - מה נוסף:** הגדרות › כללי › "צבעי המותג": צבע ההדגשה (כפתורים ראשיים, קישורים, בחירה, מיקוד) וצבע מתג פעיל, כל אחד "ברירת מחדל" (כחול המערכת), צבע מוכן (ירוק iOS - צבע המתג של מוקאפ הזכוכית, כחול iOS, טורקיז, סגול, כתום, ורוד, גרפיט) או כל צבע מבוחר הצבעים. חל על שכבת האסימונים של DU1 בכל הסגנונות, בהיר וכהה, כולל מסכי הזכוכית; צבע בהיר מדי לטקסט לבן מסומן באזהרה. ההגדרות `ui.accent`, `ui.toggle_on` (`system.configure`, נרשם ביומן, בגיבוי).
- **עברית - איך משתמשים:** הגדרות › כללי › צבעי המותג (מנהל) › בוחרים › שמור.

### Glass screens: light or dark - מסכי הזכוכית: בהיר או כהה
- **English - what was added:** Settings › Electricity and devices › "Glass screens: light or dark": follow the product's scheme (default, the DU1 rule), always light, or always dark - for the devices, schedules, automations, media and notification surfaces. Setting `devices.glass_scheme` (`system.configure`, audited, in the backup).
- **English - how to use:** Settings › Electricity and devices (administrator) › pick › Save.
- **עברית - מה נוסף:** הגדרות › חשמל והתקנים › "מסכי הזכוכית: בהיר או כהה": לפי צבעוניות המערכת (ברירת מחדל, הכלל של DU1), תמיד בהיר, או תמיד כהה - למסכי חשמל והתקנים, תזמונים, אוטומציות, מולטימדיה והתראות. ההגדרה `devices.glass_scheme` (`system.configure`, נרשם ביומן, בגיבוי).
- **עברית - איך משתמשים:** הגדרות › חשמל והתקנים (מנהל) › בוחרים › שמור.

### Self-update switch (CR-021) - מתג העדכון מתוך Arx
- **English - what was added:** Settings › Updates › "Updating from Arx": On (default, as before) / Off. Off: the "Update" button is replaced by a notice and `POST /system/update/apply` answers 409 `self_update_disabled` before the infrastructure is asked anything; an update already accepted but not yet sent is not sent. The check, the interval, the restarts and a manual update in the platform's own add-on store keep working - the switch can never lock anyone out and can always be turned back on. Setting `update.apply_enabled` (`system.configure`, its own audit row `system.update.apply_enabled`, in the backup). Security notes: `docs/security/CR021_SELF_UPDATE_SECURITY_NOTES.md` section 6.
- **English - how to use:** Settings › Updates › Updating from Arx (administrator).
- **עברית - מה נוסף:** הגדרות › עדכונים › "עדכון מתוך Arx": פעיל (ברירת מחדל, כמו קודם) / כבוי. כבוי: במקום הכפתור "עדכן" מוצגת הודעה, ו־`POST /system/update/apply` עונה 409 `self_update_disabled` לפני שתשתית המערכת נשאלת משהו; עדכון שהתקבל ועוד לא נשלח - לא נשלח. הבדיקה, הבדיקה האוטומטית, ההפעלות מחדש ועדכון ידני בחנות התוספים של תשתית המערכת ממשיכים לעבוד - המתג לא נועל אף אחד בחוץ ותמיד אפשר להחזיר אותו. ההגדרה `update.apply_enabled` (`system.configure`, שורת יומן משלה `system.update.apply_enabled`, בגיבוי).
- **עברית - איך משתמשים:** הגדרות › עדכונים › עדכון מתוך Arx (מנהל).
