### What was changed - מה השתנה
- **English:** Home-system users from Arx: a system administrator creates ordinary (never administrator) Home Assistant users with one Arx role, and deactivates, activates or deletes only the users Arx itself created (Settings > Users and permissions > home-system users; new permission `users.ha_manage`, system administrators only; every write also needs the person to be an active Home Assistant administrator). Deleting a user is refused while an Arx-only user is linked to it. Do not use it on a live installation before the one-time live check.
- **עברית:** משתמשי מערכת הבית מתוך Arx: מנהל מערכת יוצר משתמשי Home Assistant רגילים (לעולם לא מנהלים) עם תפקיד Arx אחד, ומשבית, מפעיל או מוחק רק משתמשים ש-Arx עצמו יצר (הגדרות > משתמשים והרשאות > משתמשי מערכת הבית; הרשאה חדשה `users.ha_manage`, למנהלי מערכת בלבד; כל שינוי דורש גם שהאדם יהיה מנהל פעיל ב-Home Assistant). מחיקת משתמש נחסמת כל עוד משתמש Arx בלבד מקושר אליו. אין להשתמש בזה בהתקנה חיה לפני הבדיקה החיה החד-פעמית.
- **English:** Arx-only users (people who must not have a Home Assistant account): one Arx role each (never system administrator), sign-in only through the remote address, first-login and reset links issued by an administrator, self-service password reset by a WhatsApp code, security notifications to the user, passkeys as a second factor or for passkey-first sign-in, and a service identity (one non-administrator Home Assistant user acts for them). Administrative permissions work only after a second factor; zone bypass, scripts, scenes and door unlock are never available to them. OFF by default (`security.local_identity`).
- **עברית:** משתמשי Arx בלבד (אנשים שאסור שיהיה להם חשבון Home Assistant): לכל אחד תפקיד Arx אחד (לעולם לא מנהל מערכת), כניסה רק דרך הכתובת המרוחקת, קישורי כניסה ראשונה ואיפוס שמנהל מנפיק, איפוס סיסמה עצמי בקוד בוואטסאפ, התראות אבטחה למשתמש, מפתחות גישה (Passkeys) כאימות שני או לכניסה עם מפתח בלבד, וזהות שירות (משתמש Home Assistant אחד שאינו מנהל פועל בשמם). הרשאות ניהול עובדות רק אחרי אימות דו-שלבי; עקיפת אזור, סקריפטים, סצנות ופתיחת דלתות לעולם לא זמינים להם. כבוי כברירת מחדל (`security.local_identity`).
- **English:** Capture lease for card enrolment at WisKey stations: the lease ledger, the signed revocation stream and the triggers that revoke a lease when a person's authority changes (also for Arx-only users) are built, OFF, and cannot be switched on in this build (a separate owner permit is needed).
- **עברית:** חכירת צילום לרישום כרטיסים בעמדות WisKey: יומן החכירות, זרם הביטול החתום והטריגרים שמבטלים חכירה כשסמכות של אדם משתנה (גם למשתמשי Arx בלבד) בנויים, כבויים, ואי אפשר להפעיל אותם בגרסה הזו (נדרש אישור נפרד של הבעלים).
- **English:** WisKey station passwords are stored encrypted with the installation's own key (converted once at start-up).
- **עברית:** סיסמאות עמדות WisKey נשמרות מוצפנות במפתח של ההתקנה (המרה חד-פעמית בהפעלה).
- **English:** Hardening: the vendor's number is checked again at send time, verification codes have caps, the WisKey connection test runs on a throwaway stream, Frigate auto-sync and event health fixes, and the documentation warns that a Home Assistant add-on backup holds both the key file and the database.
- **עברית:** הקשחה: המספר של הספק נבדק שוב ברגע השליחה, לקודי האימות יש תקרות, בדיקת החיבור ל-WisKey רצה על זרם זמני, תיקונים בסנכרון האוטומטי של Frigate ובבריאות האירועים, והתיעוד מזהיר שגיבוי תוסף של Home Assistant מכיל גם את קובץ המפתח וגם את המסד.
- **English:** Work order from an awarded quote: after the award, one service request per chosen vendor is prepared from the quote request, shown as a preview and sent only on an explicit "send". Quotes carry a "valid until" date, and the quote-request managers get notifications about their requests.
- **עברית:** הזמנת עבודה מהצעה שנבחרה: אחרי הבחירה נוצרת מבקשת הצעת המחיר בקשת שירות אחת לכל ספק שנבחר, מוצגת בתצוגה מקדימה ונשלחת רק בלחיצה מפורשת על "שליחה". להצעות יש תאריך "בתוקף עד", ומנהלי בקשות הצעת המחיר מקבלים התראות על הבקשות שלהם.
- **English:** Vendor area on the public page: a vendor opens `/support` without a link, types his mobile number and signs in with a one-time WhatsApp code; for 30 minutes he sees, read-only, his open requests and the ones closed in the last months, with the quote and the payment request (amount and state). By default only a number its owner confirmed gets a code. The public pages show the organisation logo when one is set. OFF by default.
- **עברית:** אזור ספקים בדף הציבורי: ספק פותח את `/support` בלי קישור, מקליד את הנייד שלו ונכנס עם קוד חד-פעמי בוואטסאפ; במשך 30 דקות הוא רואה, לצפייה בלבד, את הבקשות הפתוחות שלו ואת אלה שנסגרו בחודשים האחרונים, עם הצעת המחיר ודרישת התשלום (סכום ומצב). כברירת מחדל קוד נשלח רק למספר שבעליו אישר אותו. הדפים הציבוריים מציגים את לוגו הארגון כשהוא מוגדר. כבוי כברירת מחדל.
- **English:** Organisation locations: a new Settings tab (name, address, access details, optional coordinates; an organisation default and a default per department; a used location is deactivated, never deleted) and a location picker on the service request and quote request forms; the request keeps the address as it was on the day it was opened, and the vendor gets it in the message and on his page.
- **עברית:** מיקומי הארגון: לשונית חדשה בהגדרות (שם, כתובת, פרטי גישה, קואורדינטות לא חובה; ברירת מחדל לארגון וברירת מחדל לכל מחלקה; מיקום שכבר נבחר מושבת ולא נמחק) ובורר מיקום בטופס בקשת שירות ובטופס בקשת הצעת מחיר; הבקשה שומרת את הכתובת כפי שהייתה ביום פתיחתה, והספק מקבל אותה בהודעה ובדף שלו.
- **English:** Navigation link in messages: the send dialog of a quote request and the "send to an outside handler" dialog of a service request have a switch "attach a navigation link" (off by default; shown only for a location with coordinates); the preview shows exactly the message that will be sent.
- **עברית:** קישור ניווט בהודעות: בחלון השליחה של בקשת הצעת מחיר ובחלון "שליחה לגורם חיצוני" של בקשת שירות יש מתג "לצרף קישור ניווט להודעה" (כבוי כברירת מחדל; מוצג רק למיקום עם קואורדינטות); התצוגה המקדימה מראה בדיוק את ההודעה שתישלח.
- **English:** Department managers manage the handlers and vendors of their own departments without the settings permission (new permission `tickets.handlers`): add or remove members, attach or detach staff without an account, vendors and contacts, create new records. Phone numbers are masked (last four digits) unless a system administrator turns on "department managers see full numbers". Every action is audited.
- **עברית:** מנהלי מחלקה מנהלים את המטפלים והספקים של המחלקות שלהם בלי הרשאת הגדרות (הרשאה חדשה `tickets.handlers`): הוספה והסרה של חברים, שיוך והסרה של עובדים בלי חשבון, ספקים ואנשי קשר, ויצירת רשומות חדשות. מספרי הטלפון מוסתרים (ארבע ספרות אחרונות) אלא אם מנהל מערכת מדליק "מנהלי מחלקה רואים מספרים מלאים". כל פעולה נרשמת ביומן הביקורת.
- **English:** Handler cards show how many requests each handler handled, with a period selector (today / 7 days / month; default 7 days, the installation default is set in Settings > service management > display).
- **עברית:** כרטיסי המטפלים מציגים כמה בקשות כל מטפל טיפל, עם בורר תקופה (היום / 7 ימים / חודש; ברירת מחדל 7 ימים, ברירת המחדל של ההתקנה נקבעת בהגדרות > ניהול השירות > תצוגה).
- **English:** Files and pictures on quote requests: pictures and PDF always, Word and Excel only when switched on (off by default); up to 10 files per request; pictures are re-saved without location data, documents are checked before they are kept; every invited vendor gets the same files through his link, and an awarded vendor keeps them in the work order.
- **עברית:** קבצים ותמונות בבקשות הצעת מחיר: תמונות ו-PDF תמיד, Word ו-Excel רק כשמדליקים (כבוי כברירת מחדל); עד 10 קבצים לבקשה; תמונות נשמרות מחדש בלי נתוני מיקום, מסמכים נבדקים לפני שהם נשמרים; כל ספק שהוזמן מקבל את אותם קבצים בקישור שלו, וספק שנבחר ממשיך לראות אותם בהזמנת העבודה.
- **English:** Vendor questions are visible: a separate "question to the organisation" field on the quote form, red badges with the number of pending questions (list, request header, vendor row, comparison, the quote requests tab), a "pending questions" section at the top of the request with "reply" and "handled without a reply", and a reminder notification for a question left unanswered.
- **עברית:** שאלות ספקים גלויות: שדה נפרד "שאלה לארגון" בטופס ההצעה, תגים אדומים עם מספר השאלות הממתינות (רשימה, כותרת הבקשה, שורת הספק, ההשוואה, לשונית בקשות הצעת המחיר), אזור "שאלות ממתינות" בראש הבקשה עם "מענה" ו"טופל בלי תשובה", והתראת תזכורת לשאלה שנשארה בלי מענה.
- **English:** Payment schedule and arrival confirmation on a quote request (off by default): the vendor may propose a down payment, up to four interim payments and the balance; the approver confirms or edits the schedule at the award and may set a planned arrival date; the vendor confirms the arrival date (or proposes another) on his link; a payment demand above the agreed schedule is flagged for review, never refused. ### What is OFF by default and how to enable - מה כבוי כברירת מחדל ואיך מפעילים
- **English:** Home-system users: no switch, but the screen is for system administrators only and must not be used before the one-time live check; if the check says the add-on is not authorised, save an administrator token in Settings > Connections > Secrets. Arx-only users: Settings > Security (`security.local_identity`, system administrator; switching it off ends every Arx-only session). Capture lease: cannot be switched on in this build. Vendor area: Settings > service management > General > the handler page card - "vendor area", "closed requests to show (months back)", "the portal requires a number confirmed by code" (on by default). Word / Excel attachments: `rfq.attachments.allow_office` (system administrator). Payment schedule and arrival: Settings > service management > General > quote requests: payment schedule and arrival date. Department managers: give the manager the permission `tickets.handlers`; full phone numbers: Settings > service management > messaging channel > "department managers see full numbers". Navigation link: the switch in each send dialog.
- **עברית:** משתמשי מערכת הבית: אין מתג, אבל המסך למנהלי מערכת בלבד ואין להשתמש בו לפני הבדיקה החיה החד-פעמית; אם הבדיקה אומרת שלתוסף אין הרשאה, שומרים אסימון מנהל בהגדרות > חיבורים > סודות. משתמשי Arx בלבד: הגדרות > אבטחה (`security.local_identity`, מנהל מערכת; כיבוי מנתק כל כניסה של משתמשי Arx בלבד). חכירת צילום: אי אפשר להפעיל בגרסה הזו. אזור ספקים: הגדרות > ניהול השירות > כללי > כרטיס דף המטפלים - "אזור ספקים", "סגורות להצגה (חודשים אחורה)", "הפורטל דורש מספר שאושר בקוד" (פעיל כברירת מחדל). צירוף Word ו-Excel: `rfq.attachments.allow_office` (מנהל מערכת). לוח תשלומים ומועד הגעה: הגדרות > ניהול השירות > כללי > בקשות הצעת מחיר: לוח תשלומים ומועד הגעה. מנהלי מחלקה: נותנים למנהל את ההרשאה `tickets.handlers`; מספרים מלאים: הגדרות > ניהול השירות > ערוץ הודעות > "מנהלי מחלקה רואים מספרים מלאים". קישור ניווט: המתג בכל חלון שליחה.

### How to use - איך משתמשים
- **English:** Organisation locations: Settings > service management > Locations. Handled count: the period selector at the top of the handlers cards. Work order: award on the quote comparison, then the work-order preview and "send". Vendor questions: the badges lead to the "pending questions" section of the request. Vendor area: connect the WhatsApp account first, confirm the vendor's number (contacts directory > the vendor's card > "send code" > "verify"), then switch the area on. **Cloudflare:** the tunnel route `^/support(/.*)?$` is case-sensitive - add a route for other letter cases (`/Support`) or tell vendors the lowercase address; add a tighter rate-limit rule on `/support/api/portal/*` while the vendor area is on and on the file paths `/support/api/rfq/file/*` and `/support/api/ticket/rfq-file/*`; never "Cache Everything" (or an edge TTL that overrides the server) on `/support/api/*` - set it to "Bypass cache". Rollback: revert the release; every migration only adds tables and columns, so an older version ignores them (the Arx-only users, locations, files, schedules, questions and vendor-area data are not seen by an older version). Exception: the start-up conversion blanks the plain WisKey station passwords, so after a rollback the station passwords must be entered again.
- **עברית:** מיקומי הארגון: הגדרות > ניהול השירות > מיקומים. מספר הטיפולים: בורר התקופה בראש כרטיסי המטפלים. הזמנת עבודה: בוחרים ספק בהשוואת ההצעות, ואז תצוגה מקדימה של הזמנת העבודה ו"שליחה". שאלות ספקים: התגים מובילים לאזור "שאלות ממתינות" בבקשה. אזור ספקים: קודם מחברים את חשבון הוואטסאפ, מאשרים את המספר של הספק (ספריית אנשי הקשר > כרטיס הספק > "שליחת קוד" > "אימות"), ורק אז מדליקים את האזור. **Cloudflare:** מסלול המנהרה `^/support(/.*)?$` רגיש לאותיות - מוסיפים מסלול לכתיב אחר (`/Support`) או אומרים לספקים את הכתובת באותיות קטנות; מוסיפים כלל הגבלת קצב הדוק יותר על `/support/api/portal/*` כשאזור הספקים פעיל ועל נתיבי הקבצים `/support/api/rfq/file/*` ו-`/support/api/ticket/rfq-file/*`; אסור "Cache Everything" (או Edge TTL שגובר על השרת) על `/support/api/*` - מגדירים לו "Bypass cache". החזרה לאחור: החזרת הגרסה; כל המיגרציות רק מוסיפות טבלאות ועמודות, ולכן גרסה ישנה מתעלמת מהן (משתמשי Arx בלבד, מיקומים, קבצים, לוחות תשלומים, שאלות ונתוני אזור הספקים לא נראים בגרסה ישנה). חריג: ההמרה בהפעלה מרוקנת את סיסמאות עמדות WisKey הגלויות, ולכן אחרי החזרה לאחור יש להזין שוב את סיסמאות העמדות.

### Known limits - מגבלות ידועות
- **English:** Open question: the password hashes of Arx-only users travel in the administrator export bundle with the other access tables (excluding them would mean an administrator reset after a restore). Word / Excel attachments fail closed while switched off: such an upload is refused, and Word / Excel files already attached stop reaching vendors (and the work order) until the setting is on again. The organisation logo has no upload controls in Settings yet (the server side works; the controls come in a later version). Home-system users: a user deleted in Home Assistant itself (outside Arx) leaves a stale link to an Arx-only user. The bridge 0.9.0 is not yet installed on a real system; no live device, Home Assistant, WhatsApp or Cloudflare check was made for this release.
- **עברית:** שאלה פתוחה: גיבובי הסיסמאות של משתמשי Arx בלבד נכנסים לחבילת הייצוא של המנהל יחד עם שאר טבלאות הגישה (הוצאתם תחייב איפוס על ידי מנהל אחרי שחזור). צירוף Word ו-Excel נכשל באופן סגור כשהוא כבוי: העלאה כזו נדחית, וקבצי Word ו-Excel שכבר צורפו מפסיקים להגיע לספקים (וגם להזמנת העבודה) עד שמדליקים שוב. ללוגו הארגון עדיין אין כפתורי העלאה בהגדרות (צד השרת עובד; הכפתורים יגיעו בגרסה מאוחרת יותר). משתמשי מערכת הבית: משתמש שנמחק ב-Home Assistant עצמו (מחוץ ל-Arx) משאיר קישור יתום למשתמש Arx בלבד. הגשר 0.9.0 עדיין לא הותקן במערכת אמיתית; לא נעשתה בדיקה חיה מול התקנים, Home Assistant, וואטסאפ או Cloudflare לגרסה הזו.
