# SmplWise Arx 2.0.5 - Release notes / הערות שחרור

Source of truth for the text below: smplwise_vms/CHANGELOG.md (section 2.0.5, bilingual per item).

## 2.0.5 (pilot) - Generator control screen (view only); wall display mode; Home Assistant restart status; push relay deploy-ready

**After installing:** migrations `0061_generator` and `0062_wall_profiles` run on start. The bridge stays 0.7.0. Reload the installed web
app once. **Wall display mode is off** until a wall profile exists for a user; **the generator tab appears only when a generator
controller device is detected.**

### Generator control screen (CR-031)
**Added.** Generator tab under Infrastructure: live status and power flow, engine and controller, per-phase voltage / current / power,
gauges, charts with history, active alerts with acknowledge, history, device picker for several generators; Settings › Infrastructure ›
Generator (mapping, thresholds, alert routing starting empty, Hebrew templates with server preview). View and alerts only, no command to the
controller. **Bugs fixed.** None (new). **How to enable.** It appears under Infrastructure when the Home Assistant device list holds a
generator controller (DSE / ComAp class) and the user has the view permission; an administrator maps sensors and routing in Settings.

### Wall display mode (CR-030)
**Added.** A wall user on a fixed tablet: automatic switch to the wall interface after sign-in on a tablet, live cameras and map, schedule
windows, alert tiles with takeover and chip, photo frame, Settings › Wall displays. Remote sessions are refused.
**Bugs fixed.** None (new). **How to enable.** Settings › Wall displays › create a wall profile for a user (kiosk role + `wall.view`,
floor or cameras chosen), then sign that user in on the tablet (tablet detection, no pairing).

### Home Assistant restart status (HA1)
**Added.** Plain Hebrew status while the infrastructure restarts or is unreachable; sync back-off capped at 15 s for five minutes after a
restart. **Bugs fixed.** Restart failures were not told apart and were retried too hard (`ha_restarting` / `ha_unreachable`).
**How to enable.** Nothing.

### Push relay (RELAY1)
**Added.** Cloudflare Worker `services/push-relay` (27 tests) and the Hebrew owner guide. **Bugs fixed.** None. **How to enable.** The owner
deploys it by the guide (Firebase / Apple accounts first); not deployed, never tried against real Apple / Google.

### Known limits
- Generator and wall display: fakes, mocks and Playwright evidence only; no real DSE controller, tablet or live system was contacted.
- Push relay: unit tests only.

## עברית - 2.0.5: מסך שליטה בגנרטור (צפייה בלבד); מצב מסך קיר; מצב כשהתשתית מופעלת מחדש; ממסר ההתראות מוכן להעלאה

**אחרי ההתקנה:** המיגרציות `0061_generator` ו־`0062_wall_profiles` רצות בהפעלה. רכיב החיבור נשאר 0.7.0. טוענים מחדש את אפליקציית
הרשת פעם אחת. **מצב מסך קיר כבוי** עד שנוצר פרופיל קיר למשתמש; **לשונית הגנרטור מופיעה רק כשמזוהה בקר גנרטור.**

### מסך שליטה בגנרטור (CR-031)
**מה נוסף.** לשונית גנרטור תחת תשתיות: מצב חי וזרימת הספק, מנוע ובקר, מתח / זרם / הספק לפי פאזה, מדים, גרפים עם היסטוריה, התראות
פעילות עם אישור, היסטוריה, בורר כשיש כמה גנרטורים; הגדרות › תשתיות › גנרטור (מיפוי, ספים, ניתוב שמתחיל ריק, נוסחים בעברית עם תצוגה
מקדימה). צפייה והתראות בלבד. **באגים שתוקנו.** אין (חדש). **איך מפעילים.** מופיעה תחת תשתיות כשברשימת ההתקנים של Home Assistant
יש בקר גנרטור ולמשתמש הרשאת צפייה; מנהל ממפה חיישנים וניתוב בהגדרות.

### מצב מסך קיר (CR-030)
**מה נוסף.** משתמש קיר בטאבלט קבוע: מעבר אוטומטי לממשק הקיר אחרי כניסה בטאבלט, מצלמות לייב ומפה, חלונות זמן, אריחי התראות עם
השתלטות ותג, מסגרת תמונות, הגדרות › מסכי קיר. כניסה מרחוק נדחית. **באגים שתוקנו.** אין (חדש). **איך מפעילים.** הגדרות › מסכי קיר ›
יוצרים פרופיל קיר למשתמש (תפקיד kiosk + `wall.view`, קומה או מצלמות), ואז מחברים אותו בטאבלט (זיהוי טאבלט, בלי צימוד).

### מצב כשהתשתית מופעלת מחדש (HA1)
**מה נוסף.** סטטוס בעברית פשוטה בזמן הפעלה מחדש או חוסר זמינות; האטת סנכרון עד 15 שניות למשך חמש דקות. **באגים שתוקנו.** כשלי הפעלה
מחדש לא הובחנו ונוסו מחדש בעוצמה מדי. **איך מפעילים.** אין מה להפעיל.

### ממסר התראות (RELAY1)
**מה נוסף.** Worker של Cloudflare (`services/push-relay`, 27 בדיקות) ומדריך הפריסה בעברית. **באגים שתוקנו.** אין. **איך מפעילים.** הבעלים
מעלה לפי המדריך (קודם חשבונות Firebase / Apple); לא הועלה ולא נוסה מול Apple / Google.

### מגבלות ידועות
- גנרטור ומסך קיר: דמויות, דמי־נתונים וראיות Playwright בלבד; לא נוצר קשר עם בקר DSE, טאבלט או מערכת חיה.
- ממסר ההתראות: בדיקות יחידה בלבד.
