זיהוי טאבלט והמעבר האוטומטי למצב מסך קיר

אותו משתמש מסך קיר (reception-wall, תפקיד קיוסק) מתחבר משלושה מכשירים. הכניסה היא ההתחברות הרגילה של המערכת. רק מכשיר שזוהה כטאבלט עובר למצב מסך קיר; בטלפון ובמחשב רואים את המערכת הרגילה - מפה ווידאו חי בלבד, כפי שהתפקיד מגביל. הזיהוי הוא הצגה בלבד: ההרשאות בשרת לא תלויות בו. מסמך השינוי: docs/changes/CR-030-WALL-DISPLAY.md סעיף 3.2.

הכלל

class = desktop   if not touch
        phone     if touch and short < 600
        phone     if touch and mobileUA and short < 700     // large phone, folded foldable
        tablet    otherwise

touch    = maxTouchPoints > 0 && (matchMedia('(pointer: coarse)') || matchMedia('(hover: none)'))   // primary pointer is touch
short    = min(screen.width, screen.height)            // physical screen in CSS px - not the viewport (keyboard, split screen, rotation do not change it)
mobileUA = navigator.userAgentData?.mobile ?? /Mobi|iPhone|iPod/.test(navigator.userAgent)
