# Plan Studio 6 mockups (CR-029)

Static HTML stand-ins for the three proposed modes of `docs/changes/CR-029-PLAN-STUDIO-6-REALISTIC-3D.md`. They are
design intent, not build screenshots: the "3D" is inline SVG / CSS 3D, the numbers are illustrative.

| File | Shows | CR section |
|---|---|---|
| `01-realistic-iso.html` | Quality level 3 on the floor map: materials by room, sun by hour, window daylight, emissive lamps, state layer, the new "ריאליסטי" and "סיור" chips, the material picker in the editor panel, the fallback ladder | §3.1, §3.3, §3.4, §6 |
| `02-eye-level-walk.html` | The walk-through on a tablet and a phone: HUD, walk bar with numeric fields, saved positions, stand-at-camera / in-room, minimap, device popover, virtual joystick, tap-to-walk hint | §4 |
| `03-stills-kiosk-fallback.html` | Stills + per-room masks on a kiosk at night after the idle timer, the dashboard card fed by the same assets, the bake card and the new settings | §3.2, §3.3, §5.3, §7 |

Screenshots (desktop width, Chromium): `shots/01-realistic-iso.png`, `shots/02-eye-level-walk.png`,
`shots/03-stills-kiosk-fallback.png` - taken from these files on 2026-10-05.

Open directly in a browser (RTL, Hebrew UI, English identifiers). No external assets, no scripts.
