# Designer handoff package (2026-09-30)

The self-contained brief for redesigning the whole SmplWise Arx UI in one design language ("hi-tech Domus" first; the facts are
direction-agnostic). Written for a designer or design agent who has never seen the code. Owner-facing narrative in Hebrew, inventories
in English.

| File | Language | Purpose |
|---|---|---|
| `DESIGN_HANDOFF_HE.md` | HE | The brief: scope, product in one page, direction, hard constraints, token contract summary, deliverable format, acceptance criteria, process |
| `SCREEN_INVENTORY.md` | EN | Every route / screen with roles, viewports, screenshot, components, states; screens still to come; roles |
| `COMPONENT_INVENTORY.md` | EN | Every `sw-*` component, shell element and recurring pattern with variants, states and RTL notes |
| `TOKEN_CONTRACT.md` | EN | Every design token (`--sw-*`, `--dv-*`, knobs) with current values, naming rules, fixed vs free, what must come back |
| `REFERENCE_BOARD.md` | EN | The curated current screenshots in `current/` and the external references, with what each shows |
| `HANDOFF_CODEX_HE.md` | HE | How the owner hands the package to an outside agent and compares results fairly |
| `COMPARISON_TASK_HE.md` | HE | The bounded round-1 task given identically to two entrants, with the scoring rubric and sheet |
| `current/` | — | 55 PNG screenshots of the current build and the approved mockups (named `<screen>-<viewport>.png`) |

Returned designs go to `returned/<entrant>/`; the decision to `returned/DECISION_HE.md`.
