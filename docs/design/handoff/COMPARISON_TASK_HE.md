## 1. המשימה

### 1.1 יסודות (Foundations), light + dark

עמוד לכל קבוצה, ערכי light ו-dark זה לצד זה, ניגודיות מודפסת ליד כל צמד טקסט/משטח:

1. **צבע:** קנבס, 3 רמות משטח (זכוכית + fallback אטום), קווי שיער, overlay; טקסט ×4; accent ×4 + focus; 9 צבעי מצב + `-soft`; glow
   "דולק" (חם / קר / מתג); 7 תפקידי צבע לכרטיסים. (הרשימה המדויקת: `TOKEN_CONTRACT.md` §3–§4.)
2. **סקאלת טיפוגרפיה:** משפחה (עברית ראשונה, עם רישיון), H1 גדול (בסגנון Domus), H2, כותרת מקטע, גוף, כיתוב, ספרות טבלאיות, קריאה
   גדולה (שעון, טמפרטורה); גדלים, משקלים, line-height, tracking.
3. **רדיוסים:** פקד / אריח / פאנל / דיאלוג / pill.
4. **צללים:** 3 רמות + אגודל פקד, light/dark, highlight עליון אם יש.
5. **חומר הזכוכית:** blur, saturate, אלפות ל-3 רמות, כלל קינון, fallback אטום, התנהגות ב-`prefers-contrast: more`.
6. **תנועה:** 3 משכים + easing; כניסה/יציאה של drawer, bottom sheet, dialog, popover; tab thumb; toggle; glow; hover lift; reduced-motion.
7. **Focus ring:** צבע, עובי, offset, על בהיר / כהה / זכוכית / וידאו.

## 3. אילוצים (10 שורות)

1. עברית RTL תחילה; כל הכיוונים לוגיים; מראה LTR למעטפת + הבית + האזור.
2. סרגל צד בקצה ההתחלה (מחשב) ופס תחתון (טלפון). **אין פס עליון.** חיפוש ובריאות — בפינה צפה.
3. יעדי מגע ≥ 44px לכל פקד במסכי המפעיל (הגודל החזותי יכול להיות קטן יותר).
4. בלי פסקאות, רמזים או badges של זכאות במסכי המפעיל; אישור = שאלה + ספירה + 2 כפתורים + "פרטים" מקופל.
5. אין "Home Assistant" / HA / Supervisor / Ingress / תוסף / Companion בשום טקסט. המוצר: Arx. הפלטפורמה: "תשתית המערכת".
6. נראות לפי הרשאות: פקד/לשונית שאין הרשאה אליהם לא מוצגים (לא אפורים). לוח המצבים כולל read-only.
7. מסגרת WisKey לא נוגעים בה — לא בהיקף המשימה, אבל הסרגל חייב להכיל את האזור "WisKey".
8. קיר המצלמות זול: אין blur / צל כבד / אנימציה על אריחי וידאו; snapshot מסומן "צילום"; מצבי אריח בצורה + טקסט, לא בצבע בלבד.
9. light + dark שווי מעמד; ניגודיות טקסט גוף ≥ 4.5:1 גם על זכוכית; fallback אטום לכל משטח שקוף; reduced-motion = אפס תנועה.
10. גאומטריה (וידאו, מפה, ציר זמן) לא משתקפת ב-RTL; אין העתקת קוד/CSS/SVG/טקסט מ-DomusUI או מכל מקור אחר.
