# מה חדש בגרסאות 2.43.9, 2.44.0 ו-2.45.0

Source: original

> עמוד אחד לאנשי התפעול ולמנהל המערכת, בעברית ואחריה באנגלית. נכתב מהערות השחרור ומתיעוד השינויים, **לא מבדיקה על מערכת
> חיה**. אין בשלוש הגרסאות מיגרציה חדשה, והגשר נשאר 0.10.7, ולכן אין צורך להפעיל מחדש את מערכת הבית.

## אחרי העדכון

1. טוענים מחדש את הדף פעם אחת אחרי כל עדכון (הממשק נבנה מחדש).
2. שום דבר חדש לא נדלק מעצמו. ייצוא היומן זמין רק למי שמורשה לנהל את הגדרות המערכת.
3. המתגים, ההודעות הקצרות והטבלאות נראים קצת אחרת (גודל וצבעים), בלי שינוי בפעולה.

## 2.43.9

| יומן התזכורות בתחזוקה | יומן ארוך מוצג בעמודים במקום בגלילה (לפי ההגדרה "רשימות ארוכות") |
| כניסת אפליקציית הטלפון | אחרי יציאה, ביטול או "יציאה מכל המכשירים" הכניסה נפסקת מיד. שינוי הרשאות או השבתת משתמש חלים כבר בפעולה הבאה |
| לוח הטלוויזיה | ערכים שמגיעים מהפיד מוצגים כטקסט פשוט בלבד; גופני הלובי נטענים רק לפי סגנון התצוגה |
| מקלדת | שורות וכרטיסים שלוחצים עליהם נפתחים גם ב-Enter וברווח |
| אירועים | טבלת חלונות הבדיקה מעוצבת, ותג החומרה זהה בכל המסכים (קריטי באדום) |
| הקלטות | רשת ה-2x2 נכנסת בחלון בלי גלילה |
| חשמל ושמות | שאר מסכי החשמל מתורגמים, וטופס לקוח אחד משותף; שם מערכת הבית כבר לא מופיע במסכי התפעול (רק בהגדרות) |

## 2.44.0

| מה | מה רואים |
|---|---|
| ייצוא יומן מצונזר | **הגדרות › בריאות ומשימות**, כרטיס "ייצוא יומן מצונזר". בוחרים חלון זמן (ברירת מחדל שעה) ורמה (ברירת מחדל: מידע ומעלה), ולוחצים "ייצוא היומן". אחרי חלון אישור יורד קובץ עם שורות היומן האחרונות, מזהה הבקשה של כל שורה, בדיקות המערכת והמלצה לכל תקלה. סיסמאות, אסימונים, פרטי גישה בכתובות, כתובות IP ו-MAC, מספרים סידוריים, טלפונים ודוא"ל מוסתרים; וידאו, תמונות ותוכניות לא נכללים לעולם. הכרטיס מופיע רק למי שמורשה לנהל את הגדרות המערכת, והייצוא נרשם ביומן הביקורת |
| שמות תעריף באנגלית | בעורך התעריף לפי שעות אפשר לתת לכל עונה, סוג יום ורצועה שם באנגלית (רשות, עד 40 תווים, בלי אותיות עבריות). הממשק באנגלית מציג אותו; לתבנית הישראלית כבר יש שמות באנגלית. החשבונית העברית לא משתנה |
| מתגים אחידים | מתגי ההפעלה בהתראות, אוטומציות, לוחות זמנים, עורך השלט, אזעקה, מיתוג, מיפוי, מפת ההיסטוריה, הגדרות האירועים ומסיכות הפרטיות הם עכשיו אותו מתג. הגודל והצבעים משתנים מעט |
| הודעות קצרות | 32 מסכים משתמשים באותו בקר: הודעה שנייה מקבלת את מלוא הזמן שלה, ושום הודעה לא מופיעה אחרי שעוזבים את המסך |
| הקלטות | העמוד נכנס במלואו למסך גם כשמוצגת שורת האבחון (הייתה גלישה של כמה פיקסלים) |
| חשמל ומים | כרטיס הלקוח הוא טופס אחד משותף, עם אותם שדות ואותן בדיקות |

| לוח הטלוויזיה | אותיות לטיניות וספרות בסגנונות Lumen, ‏Axis ו-Prism בגופן הנכון |

# What is new in 2.43.9, 2.44.0 and 2.45.0

> One page for operators and the system administrator. Written from the release notes and the change records, **not from a
> live installation**. The three builds carry no new migration and the bridge stays 0.10.7, so the home system does not need a restart.

## After the update

1. Reload the page once after each update (the interface is rebuilt).
2. Nothing new switches itself on. The log export is offered only to a user allowed to manage the system settings.
3. Switches, short messages and tables look slightly different (size and colours); they behave the same.

## 2.43.9

| What | What you see |
|---|---|
| Languages | English, Arabic and Russian load only when chosen. The first load of the Hebrew interface is about a quarter smaller, so it opens faster |
| Maintenance reminder log | A long log is shown in pages instead of scrolling (per the "long lists" setting) |
| Phone-app sign-in | After sign-out, revoke or "sign out everywhere" the sign-in stops at once. A permission change or a disabled user applies from the next action |
| TV board | Values from the feed are shown as plain text only; lobby fonts load per display style only |
| Keyboard | Clickable rows and cards also open with Enter and Space |
| Events | The review-windows table is styled and the severity badge is the same on every screen (critical in red) |
| Recordings | The 2x2 grid fits the window without scrolling |
| Electricity and names | The remaining electricity screens are translated and share one customer form; the home platform's name no longer appears on operator screens (Settings only) |

## 2.44.0

| What | What you see |
|---|---|
| Redacted log export | **Settings > Health and jobs**, card "Redacted log export" (ייצוא יומן מצונזר). Choose a time window (default one hour) and a level (default: information and above), then "Export the log". After a confirmation a file downloads with the latest log lines, each line's request id, the system checks and a recommendation for each problem. Passwords, tokens, credentials inside addresses, IP and MAC addresses, serial numbers, phone numbers and e-mail are hidden; video, pictures and plans are never included. The card is shown only to a user allowed to manage the system settings, and the export is recorded in the audit log |
| English tariff names | In the time-of-use tariff editor every season, day type and band can carry an optional English name (up to 40 characters, no Hebrew letters). The English interface shows it; the Israeli template already has English names. The Hebrew bill does not change |
| One switch everywhere | The on/off switches in notifications, automations, schedules, the remote editor, the alarm, branding, mapping, the history map, the incident settings and the privacy masks are now the same switch; size and colours change slightly |
| Short messages | 32 screens use one controller: a second message gets its full time, and nothing appears after you leave the screen |
| Recordings | The page fits the screen even with the diagnostics row shown (it overflowed by a few pixels) |
| Electricity and water | The customer card is one shared form with the same fields and checks |
| Phone | A tap on a folding heading or a label in a bottom sheet is no longer lost |
| TV board | Latin letters and digits in the Lumen, Axis and Prism styles use the right font |

## 2.45.0

| What | What you see |
|---|---|
| Shared table | The electricity and water tables, generator, maintenance, temperature log, recent incidents, waste, read receipts and the fleet report: one header, one set of state colours, a row opens by click or keyboard. At 1024 px the table fits its card with no sideways scroll |
| One segmented control | Most segmented choosers (settings, calendars, tickets, notifications, access, WisKey) are now one control, and the chip rows one chip chooser. The glass screens keep their look. Drop-downs in forms sit in a shared field |
| "Not yet" in electricity and water | An account without a customer, an active period or a next period, and a bill whose total the user may not see, show a dash or "not yet" instead of an error, NaN or 0 |
| Alarm and devices | A hidden zone no longer breaks the alarm screen; a camera sync that succeeded on no recorder no longer breaks the devices screen |
| Notices | A permission on a deleted site or building no longer applies to its floors, in a notice's audience and in the read receipts |
| Short messages | Seven more screens moved to the shared controller |
