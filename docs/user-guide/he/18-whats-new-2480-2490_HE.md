# מה חדש בגרסאות 2.48.0 ו-2.49.0

Source: original

> עמוד אחד לאנשי התפעול ולמנהל המערכת, בעברית ואחריה באנגלית. נכתב מהערות השחרור ומתיעוד השינויים, **לא מבדיקה על מערכת
> חיה**. בשתי הגרסאות אין מיגרציה חדשה ואין שינוי בגשר (נשאר 0.10.8).

## אחרי העדכון

1. אין צורך בהפעלה מחדש של מערכת הבית.
2. טוענים מחדש את הדף פעם אחת אחרי כל עדכון (הממשק נבנה מחדש).
3. שום דבר חדש לא נדלק מעצמו. העמודים בטבלת הקריאות (2.49.0) פועלים כברירת מחדל, ואפשר לחזור לגלילה (ראו למטה).

## 2.48.0

| מה | מה רואים |
|---|---|
| מתגים | תיבות סימון ומתגים שנבנו ביד להגדרה אחת של כן/לא הם עכשיו המתג המשותף, בגודל קומפקטי. מתגי מסך הבית ושורות ההגדרות לא השתנו |
| תיבות בחירה | כל תיבות הבחירה במסכי ההגדרות יושבות בשדה המשותף (תווית, מסגרת ושגיאה אחידות). הבחירה עצמה ובורר הטלפון לא השתנו |
| בלי גלילה במסכי בקרה | חיישני האזעקה, רשימת הגישה החיצונית ורשימת "מי במבנה" מתחלקות לעמודים כשיש יותר שורות ממה שנכנס. עם ההגדרה "גלילה" הן נגללות כמו קודם |
| מראה לפי מודול | בכל 14 דפי ההגדרות עם בורר מקטעים כל מודול שומר על המקש שלו (28 פיקסלים במחשב, 44 במגע בטלפון) |
| מרכז האירועים והגנרטור | השבבים במרכז האירועים חזרו למראה של 2.47.0; בגנרטור בוחרי הנמענים והערוצים חזרו לתיבות סימון |
| טפסים בטלפון | גיליון הטפסים בחשמל ובמים (לקוחות וחשבונות) אטום, כך שהדף ופס הניווט לא נראים דרכו. בסקינים הזכוכיתיים הוא נשאר מטושטש |
| יומנים | כשהזמנה נדחית בגלל התנגשות, ההודעה אומרת עם מה היא מתנגשת (שם ההזמנה כשמותר לראות אותו, וטווח השעות) |
| התראות | ערוץ ההכרזה מופיע ברשימות הערוצים |
| טכנאי הדלת (WisKey) | אחרי שמירה המסך קורא את הדלת מחדש, והכפתורים ממתינים לקריאה. לחיצה באמצע לא נדחית יותר כ"גרסה ישנה" |
| נגישות ומהירות | שמות לכפתורים שלא היה להם שם; הטעינה הראשונה קטנה בכ-21% |

## 2.49.0

| מה | מה רואים |
|---|---|
| ממשק באנגלית | כל מסכי ההגדרות שעוד הוצגו בעברית מוצגים באנגלית למי שבחר אנגלית, וגם הטקסטים שמגיעים מהשרת: אשף ההתקנה, דוח המוכנות, הודעות שגיאה, שמות הרשאות ותפקידים, דוח הבריאות ומשפטי האוטומציות. בעברית שום טקסט לא השתנה |
| שמות ברירת מחדל | שמות שהשרת יוצר (חדר מאשף התוכנית, אירוע ידני, גנרטור, חלון פתיחת דלת ועוד) נוצרים בשפה של מי שיצר אותם. שמות שכבר נשמרו לא משתנים |
| חיפוש בהגדרות | מוצא הגדרה גם לפי מילים באנגלית (למשל restore, codec, ntp), בכל שפת ממשק |
| טבלת הקריאות | מטאבלט ומעלה הטבלה מתחלקת לעמודים שממלאים את הכרטיס, במקום גלילה בתוכה. הבחירה, המקלדת ו"טען עוד" עובדים לאורך העמודים. בטלפון אין שינוי |
| הגדרות הגנרטור | יחידת המידה (kW, kVA, בר, °C, %, V, Hz, שעות, שניות, דקות, ימים) מוצגת בתוך השדה, כמו בחשמל ובמים |

**לחזור לגלילה בטבלת הקריאות:** הגדרות › כללי › עיצוב הממשק › "רשימות ארוכות במסכי השליטה" › גלילה בתוך הרשימה. ההגדרה חלה על
כל המשתמשים ועל כל מסכי הבקרה שמתחלקים לעמודים.

**לבחור אנגלית:** התפריט האישי › החשבון שלי › שפה › "שפת הממשק". כל משתמש בוחר לעצמו.

# What is new in 2.48.0 and 2.49.0

> One page for operators and the system administrator. Written from the release notes and the change records, **not from a live
> installation**. Neither version has a new migration or a bridge change (it stays 0.10.8).

## After the update

1. No home-system restart is needed.
2. Reload the page once after each update (the interface is rebuilt).
3. Nothing new switches itself on. Pages in the tickets table (2.49.0) are on by default, and the scroll can be kept (see below).

## 2.48.0

| What | What you see |
|---|---|
| Switches | Hand-built check boxes and switches for one on/off setting are now the shared switch, in a compact size. The home screen switches and the settings row switches are unchanged |
| Selects | Every select on the settings screens sits in the shared field (one label, frame and error look). The select itself and the phone's own picker are unchanged |
| No scrolling on control screens | The alarm sensors, the external access list and the "who is in the building" list split into pages when there are more rows than fit. With the "scroll" setting they scroll as before |
| Module look | On all 14 settings pages with a segmented selector each module keeps its own key (28 px on a desktop, 44 px under a finger on a phone) |
| Events centre and generator | The events centre chips draw the 2.47.0 look again; the generator recipient and channel choosers are check boxes again |
| Phone forms | The form sheet in electricity and water (customers and accounts) is opaque, so the page and the bottom bar do not show through. In the glass skins it stays frosted |
| Calendars | When a booking is refused for a conflict, the message says what holds the slot (the booking's name where you may see it, and the time range) |
| Notifications | The announce channel appears in the channel lists |
| Door technician (WisKey) | After a write the screen reads the door again and the buttons wait for that read. A press in the middle is no longer refused as an old revision |
| Accessibility and speed | Names for buttons that had none; the first load is about 21% smaller |

## 2.49.0

| What | What you see |
|---|---|
| English interface | Every settings screen that still showed Hebrew is in English for a user who chose English, and so are the server's texts: the setup wizard, the readiness report, error messages, permission and role names, the health report and the automation sentences. Nothing changed in Hebrew |
| Default names | Names the server makes (a room from the plan wizard, a manual incident, a generator, a door window and more) are made in the language of the user who creates them. Names already stored do not change |
| Settings search | Finds a setting by English words too (for example restore, codec, ntp), in either interface language |
| Tickets table | From a tablet up the table splits into pages that fill the card, instead of scrolling inside it. Selection, the keyboard and "load more" work across the pages. Nothing changed on a phone |
| Generator settings | The unit (kW, kVA, bar, °C, %, V, Hz, hours, seconds, minutes, days) sits inside the field, as in electricity and water |

**To keep the scroll in the tickets table:** Settings › General › Interface design › "Long lists on the control screens" › scroll
inside the list. The setting applies to every user and to every control screen that pages.

**To choose English:** the personal menu › My account › Language › "Interface language". Each user chooses for themselves.
