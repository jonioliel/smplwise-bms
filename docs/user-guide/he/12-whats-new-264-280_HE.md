# מה חדש בגרסאות 2.6.4 עד 2.8.0

Source: original

## מה זה

סיכום קצר, בעברית פשוטה, של מה שמשתמש ומנהל יראו אחרת בגרסאות 2.6.4, 2.7.0, 2.7.1, 2.7.2, 2.7.3 ו-2.8.0. לכל פריט יש קישור לפרק שמפרט אותו.
**אחרי ההתקנה** טוענים מחדש את אפליקציית הרשת פעם אחת. העמוד נכתב מהערות השחרור ומהקוד, לא מבדיקה על מערכת חיה; מה שלא נבדק מול התקנה
אמיתית מסומן כך.

> גרסה 2.8.0 שוחררה. מה שנוסף אחריה (2.9.0 עד 2.9.2) מפורט ב-`13-whats-new-290-292_HE.md`.

## מה פעיל מעצמו ומה כבוי

| מה | מצב אחרי העדכון |
|---|---|
| לשונית "סקירה" למנהלי מחלקות (2.7.0) | **פעילה** |
| דרישת תשלום ממולאת מההצעה המאושרת, דרישה לכל תשלום, הודעת "מאושר ומחייב" והודעת דחייה (2.7.1) | **פעילים בלי מתג.** הודעת האישור מוגדרת "באישור המנהל" (שלב נוסף בחלון הבחירה) |
| מעליות (2.7.2, מורחב ב-2.8.0) | **מוסתרות** עד שמגדירים מעלית; התראות מעליות **כבויות** |
| דוח "דורש בחינה" (2.8.0) | פעיל למי שמורשה לערוך את ספריית אנשי הקשר |
| לוח תשלומים, קבצים מספקים, אזור ספקים, בקשות טכנאים, הסכמה בקישור | **כבויים** |
| משתמשי מערכת הבית מתוך Arx, משתמשי Arx בלבד ומפתחות גישה | **לא מיועדים לשימוש** (ראו `47-identity-users_HE.md`) |
| זהות שירות מורחבת, חכירת צילום, הרשאות כניסה לאנשים חיצוניים | **נעולות בקוד** |
