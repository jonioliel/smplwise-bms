# מה חדש בגרסאות 2.40.3 עד 2.43.8

Source: original

> עמוד אחד לאנשי התפעול ולמנהל המערכת, בעברית ואחריה באנגלית. נכתב מהערות השחרור ומתיעוד השינויים, **לא מבדיקה על מערכת
> חיה**. הגרסאות 2.40.0 עד 2.40.2 מתוארות ב-`15-whats-new-2400-2401_HE.md`. הממשק הביתי מתואר בהרחבה ב-`23-home-interface_HE.md`.

## אחרי העדכון

1. **הפעלה מחדש של מערכת הבית** נדרשת פעם אחת אחרי 2.40.4 (גשר 0.10.5), 2.40.7 (גשר 0.10.6) ו-2.43.7 (גשר 0.10.7).
   **את 2.40.4 מתקינים לפני שמשדרגים את מערכת הבית לגרסה 2026.11.**
2. מיגרציות שרצות לבד בהפעלה הראשונה: 2.40.4, 2.40.6, 2.40.7, 2.41.0, 2.41.2, 2.42.0, 2.42.1, 2.43.0, 2.43.1 ו-2.43.7. הן רק
   מוסיפות; חזרה לגרסה שלפניהן רק עם הגיבוי שנלקח לפני העדכון.
3. טוענים מחדש את הדף פעם אחת אחרי כל עדכון.
4. שום דבר חדש לא נדלק מעצמו, חוץ ממה שכתוב כאן במפורש (למשל Domus כמראה ברירת המחדל ב-2.43.8).

# What is new in 2.40.3 to 2.43.8

> One page for operators and the system administrator. Written from the release notes and the change records, **not from a live
> installation**. 2.40.0 to 2.40.2 are in `15-whats-new-2400-2401_HE.md`. The home interface is described in full in
> `23-home-interface_HE.md`.

## After the update

1. **Restart the home system** once after 2.40.4 (bridge 0.10.5), 2.40.7 (bridge 0.10.6) and 2.43.7 (bridge 0.10.7).
   **Install 2.40.4 before upgrading the home system to 2026.11.**
2. Migrations that run by themselves at the first start: 2.40.4, 2.40.6, 2.40.7, 2.41.0, 2.41.2, 2.42.0, 2.42.1, 2.43.0, 2.43.1
   and 2.43.7. They only add; going back past one needs the backup taken before the update.
3. Reload the page once after each update.
4. Nothing new switches itself on, except what is said here (for example Domus as the default look in 2.43.8).

## 2.40.3 to 2.40.7

| What | What you see |
|---|---|
| An installation without video | The interface no longer asks for video settings when there is no recorder and no video server; "Video" in "My account" shows only when there is live video |
| Kiosk and display wall | When a camera's sub stream sends no picture they move to the main stream, like the camera wall, and remember it for 10 minutes |
| Device names (2.40.4) | Names in Arx match the home system's: the device name followed by the entity name. A child device without an area takes its parent's |
| Intercom doors through the bridge (2.40.4) | The bridge blocks intercom door commands sent through its device commands by default. WisKey's own screens are not affected |
| A connection fault (2.40.5) | A command whose link dropped after it left shows "unknown - check the device" and is never offered for a blind retry |
| A full disk (2.40.5) | The system says so clearly and refuses actions that must be recorded until space is freed. Nothing refused is sent later |
| Owner contacts (2.40.5) | Up to five system administrators who are alerted first about the bridge key |
| A large room (2.40.5) | A room with dozens of devices fits the area screen without scrolling |
| Event load (2.40.6) | No more long database locks when many events arrive; WisKey comes back faster after an absence |
| Emergency revoke of the bridge key (2.40.7) | A system administrator revokes the key at once and gets a new one; showing the new code needs an authenticator code |
| Camera reboot (2.40.7) | From the camera screen, through the recorder: a dedicated permission, the recorder-changes switch and a confirmation; once per 5 minutes per camera |
| Recorded-days calendar (2.40.7) | The recordings show which days of the month have recordings |
| WisKey visits (2.40.7) | Arx is the place to manage guests; visits made in WisKey's panel are shown read only |

## 2.41.0 to 2.41.2

| What | What you see |
|---|---|
| A video source per camera | In the camera settings: from the recorder (the default) or from a manual RTSP address for the main and the sub stream. "Test stream" shows a frame, the resolution and the codec before saving |
| Cameras without a recorder | Add a camera with a name, an area and RTSP addresses. It appears on every screen with live video and snapshots only, and on the floor map. Without a recorder the camera screens appear once such a camera exists |
| No WebRTC server | A clear notice with a link to the connection settings instead of an empty player |
| Events screen | The filters are built from ready per-day counts and open much faster |

## 2.42.0 to 2.43.8

| What | What you see |
|---|---|
| The home interface (2.42.0) | A second, simple, room-first interface, with settings per person and per installation. See `23-home-interface_HE.md` |
| Switch classification (2.42.1) | The system suggests "light" or "protected" from the name, and the administrator approves, several at once |
| Start-up warm-up (2.42.1) | After an update the first screen opens faster; it can be turned off in the settings |
| The video service (2.43.0, 2.43.5) | When the video server is unavailable the system says so clearly and recovers by itself. Settings › Video and media lists the video services found and lets you choose one; administrators are told after 15 minutes by default (1 to 60) |
| "More", family and building (2.43.0, 2.43.1) | In the home interface: recordings, the house log, intercom, alarm, music, electricity and water, who is home, the family calendar, shared rooms, the notice board, buses, tickets and "do not disturb" |
| Realistic 3D map (2.43.1, 2.43.3, 2.43.6) | Soft shading, floor reflections (a personal setting), marble and porcelain floors, zoom buttons, one pill per room, the room card, a "building / spread" switch and eight new settings under Settings › Map › "3D map" |
| New plan from a picture (2.43.2) | From a picture or PDF of a floor plan to a 3D floor in seven steps. Detection is local, and nothing reaches the map before publishing |
| Control screens without scrolling (2.43.5) | Thirteen screens fit 1366x768; many cards show in pages |
| No demo mode (2.43.6) | When the server is briefly away the screen shows "no connection to the server" and "try now" instead of made-up data |
| Management screens (2.43.7) | The same components and frame on every management screen; Settings › General shows the real system health, and the backup tab its own errors |
| Arx users (2.43.8) | The create form works again; the administrator sets a password at creation and can set a new one; an on / off switch on the "Arx users" tab itself |
| Look (2.43.8) | Domus is the default look (classic can be chosen again); the selected chip is light blue with a ring and a check mark; one dialog and one drawer across the system |
| English interface (2.43.8) | A language choice in "My account": Hebrew or English. See `80-settings_HE.md` |
