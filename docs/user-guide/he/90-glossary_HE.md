# מילון מונחים — עברית ↔ אנגלית

Source: original

## מה זה

רשימת מונחי מוצר, לפי סדר א-ב עברי, לצוות שעובר בין השפות (למשל כשקוראים את `CHANGELOG.md`
באנגלית מול המדריך בעברית) או שצריך למסור מונח מדויק לתמיכה. מונחים טכניים כלליים (HTTP, SQLite)
לא נכללים; רק מונחי מוצר.

| עברית | English | הסבר קצר |
|---|---|---|
| אודיט / יומן ביקורת | Audit log | רישום כל פעולה מורשית/נדחית, מי ומתי ולמה |
| אזור | Area | חלל בעל שם על תוכנית קומה (חדר/אזור/מסדרון/חוץ/שירות); גם אזור Home Assistant |
| אזור זמן | Time zone | ה-IANA zone שאליו מתורגמים כל הזמנים המוצגים (`time.zone`) |
| אישור פרטיות | Privacy acknowledgement | הסכמה מפורשת לפני ששולחים משהו לספק חיצוני (AI, סקינים) |
| בקרות כניסה | Access control | ההגדרות שקובעות אם מסך WisKey מוטמע או SMPLWISE |
| גיבוי ושחזור | Backup / Restore | ייצוא/ייבוא של נתוני הפרויקט |
| גרסת תוכנית | Plan version | תמונת מצב מפורסמת של קומה; לא נמחקת לעולם |
| הרשאה אפקטיבית | Effective permission | מה שמשתמש נתון רשאי לעשות בפועל, אחרי חישוב תפקיד+היקף+קבוצות |
| הרשאה רגישה | Sensitive permission | הרשאה שחייבת סימון מפורש בתפקיד מותאם אישית (למשל `door.unlock`) |
| היקף | Scope | רמת ההרשאה: כל ההתקנה / אתר / מבנה / קומה |
| הענקה | Grant | הרשאה בודדת שהוענקה במפורש בתוך תפקיד |
| האצלה | Delegation | מנהל אתר משייך תפקידים בתוך היקפו, בכפוף למגבלות |
| חשמל והתקנים | Devices (area) | האזור לשליטה בציוד HA לפי מבנה/קומה/אזור |
| חדר | Room | אזור מסוג "חדר" (סוג ספציפי בתוך "אזורים") |
| חיפוש מרחבי | Spatial search | שדה חיפוש עולמי (Ctrl/⌘K) שמוצא חדרים, מצלמות, ישויות |
| כיול | Calibration | סימון מרחק ידוע על התוכנית כדי שמרחקים יוצגו במדויק, לא כאומדן |
| מדיניות אחסון | Storage policy | תוכנית הקלטה כפי שה-NVR מדווח אותה (קריאה בלבד) |
| מנהל אתר | Site admin | תפקיד לניהול משתמשים/תפקידים/פעולות מרוכזות בהיקף אתר |
| מנהל מערכת | System admin | תפקיד עם כל ההרשאות, כולל הגדרות והרשאות מערכת |
| מסך קיוסק | Kiosk wall | תצוגת קיר ללא תפריטים, מפה ווידאו חי בלבד |
| מפה היסטורית | History map | תצוגת מפה של רגע שחלף, קריאה בלבד |
| מפעיל | Operator | תפקיד שמאשר אירועים, מנהל תיקים, שולט בהתקנים בודדים |
| מקרא | Legend | מקרא סמלים על המפה (פינה ימנית-תחתונה) |
| ניגון מסונכרן | Synchronized playback | ניגון עד 4 מצלמות יחד סביב זמן ייחוס אחד |
| ספריית אנשים | People directory | לשונית WisKey לניהול אנשים, PIN וכרטיסים |
| עורך | Editor | תפקיד שמייבא/עורך תוכניות קומה וממקם מצלמות/ישויות |
| עיבוד לשפת SMPLWISE | Render to SMPLWISE language | ניקוי חזותי מקומי של שרטוט לתוכנית סכמטית |
| פעולה מרוכזת | Bulk action | פעולה על כמה התקנים בבת אחת (כיבוי קומה/אזור/מבנה) |
| פרסום (גרסה) | Publish (a version) | הפיכת טיוטת תוכנית לגרסה שהצופים רואים |
| צופה | Viewer | התפקיד המצומצם ביותר — קריאה בלבד |
| קונוס ראייה | Field-of-view cone | ההמחשה החזותית של כיוון מצלמה על המפה (לא נמדד באמת) |
| קליטת כרטיס | Card capture | תהליך רישום כרטיס RFID חדש דרך קורא עמדת דלת |
| רענון מ-Home Assistant | Refresh from Home Assistant | בקשת עדכון מיידי של מבנה/ישויות מ-HA |
| שכבה (במפה) | Layer | קבוצת סמלים שאפשר להראות/להסתיר על המפה (מצלמות, תאורה…) |
| שיוך (תפקיד) | Role binding | קישור תפקיד↔היקף למשתמש או לקבוצה |
| תיק חקירה | Case | אוסף ראיות (סימניות/עותקים שמורים) סביב אירוע |
| תפקיד מותאם אישית | Custom role | תפקיד שנבנה מהרשאות בודדות, לא אחד מהמובנים |
| תצוגה (שמורה) | (Saved) view | קבוצת מצלמות עם שם ופריסה, שמורה לשימוש חוזר |
| Bridge (גשר) | — | אינטגרציית `smplwise_bridge` ב-Home Assistant, מתווכת פעולות בזהות המשתמש |
| DXF | — | פורמט שרטוט וקטורי הניתן לייבוא ישיר (DWG חייב המרה ל-DXF קודם) |
| go2rtc | — | שרת ממסר וידאו חיצוני; רק זרמי `smplwise_*` שייכים למוצר |
| Ingress | — | מנגנון ה-Proxy של Home Assistant שדרכו האפליקציה נטענת ומזוהה המשתמש |
| MSE / WebRTC | — | שתי שיטות שידור וידאו חי; MSE ברירת המחדל, עובד מאחורי CGNAT/מנהרות |
| NVR | — | Network Video Recorder — יחידת ההקלטה של Hikvision |
| PTS↔UTC | — | עוגן זמן בין הזרם המקורי לזמן אמיתי; עדיין לא מאומת (best effort) |
| RTSP | — | פרוטוקול הזרמת הווידאו מה-NVR |
| WisKey | — | מותג האינטרקום/בקרת הכניסה שמוטמע כברירת מחדל באזור בקרת הכניסה |
