## Notes for the lead

1. The worry that the nightly would go red on `layout-access-*` because they "still sweep bubble" did not materialise on v2.23.2:
   all three pass (8/8 each) on desktop with the frozen-skin fallback.
2. `layout-schedules-parity` passes on v2.23.2 (the FIX2232B fixes hold); only its bubble case is skipped.
3. The four bubble-only files (`evidence-material-dials`, `layout-bubble-screens`, `layout-material`, `layout-bubble-lists`) are
   pure no-ops while `FROZEN_SKINS` contains bubble (27 skipped tests in total).
4. Timing-sensitive tests: the page-load timeouts appear whenever the runner load exceeds about 30. A quiet window (or a longer
   navigation timeout for the dev-server projects) would remove these false reds; it is a runner-capacity issue, not a product issue.
5. NOT run: Playwright on tablet/mobile for specs that skip those projects by design; fixture-backed specs; pixel baselines;
   the full ASGI run; the remaining non-heavy Playwright spec files (the nightly covers them).
6. Mid-run decision: the first backend attempt (2 shards) was stopped after 35 min (about 5 percent done, runner load 40) and
   restarted with 6 shards; only the 6-shard run is counted.
