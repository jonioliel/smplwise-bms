# גיבוי מחוץ למכונה ל־Google Drive: מדריך קצר לבעלים

הגרסה המלאה באנגלית: `GDRIVE_BACKUP_SETUP.md`. Arx לא יוצר עבורכם פרויקט, לקוח OAuth או כניסה ב־Google. את שלבים 1–5 עושים פעם אחת בחשבון Google שלכם.

## א. ב־Google Cloud Console (פעם אחת)

1. נכנסים ל־https://console.cloud.google.com.
2. יוצרים פרויקט חדש, למשל `SmplWise Arx backup`, ושומרים אותו כל עוד שומרים את הגיבויים.
3. APIs & Services › Library › ‏Google Drive API › ‏Enable.
4. מסך ההסכמה (Google Auth Platform / OAuth consent screen): סוג משתמש External, שם אפליקציה ודוא"ל תמיכה; בהרשאות מוסיפים **רק** `drive.file`; סטטוס פרסום **In production** (ב־Testing האסימון פג אחרי 7 ימים).
5. Clients › Create OAuth client › סוג **TVs and Limited Input devices** › מעתיקים את ה־Client ID ואת ה־Client secret.

## ב. ב־Arx (הגדרות › אבחון › גיבוי ושחזור › עותקים מחוץ למכונה)

1. אם מפתח ההצפנה לא יוצא — מייצאים אותו ושומרים מחוץ למערכת. ב־Drive נשמר רק עותק מוצפן.
2. "הוספת Google Drive" › מדביקים Client ID ו־Client secret › שמירה. היעד נשמר **כבוי**.
3. "חיבור חשבון Google": בטלפון או במחשב פותחים https://www.google.com/device, מקלידים את הקוד, נכנסים לחשבון שבו יישמרו העותקים ומאשרים.
4. מפעילים את היעד › "בדיקת חיבור" › "העלאה עכשיו" (או מחכים לגיבוי היומי).

## איך נשמרים הפרטים

- ‏Client ID — לא סוד, נשמר בהגדרות היעד.
- ‏Client secret ואסימון הרענון — מוצפנים במפתח ההתקנה (`backup_offbox_secrets`), לא מוצגים, לא נרשמים ביומן ולא נכללים בגיבוי פרויקט. האסימון מתקבל רק דרך "חיבור חשבון Google".
- "ניתוק החשבון" מבטל את ההרשאה ב־Google, מוחק את האסימון ומכבה את היעד. העותקים נשארים ב־Drive.

## הודעות אפשריות

- **אין מספיק מקום פנוי ב־Google Drive** — לפנות מקום או לשמור פחות עותקים.
- **Google Drive מגביל את קצב הבקשות** — אין צורך לעשות דבר; ינסה שוב.
- **החיבור פג או בוטל; יש לחבר מחדש** — ללחוץ שוב "חיבור חשבון Google".
- **Google דחה את מזהה הלקוח או הסוד** — לבדוק את הערכים ואת סוג הלקוח.
