# רשימת קבלה: המערכת הישנה מול Arx, זו לצד זו (אתר הפיילוט) — T070

מסמך עבודה ליום הבדיקה באתר. בכל שורה בודקים את אותו דבר בשתי המערכות, באותו זמן, ורושמים תוצאה.
המערכת הישנה = התוסף "Hikvision NVR Panel" 1.5.27 (הפאנל "NVR"). Arx = SmplWise Arx (הפאנל של Arx).

כללי הבדיקה:
- שתי המערכות פועלות במקביל לכל אורך הבדיקה. שום דבר בישן לא נמחק ולא משתנה.
- ב־Arx מתג "כתיבה ל־NVR" כבוי לכל תקופת הבדיקה (הגדרות › חיבורים). אין שום כתיבה ל־NVR.
- כל צילום מסך נשמר רק בתיקייה הפרטית (`private-evidence/`), לא במאגר.
- תוצאה בכל שורה: **עבר** / **נכשל** / **מקובל** (יש הבדל, והבעלים מאשר אותו) / **לא נבדק**.
