## 9. NVR — Notify Surveillance Center (הגדרה חד־פעמית)

בממשק ה־NVR (דפדפן): **Configuration → Event → Basic Event → Motion Detection** → לבחור מצלמה → לשונית
**Linkage Method / Linkage Action** → לסמן **Notify Surveillance Center** → Save → לחזור על כל מצלמה (או "Copy to"
לשאר). אין כתובת שרת ואין פורט להגדיר: ה־VMS הוא שמתחבר ל־NVR ומאזין לזרם ההתראות; הסימון רק אומר ל־NVR לפרסם
את האירוע לזרם הזה. לא לגעת ב־"Notify by HTTP" / "HTTP listening" — זו אפשרות אחרת שכן דורשת כתובת.
לאירועי אדם/רכב: אותו סימון גם תחת **Smart Event** (Line Crossing / Intrusion / Region Entrance) לכל מצלמה שיש לה.
אחרי השמירה: הגדרות › כללי ב־VMS → "NVR: שלח התראות" תוך דקות מהתנועה הראשונה; ואני אאמת מולך בקריאה בלבד.
