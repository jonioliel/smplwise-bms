# חיבור יומנים חיצוניים - הגדרה קצרה לבעלים (CALCONNECT-2330)

הגרסה המלאה באנגלית: `CALENDAR_CONNECT_SETUP.md`.

Arx לא יוצר חשבון, לא מבקש סיסמה ולא מאשר בשמך. יוצרים אפליקציה משלך אצל הספק, מדביקים את המזהה ב־Arx ומאשרים בדפדפן שלך.
הכול כבוי עד שמפעילים: הגדרות › יומנים (יומנים, ואז סנכרון; פידים יוצאים בנפרד). חיבור דורש את ההרשאה "יומנים: חיבור יומנים
חיצוניים"; שיוך יומן דורש בנוסף עריכה באותו יומן.

## מנוי iCal (קריאה בלבד, בלי חשבון)
1. מעתיקים את **הכתובת הסודית בפורמט iCal** של היומן.
2. הגדרות › חיבורי יומן › iCal › "מנוי iCal" ומדביקים (https או webcal).
3. "שיוך יומן" ובוחרים את היומן ב־Arx.

רק https לכתובת ציבורית (כתובת ברשת הביתית נחסמת), עד 5MB. הכתובת נשמרת מוצפנת ולא מוצגת שוב.

## Google
1. ב־Google Cloud: פרויקט, להפעיל Google Calendar API.
2. OAuth consent screen: להוסיף את עצמך כ־Test user. במצב Testing ההרשאה פגה אחרי 7 ימים - כדאי לפרסם את האפליקציה.
3. Credentials › OAuth client ID מסוג **Desktop app**. מעתיקים Client ID ו־Client secret.
4. ב־Arx: כרטיס Google › "חיבור", מדביקים, "שמירה והמשך".
5. "פתיחת מסך האישור של Google" ומאשרים **את כל** התיבות.
6. הדפדפן יעבור ל־`http://127.0.0.1:8749/...` ויראה שגיאה - זה תקין. מעתיקים את כל הכתובת, מדביקים ב־Arx, "סיום".
7. "שיוך יומן": יומן Google, יומן Arx, כיוון, ומה עובר ("תפוס" / כותרות / כותרות והערות).

## Microsoft 365 / Outlook
1. ב־Microsoft Entra: App registrations › New registration.
2. Authentication: **Allow public client flows = Yes** (לא צריך סוד ולא כתובת חזרה).
3. API permissions: Microsoft Graph › Delegated › **Calendars.ReadWrite** (או Calendars.Read).
4. ב־Arx: כרטיס Microsoft › "חיבור", מדביקים את Application (client) ID; ספרייה `common` כברירת מחדל.
5. Arx מציג קוד קצר: פותחים https://microsoft.com/devicelogin בכל טלפון או מחשב, מקלידים ומאשרים. Arx מזהה לבד.

בניתוק Microsoft כדאי גם להסיר את הגישה של האפליקציה ב־myapps.microsoft.com / account.live.com.

## פיד iCal יוצא
מפעילים "פידים" בהגדרות › יומנים. iCal › "פידים יוצאים", בוחרים יומנים ו"תפוס" או כותרות. הכתובת מוצגת **פעם אחת**.
הערות ופרטי אורחים לא יוצאים אף פעם. הכתובת עובדת רק היכן ש־Arx נגיש לאפליקציית היומן.

## מצבים בכרטיס
- **ממתין להגדרה** - חסר מזהה / אישור / כתובת: "המשך הגדרה".
- **נדרשת הרשאה מחדש** - ההרשאה פגה או בוטלה: "הרשאה מחדש" (או "המשך" לניסיון נוסף).
- **הספק מגביל את קצב הבקשות / המכסה נוצלה** - לא צריך לעשות כלום, Arx ינסה שוב לבד.
- **הספק דחה את מזהה הלקוח** - לבדוק את האפליקציה אצל הספק ולהדביק שוב.
