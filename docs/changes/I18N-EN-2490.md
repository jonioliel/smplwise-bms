## 3. Tool: `frontend/scripts/i18n-wrap-hebrew.mjs` (commit 9a17655db)

Mechanical codemod (TypeScript AST with the type checker) for the next modules:
`node scripts/i18n-wrap-hebrew.mjs --table <msg table> [--report out.json] [--skip-owner NAME] <files>`. It wraps plain
strings, turns string templates into `tr('... {a} ...', { a })`, and in `html` templates wraps a whole text node or quoted
attribute value when every value inside is a plain string / number (a template or node value splits the text instead). It
leaves css, HTML comments, data attributes, comparisons / `case`, matching-method arguments, literal types, `{ he, en }`
objects, `lang ? en : he` ternaries, and declarations named demo / mock / fixture / sample / keyword / pattern (listed with
the reason in `--report`). The English is then written by hand into the pack file. Known limit: whitespace inside a wrapped
html text node is collapsed to one space (same rendering outside `white-space: pre`); `&lt;`-style entities split a text.
