# CR-WKBRIDGE295 — Arx-side preparation for the WisKey round-3 bridge command route

Status: PREPARED, NOT WIRED. Branch `pilot/WKBRIDGE-295` from `main` @ `c37c75c917c79f694039c961174db37d57d43c4c` (v2.12.3).
No route, switch, UI or caller uses any of it. Nothing is sent to WisKey.

## Why

The owner wants Arx to have full WisKey access **only** through the authenticated Arx bridge principal (no HA admin, no
`users:view`, no per-command human approval). WisKey's round-3 plan (planning only, WisKey repository @
`acc6509111ae2afbd2d54b620709960208d7e6c8`, `docs/owner-development-2026-10-23/arx-round3-mac-plan/`) adds a signed command route
`wiskey-bridge-command.v1` that reuses the existing `bridge` field and pairing signature, and asks Arx for (a) an authority policy
snapshot for T06 `authority_revision` and (b) Arx's data for the shared Q1 fixture. Final shapes are published later, on WisKey's
implementation SHA, so everything here sits behind ONE adapter module.

## What

1. `smplwise_vms/backend/smplwise/services/wiskey_bridge_adapter.py` — the only place with WisKey round-3 wire shapes.
   - `build_command(conn, request_id=, command=, parameters=, query_owner_id=)` → `SignedCommand`: envelope `{id, type, bridge}`,
     signed body `{kind, command, query_owner_id, issued_at, expires_at, parameters}` + `ts, nonce, sig`, signed by the EXISTING
     `ha_bridge.signing_key` / `ha_bridge.sign` (pairing secret or the key set's adopted `g0-legacy`; byte-compatible with WisKey's
     verifier recipe). Allow-listed commands only, each with an exact parameter key set; read commands refused; floats/non-str keys
     refused; `0 < expires_at - issued_at <= 15 s`; frame id exact int 1..2^53-1; wire ≤ 65536 bytes.
   - `authority_snapshot(conn, actor=, station_ids=, query_owner_id=, repository_id=)` → `{schema, schema_version, repository_id,
     query_owner_id, actor_ref, revision, issued_at, expires_at, stations, grants:[{grant_id, station_id, permission}]}` from
     `rbac.authorize` per station and station permission (deny-overrides, active flag, station chain); `grant_id` is the binding
     that allows it. Revision read before and after; a change in between → `revision_moved`. `snapshot_current()` re-checks.
2. `smplwise_vms/backend/smplwise/migrations/0150_arx_authority_revision.sql` — PROVISIONAL number, one file: a single monotonic
   counter bumped by triggers on bindings, custom roles, group membership, `users.active`, station placement, building/site
   deletion or re-parenting, per-station person decisions (effect/relays), external door grants (doors/window/timing/state) and every
   change of the `permission_revision` setting. The existing `permission_revision` is not used alone because several writers
   (group bindings, group membership, station placement, station-permission decisions) change access without bumping it.
3. `smplwise_vms/backend/tests/fixtures/arx_station_pending_round2_arx.json`, generated by `tests/wkbridge_fixture.py` from WisKey's
   synthetic `tests/fixtures/arx_station_pending_round2.json` (commit `f842b2c523b22b8d1f4275ca9b02f78acb1010fd`, blob
   `3e6488a21d0ceb5b66cd4056e23442b2bfa5ac47`, sha256 `b82955330e3427639ca1a2f4c64a36c4a7aefa6736585dc98c531a67cad7048e`):
   same top-level shape plus an `arx` block (the access_state_v2 answer Arx expects, parsed by the strict parser, and Arx's
   verdicts). Semantics: `pilot/WKB-295` @ `812b49a1df5f8b0ca31803754d114066ed56d6a1`; the output is identical under main's rule
   (checked locally by running the generator against both modules). Verdicts: station-a `unknown`, station-b `pending`,
   station-c `pending`, person `pending`.
4. `smplwise_vms/backend/tests/test_wkbridge_295.py` — builder, revision, snapshot and fixture-drift tests (fakes only).

## Assumptions awaiting the WisKey implementation SHA (ASSUMED-PENDING-WISKEY-SHA)

- kind name `wiskey-bridge-command.v1`; closed body key set; envelope `{id, type, bridge}`; `type = hikvision_intercom/<command>`.
- the 15 s window and the 65536-byte request cap (taken from peer_query).
- pairing-v1 framing only: a rotated key-ring v2 key (`kid`) refuses to build (`keyset_v2_unconfirmed`, `ALLOW_KEYSET_V2 = False`).
- the allow-list and parameter sets: `media/station_descriptor`, `media/stream_lease`, `media/talk_open`, `media/talk_floor`,
  `media/talk_close` (W10 plan); profile `sub|main`; close reasons; ref format `[A-Za-z0-9_-]{16,128}`; actor `{id, display_name}`.
- left out until published: `media/talk_frame` (the 50 Hz frame plane / nonce budget is unresolved), `whatsapp/template_send_v2`,
  the name_ref prepare/apply routes, and the command that installs the policy snapshot.
- snapshot schema name `arx-authority-snapshot.v1`, its key set, grant shape, TTL default 60 s / max 300 s.
- the snapshot→access_state_v2 projection in the fixture is Arx's reading of WisKey's projection.

## Recorded, not resolved

WisKey's text says "C without a row stays UNKNOWN" and "the global blocked flag does not void A's per-station proof". Arx's model
on the same input answers station-c `pending` (it is named in a removal queue) and station-a `unknown` (a queued id without a row
cannot be attributed, WKB-295). Joint acceptance belongs to the Mac round.

## Security notes

- No new key, signer, endpoint or account; authority is never taken from caller JSON (`principal`, `consent`, `is_admin`, `user`,
  wire fields are refused as parameter names).
- Parameter values (raw PIN, name, card, audio) are never logged, audited, put in an exception or a repr; `audit_fields()` carries
  the parameter keys only. The signed wire is held as text so it cannot be mutated after signing.
- The snapshot carries ids, permission names, a revision and times only; it reads, never writes or audits.
- The counter table is in no backup allow-list, so a `replace` restore bumps it rather than rolling it back. A whole-file database
  restore rolls it back; WisKey plans to refuse a rollback, so that host must re-pair (known limit).

## Rollback

Delete the adapter module, the tests and the fixture; drop `arx_authority_revision` and the `trg_aar_*` triggers. Nothing else reads them.
