## What was built

### Slice 1 - backend (commit 69da383f2)

* `services/home_interface.py`: six new home categories `MODULES_P3 = (media, announce, bills, water, systems, map)`, appended to
  `MODULES` (so the administrator page lists them and a person with no explicit list sees them).
* The home-only gate opens exactly the routes the phase 3 screens call - exact routes (`HOME_ALLOWED_EXACT_P3`) and two whole-path
  patterns (`HOME_ALLOWED_PATTERNS_P3`), no new prefix (a prefix would also open the administrative leaves next to them):

| Capability | Routes opened to a home-only person | Permission the route checks (unchanged) |
|---|---|---|
| Music and screens | `GET multimedia/status`, `GET multimedia/devices`, `GET multimedia/devices/{key}`, `.../{key}/library`, `.../{key}/artwork`, `POST .../{key}/commands`, `GET multimedia/groups`, `POST multimedia/groups/join`, `POST multimedia/groups/leave` | media.read / control / power / group at the device's anchor |
| Announcement | `GET announcements/areas`, `POST announcements` | media.announce |
| Electricity bill | `GET energy/accounts`, `GET energy/accounts/{id}/status`, `GET energy/accounts/{id}/periods` | energy.view / bills (money only with energy.bills) |
| Water | `GET infra/water/status`, `meters`, `consumption`, `events/summary` | the water module + water.view reach |
| House systems | `GET generator/devices/live`, `GET infra/elevators`, `GET infra/temperature` | generator.view / their own reach |

  Still refused to a home-only person (tested): `announcements/emergency` (even for an announcer), `announcements/config | templates |
  test | history | translate`, the media layout / remote editor / admin / bulk / presets / queue, every energy bill / customer / setting,
  the water settings / meter detail / alert log, the generator settings / detect / alerts / device detail, the elevator and temperature
  management. The gate never grants: an operator (no media.announce) is refused by the route itself (403 `forbidden`, not the gate).
