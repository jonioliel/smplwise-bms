## Unit A - catalog, discovery, transport choice (commit `54504eafc`)
- implemented / registered / wired: `services/wiskey_direct_catalog.py` (`load`, `parse`, `envelope_for`, `direct_refusal`,
  `OWNER_EXCLUDED_WRITES`), runtime data `services/wiskey_r5_catalog.jsonl` (trimmed by `scripts/wiskey_r5_catalog_trim.py`; the
  provenance row keeps the original SHA-256 `f707d1a15252e08f87596a1296b476f366d8718f884c5857756f1a6c63f431d7`);
  `services/wiskey_direct_discovery.py` (`read_capabilities`, `read_time`, `TimeObservation.admits`, `DirectDiscovery`);
  `services/wiskey_direct_join.py` (`envelope_kind` from the catalog, `DirectCommandSession.discover / transport_refusal /
  discovery_due / require_discovery`, `connect_ready(command=)`, `DirectJoin.selected(command)`, per-command selection in
  `SelectingLeaseTransport`, `template_or_none`, `people_send`).
- W5-CATALOG-01: the reader handles `CATALOG_PROVENANCE` (one, not counted), `COMMAND` (274) and `DIRECT_ONLY_COMMAND` (3, no HA fields)
  explicitly: 277 names, 270 discovered, 43 families; any other row kind / duplicate / count mismatch refuses the whole catalog.
- W5-API-01: the signed `bridge.kind` comes from the catalog row (peer-query for the four peer reads, bridge-command otherwise and for the
  three direct-only reads); `capabilities.commands[].envelope` must equal `wiskey-direct-ws.v1` and is never used as a kind. The five
  HA-body audio commands and the owner-excluded `jobs/approval_decide` / `jobs/approval_request` are refused `not_sent` before any byte.
- Selection rule part (4): with the join installed a command is written only when the CURRENT connection's `direct/capabilities`
  lists it and `direct/time` admits Arx's own signing window (Arx ahead of WisKey: skew + 0.5 s <= max_issued_future; WisKey ahead:
  skew + 2 s < Arx's 10 s window; never beyond max_ts_skew; window <= max_command_ttl). Time is an observation only: it renews nothing
  and never moves Arx's signing clock. Discovery is bound to its connection_ref: a reconnect re-reads it; a failed discovery is not
  asked again on that connection. A v1-incompatible lifecycle (kid, cursor resume, resource adoption) is not selected.
- Caller/router map: `docs/integrations/wiskey/r5/CALLER_MAP.json` (generator `scripts/wiskey_caller_map.py`): per family and command
  the direct envelope and the Arx modules that name the command (a string-literal scan - a candidate, not a send or an acceptance);
  25 of 43 families have an Arx caller candidate.
- Changed existing test: `test_wkjoin_295.py` - its fake server answers the two discovery reads in WisKey's shapes; one expected
  command list now starts with `direct/capabilities`, `direct/time`.
