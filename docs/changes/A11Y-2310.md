## Open, not fixed here

- Dark-scheme probe leftovers (UXREST-295, `audit-dark-*-after.json`): alarm hero hint 3.9:1; messaging-accounts 11 px muted text
  4.0-4.3:1 on the account list; electricity meters tree count 4.0:1; multimedia screens decorative 68 px channel number 2.0:1
  (decorative); diagnostics device pill 1.8:1 (dark text on a dimmed pill, likely a probe artefact on a glass fill); events chip
  count "(" 1:1 (probe artefact). Each needs a re-measure on 2.29.0 and, for the muted ones, a token decision
  (`--sw-text-3` in dark), which changes many screens, so it is not a small fix. Recommend a follow-up with a dark-scheme probe.
- Form-label coverage was not machine-audited beyond the focus probe; no systematic gap was found in the sampled screens.
- `sw-popover` is a non-modal `role="dialog"` with no Escape handler (map marker card); low severity, left as is.

None. The fix adds key handling only; no screen changes appearance. Pixel snapshots untouched.
