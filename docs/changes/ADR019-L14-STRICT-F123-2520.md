## Known limits, rollback

* ADR-019 D2 condition (c) ("one release in the lab logged no unknown key for the model") is NOT met: no model was on the observing
  `RequestModel` in a released build (step 1 shipped the base, nobody adopted it). The flip rests on (a) the backend tests in strict
  mode and (b) reading every frontend caller, as the row brief asks. See open question 1.
* The inventory scan is static (a floor): a body built only through `model_validate` in a helper outside the router would be missed;
  the families' modules were also scanned class by class, not only through routes.
* Rollback: one line per module (`_Body` back to `BaseModel`, or onto `RequestModel` to observe), and `--write` the ratchet.
