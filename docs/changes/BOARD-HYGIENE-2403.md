## 1. Method

Every BACKLOG (137) and BLOCKED (18) card at v2.40.2 was checked against git before anything was claimed:

- `git log origin/main --grep <id>` for every card id (whole-token match) since the last full audit (REGISTRY-AUDIT-20261103, commit
  83ce74480) and the GUIDE-BOARD-2402 registry update (3308bd1fa); only those two registry commits named open cards since 2026-11-04;
- `docs/changes/*.md` searched for every id; the card's own evidence lines and the commits they name re-checked with
  `git merge-base --is-ancestor <sha> origin/main` and `git describe --contains` (first tag that contains the commit);
- unmerged branches named in the evidence re-checked (`origin/pilot/WX3-hmac-rotation`, `origin/pilot/WISKEY-importer`,
  `origin/pilot/WISKEY-screens-design`, `origin/docs/TV-RUNBOOK-2380` are still not ancestors of `origin/main`;
  `origin/pilot/WISKEY-DOOR-TECH-2390` now is - see WXW);
- owner decisions read where a card might be superseded (`private/planning/OWNER_DECISIONS_2026-10-20_NIGHT.md`, cited by path only).

Classes: **SHIPPED** (the card's scope is on origin/main in a tagged release; live acceptance may still be NOT_RUN), **PARTLY** (what
shipped and what is left), **STILL OPEN**, **OBSOLETE?** (a later decision or design replaced it - listed for the owner, never marked
here), **BLOCKED-external** (waits for the owner or WisKey, and on what).
