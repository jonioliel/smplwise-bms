- Candidates: id/task-id tokens in backend and frontend tests, plus test files named in task evidence; then keyword search.

  `~/smplwise-results/nightly/gate_main_eab715e53.md`, junit/Playwright JSON in `gate_main_eab715e53.logs/`), indexed read-only.
  Only `passed` / Playwright `expected`/`flaky` count. `SW_LIVE` evidence specs skip in the nightly and are lab tests, not passes.
- Classification of the 276 records was done by six read-only workers on fixed chunks with one brief, then merged.
  The receipt's COVERED means: named tests passed in that nightly and assert the acceptance on fakes. It is NOT a catalog PASS
  until the lead records it; the nightly sha is main, the base of this branch is the 2.40.5 train.
