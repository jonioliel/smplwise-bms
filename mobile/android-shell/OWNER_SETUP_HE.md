# חיבור ההתראות של Android

מזהה האפליקציה אושר על ידי הבעלים: `com.smplwise.arx.app`.
כעת נבנתה גרסת בדיקה מול שרת וממסר מקומיים. לא התחברנו לשרת אמיתי.

1. **פרויקט Firebase:** הבעלים ציין שצריך ליצור פרויקט. פתחו את [Firebase Console](https://console.firebase.google.com/), צרו פרויקט בחשבון SmplWise, והוסיפו אפליקציית Android עם המזהה `com.smplwise.arx.app`. Analytics אינו נדרש ל־FCM. הורידו את `google-services.json` ושמרו אותו מקומית ב־`mobile/android-shell/app/google-services.json`. הקובץ מוחרג מ־Git. אין לשלוח מפתח service-account לאפליקציה או לצ׳אט; המפתח שייך להגדרות הממסר בלבד.
2. **הממסר:** הבעלים ציין שצריך להקים ממסר. הקמתו עדיין לא בוצעה במסגרת משימת אפליקציית Android. לאחר הקמתו נדרשת כתובת HTTPS מאושרת. בזמן בנייה מעבירים `-ParxPushRelayUrl=https://…`. בקשת הרישום לממסר נושאת את טוקן FCM; אל שרתי Arx נשלח רק הטוקן האטום שמחזיר הממסר. צריך גם להשלים בחוזה כיצד האפליקציה מקבלת את מזהה השרת האטום שיגיע בדחיפה. כרגע השדה הזה קיים רק ב־mock.
3. **טלפון לבדיקה:** Android עם שירותי Google, חיבור USB ומצב ניפוי USB. יש לבדוק מיקום ברקע, מסירה תחת Doze, SSID, חיישני תנועה, צעדים, ברומטר וביקון. האמולטור אינו אישור להתנהגות הזו.
4. **חתימת הפצה:** ה־APK הנוכחי חתום במפתח debug בלבד. כשנגיע להפצה נבקש את פרטי החתימה מהבעלים. קובצי keystore וסיסמאות נשמרים מחוץ ל־Git, באמצעות `keystore.properties` המקומי או משתני הסביבה המתועדים ב־README. כדי לעדכן התקנה קיימת נדרש אותו מפתח חתימה ו־versionCode גבוה יותר.

לאחר הגדרת Firebase והממסר אפשר לבנות שוב. Plugin הגדרות Google מופעל רק אם הקובץ המקומי קיים, לכן גם build ללא Firebase עובד לצורך mock.
